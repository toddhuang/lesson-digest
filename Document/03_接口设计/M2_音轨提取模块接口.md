# M2 音轨提取模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M2
> 模块职责：从视频中提取音轨，转换为 ASR 要求的格式

---

## 一、模块概述

音轨提取模块调用 ffmpeg 从视频文件中提取音轨，并转换为 FunASR 要求的格式（16kHz，单声道，WAV）。输出 WAV 音频文件，缓存到本地支持断点续传。

---

## 二、接口列表

### 2.1 extract_audio

**功能**：从视频中提取音轨并转换为指定格式，输出 WAV 文件。

**签名**：
```python
def extract_audio(
    video_path: str,
    output_path: str,
    sample_rate: int = 16000,
    channels: int = 1
) -> AudioInfo
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 输入视频文件路径 |
| output_path | str | 是 | — | 输出 WAV 文件路径 |
| sample_rate | int | 否 | 16000 | 采样率（Hz），FunASR 要求 16000 |
| channels | int | 否 | 1 | 声道数，1=单声道，2=立体声 |

**输出**：AudioInfo 对象

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFmpegError | ffmpeg 执行失败（包含错误码和 stderr） |
| InvalidVideoError | 视频文件无音轨 |

---

### 2.2 has_audio

**功能**：检测视频文件是否包含音轨。

**签名**：
```python
def has_audio(video_path: str) -> bool
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 视频文件路径 |

**输出**：bool（有音轨返回 True）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |

## 三、数据结构

### 3.1 AudioInfo（dataclass）

```python
@dataclass
class AudioInfo:
    path: str              # 输出 WAV 文件路径
    duration: float        # 音频时长（秒）
    sample_rate: int       # 采样率（Hz）
    channels: int          # 声道数
    size_bytes: int        # 文件大小（字节）
```

## 四、第三方库调用

### 4.1 ffmpeg（命令行调用）

**音轨提取命令**：
```bash
ffmpeg -i {video_path} -vn -acodec pcm_s16le -ar {sample_rate} -ac {channels} {output_path} -y
```

**参数说明**：
- `-vn`：不处理视频流
- `-acodec pcm_s16le`：PCM 16位小端编码（WAV 标准格式）
- `-ar {sample_rate}`：设置采样率
- `-ac {channels}`：设置声道数
- `-y`：覆盖已存在文件

### 4.2 ffprobe（音轨检测）

**检测音轨命令**：
```bash
ffprobe -v error -select_streams a:0 -show_entries stream=codec_type -of csv=p=0 {video_path}
```

**输出**：有音轨时输出 `audio`，无音轨时无输出。

### 4.3 Python 调用方式

使用 `subprocess.run()` 调用 ffmpeg/ffprobe：
```python
import subprocess

result = subprocess.run(
    ["ffmpeg", "-i", video_path, "-vn", "-acodec", "pcm_s16le",
     "-ar", str(sample_rate), "-ac", str(channels), output_path, "-y"],
    capture_output=True, text=True
)
if result.returncode != 0:
    raise FFmpegError(result.stderr)
```
