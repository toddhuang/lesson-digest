# M16 文字识别适配层 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M16
> 模块职责：定义统一 OCR 接口，封装具体 OCR 引擎，隔离第三方库变化

---

## 一、模块概述

文字识别适配层采用**适配器模式（Adapter Pattern）**，定义统一的 OCR 调用接口，封装具体 OCR 引擎的 API 差异。当前实现为 PaddleOCR 适配器，将来更换 OCR 引擎（如 EasyOCR、MMOCR、Tesseract）时只需新增适配器，核心业务代码（M5 文字识别模块）零修改。

---

## 二、统一接口定义

### 2.1 OCRAdapter（抽象基类）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List

@dataclass
class OCRResult:
    text: str                    # 识别文本
    confidence: float            # 置信度（0-1）
    bounding_box: List[float]    # 文本框坐标 [x1, y1, x2, y2]（相对坐标 0-1）

class OCRAdapter(ABC):
    """文字识别适配器抽象基类"""

    @abstractmethod
    def load_model(self, config: dict) -> None:
        """加载 OCR 模型"""
        pass

    @abstractmethod
    def unload_model(self) -> None:
        """卸载模型，释放 GPU 显存"""
        pass

    @abstractmethod
    def recognize(self, image_path: str) -> List[OCRResult]:
        """
        文字识别，返回识别结果列表

        Args:
            image_path: 图片文件路径

        Returns:
            识别结果列表，按阅读顺序排序
        """
        pass

    @abstractmethod
    def get_device(self) -> str:
        """返回运行设备（cuda/cpu）"""
        pass
```

## 三、当前实现：PaddleOCRAdapter

### 3.1 类定义

```python
class PaddleOCRAdapter(OCRAdapter):
    """PaddleOCR 文字识别适配器"""

    def __init__(self):
        self.ocr = None
        self.config = None
        self._device = "cuda"
```

### 3.2 load_model

**功能**：加载 PaddleOCR 模型（检测 + 方向分类 + 识别）。

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | dict | 是 | 配置字典 |

**配置项**：
| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| use_angle_cls | bool | True | 是否启用方向分类 |
| lang | str | "ch" | 语言（ch/en/...） |
| det_db_box_thresh | float | 0.5 | 检测框阈值 |
| use_gpu | bool | True | 是否使用 GPU |

**输出**：None

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| ModelLoadError | 模型加载失败 |

**PaddleOCR 调用方式**：
```python
from paddleocr import PaddleOCR

self.ocr = PaddleOCR(
    use_angle_cls=config.get("use_angle_cls", True),
    lang=config.get("lang", "ch"),
    det_db_box_thresh=config.get("det_db_box_thresh", 0.5),
    use_gpu=config.get("use_gpu", True),
    show_log=False,
)
```

---

### 3.3 recognize

**功能**：对图片进行 OCR 识别。

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| image_path | str | 是 | 图片文件路径 |

**输出**：List[OCRResult]

**PaddleOCR 调用方式**：
```python
result = self.ocr.ocr(image_path, cls=True)
```

**返回数据解析**：
PaddleOCR 返回格式：
```python
[
  [
    [[x1,y1], [x2,y2], [x3,y3], [x4,y4]],  # 文本框四个角坐标
    ("识别文本", 置信度)                       # 文本和置信度
  ],
  ...
]
```

转换为 OCRResult：
- `text` = 识别文本
- `confidence` = 置信度
- `bounding_box` = [min_x, min_y, max_x, max_y]（转换为相对坐标 0-1）

**坐标归一化**：
```python
# 获取图片尺寸
from PIL import Image
img = Image.open(image_path)
width, height = img.size

# 归一化
x_coords = [p[0] for p in box]
y_coords = [p[1] for p in box]
bounding_box = [
    min(x_coords) / width,
    min(y_coords) / height,
    max(x_coords) / width,
    max(y_coords) / height,
]
```

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| OCRError | 识别失败 |
| ModelNotLoadedError | 模型未加载 |

---

### 3.4 unload_model

**功能**：卸载模型，释放 GPU 显存。

**实现方式**：
```python
import paddle
del self.ocr
paddle.device.cuda.empty_cache()
self.ocr = None
```

## 四、可扩展实现

| 适配器 | 引擎 | 说明 |
|---|---|---|
| PaddleOCRAdapter | PaddleOCR | 当前实现（中文识别好，百度开源） |
| EasyOCRAdapter | EasyOCR | 多语言支持，安装简单 |
| MMOCRAdapter | OpenMMLab MMOCR | 学术研究用，模型丰富 |
| TesseractAdapter | Tesseract | 老牌 OCR，CPU 推理，无需 GPU |
| RapidOCRAdapter | RapidOCR | ONNX 推理，轻量快速 |

---

## 五、依赖关系

- **被依赖**：M5 文字识别模块（通过 OCRAdapter 接口调用）
- **依赖**：无（隔离第三方库）
- **第三方依赖**：PaddleOCR（当前实现）、Pillow（图片尺寸读取）、paddlepaddle-gpu（GPU 显存管理）
