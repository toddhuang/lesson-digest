# M15 语音识别适配层 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M15
> 模块职责：定义统一 ASR 接口，封装具体 ASR 引擎，隔离第三方库变化

---

## 一、模块概述

语音识别适配层采用**适配器模式（Adapter Pattern）**，定义统一的 ASR 调用接口，封装具体 ASR 引擎的 API 差异。当前实现为 FunASR 适配器，将来更换 ASR 引擎（如 Whisper、SenseVoice）时只需新增适配器，核心业务代码（M4 语音识别模块）零修改。

---

## 二、统一接口定义

### 2.1 ASRAdapter（抽象基类）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List, Optional

@dataclass
class Sentence:
    start_time: float    # 起始时间（秒）
    end_time: float      # 结束时间（秒）
    text: str            # 识别文本（含标点）
    confidence: float    # 置信度（0-1）

class ASRAdapter(ABC):
    """语音识别适配器抽象基类"""

    @abstractmethod
    def load_model(self, config: dict) -> None:
        """加载 ASR 模型"""
        pass

    @abstractmethod
    def unload_model(self) -> None:
        """卸载模型，释放 GPU 显存"""
        pass

    @abstractmethod
    def transcribe(self, audio_path: str) -> List[Sentence]:
        """
        语音识别，返回带时间戳的句子列表

        Args:
            audio_path: 音频文件路径（WAV 格式，16kHz mono）

        Returns:
            句子列表，按时间排序
        """
        pass

    @abstractmethod
    def get_sampling_rate(self) -> int:
        """返回模型要求的采样率（Hz）"""
        pass

    @abstractmethod
    def get_device(self) -> str:
        """返回运行设备（cuda/cpu）"""
        pass
```

## 三、当前实现：FunASRAdapter

### 3.1 类定义

```python
class FunASRAdapter(ASRAdapter):
    """FunASR 语音识别适配器"""

    def __init__(self):
        self.model = None
        self.config = None
        self._sampling_rate = 16000
        self._device = "cuda"
```

### 3.2 load_model

**功能**：加载 FunASR 模型（识别 + 标点 + VAD）。

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | dict | 是 | 配置字典，包含 model、punc_model、vad_model、device、batch_size_s |

**配置项**：
| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| model | str | "paraformer-zh" | 识别模型名 |
| punc_model | str | "ct-punc" | 标点恢复模型名 |
| vad_model | str | "fsmn-vad" | 端点检测模型名 |
| device | str | "cuda" | 运行设备 |
| batch_size_s | int | 300 | 批处理大小（秒） |

**输出**：None

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| ModelLoadError | 模型加载失败 |
| ModelNotFoundError | 模型不存在 |

**FunASR 调用方式**：
```python
from funasr import AutoModel

self.model = AutoModel(
    model=config.get("model", "paraformer-zh"),
    punc_model=config.get("punc_model", "ct-punc"),
    vad_model=config.get("vad_model", "fsmn-vad"),
    device=config.get("device", "cuda"),
)
```

---

### 3.3 transcribe

**功能**：对音频文件进行语音识别。

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| audio_path | str | 是 | 音频文件路径（WAV，16kHz mono） |

**输出**：List[Sentence]

**FunASR 调用方式**：
```python
result = self.model.generate(
    input=audio_path,
    batch_size_s=self.config.get("batch_size_s", 300),
)
# 解析 result，转换为 List[Sentence]
```

**返回数据解析**：
FunASR 返回格式：
```python
[
  {
    "key": "audio.wav",
    "text": "识别文本",
    "timestamp": [[start_ms, end_ms], ...]  # 每个字的时间戳（毫秒）
  }
]
```

转换为 Sentence：
- 按标点符号分句
- 每个句子的 start_time = 第一个字的 start_ms / 1000
- 每个句子的 end_time = 最后一个字的 end_ms / 1000
- confidence = 1.0（FunASR 不返回句级置信度）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| ASRError | 识别失败 |
| ModelNotLoadedError | 模型未加载 |

---

### 3.4 unload_model

**功能**：卸载模型，释放 GPU 显存。

**实现方式**：
```python
import torch
del self.model
torch.cuda.empty_cache()
self.model = None
```

## 四、可扩展实现

将来更换 ASR 引擎时，只需实现 ASRAdapter 接口：

| 适配器 | 引擎 | 说明 |
|---|---|---|
| FunASRAdapter | FunASR | 当前实现（中文识别+标点+VAD） |
| WhisperAdapter | OpenAI Whisper | 多语言支持，英文识别更好 |
| SenseVoiceAdapter | 阿里 SenseVoice | 轻量级，速度快 |
| SherpaOnnxAdapter | Sherpa-ONNX | 离线推理，无需 GPU |

每个适配器只需实现 `load_model`、`unload_model`、`transcribe`、`get_sampling_rate`、`get_device` 五个方法。
