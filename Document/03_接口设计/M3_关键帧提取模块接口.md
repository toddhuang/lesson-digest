# M3 关键帧提取模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M3
> 模块职责：从视频中按间隔提取关键帧图片

---

## 一、模块概述

关键帧提取模块调用 ffmpeg 从视频中按固定间隔（默认 30 秒）提取关键帧图片（JPG/PNG），每张图片带时间戳。输出图片列表，缓存到本地支持断点续传。

---

## 二、接口列表

### 3.1 extract_frames

**功能**：从视频中按固定间隔提取关键帧，输出到指定目录。

**签名**：
```python
def extract_frames(
    video_path: str,
    output_dir: str,
    interval: int = 30,
    format: str = "jpg",
    quality: int = 90
) -> List[FrameInfo]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 输入视频文件路径 |
| output_dir | str | 是 | — | 输出图片目录 |
| interval | int | 否 | 30 | 抽帧间隔（秒） |
| format | str | 否 | "jpg" | 图片格式（jpg/png） |
| quality | int | 否 | 90 | JPG 质量（1-100），仅 jpg 有效 |

**输出**：List[FrameInfo]（关键帧信息列表，按时间排序）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFmpegError | ffmpeg 执行失败 |
| InvalidVideoError | 视频文件无视频流 |

---

### 3.2 extract_frame_at

**功能**：在视频指定时间点提取单帧图片（用于题目截图）。

**签名**：
```python
def extract_frame_at(
    video_path: str,
    timestamp: float,
    output_path: str,
    format: str = "jpg"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 输入视频文件路径 |
| timestamp | float | 是 | — | 提取时间点（秒） |
| output_path | str | 是 | — | 输出图片路径 |
| format | str | 否 | "jpg" | 图片格式 |

**输出**：str（输出图片路径）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFmpegError | ffmpeg 执行失败 |
| TimestampOutOfRangeError | 时间戳超出视频时长 |

## 三、数据结构

### 3.1 FrameInfo（dataclass）

```python
@dataclass
class FrameInfo:
    path: str           # 图片文件路径
    timestamp: float    # 帧在视频中的时间点（秒）
    format: str         # 图片格式（jpg/png）
    size_bytes: int     # 文件大小（字节）
    width: int          # 图片宽度（像素）
    height: int         # 图片高度（像素）
```

## 四、第三方库调用

### 4.1 ffmpeg（命令行调用）

**按间隔抽帧命令**：
```bash
ffmpeg -i {video_path} -vf "fps=1/{interval}" -q:v {quality} {output_dir}/frame_%06d.{format} -y
```

**参数说明**：
- `-vf "fps=1/{interval}"`：设置帧率为每 interval 秒一帧
- `-q:v {quality}`：设置 JPG 质量（2-31，值越小质量越高，这里做了映射）
- `frame_%06d.{format}`：输出文件名格式，6位数字序号

**单帧提取命令**：
```bash
ffmpeg -ss {timestamp} -i {video_path} -vframes 1 -q:v {quality} {output_path} -y
```

**参数说明**：
- `-ss {timestamp}`：定位到指定时间点
- `-vframes 1`：只提取一帧

### 4.2 Python 调用方式

使用 `subprocess.run()` 调用 ffmpeg，提取后用 PIL/Pillow 获取图片尺寸。
