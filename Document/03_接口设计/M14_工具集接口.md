> 所属文档：02_架构设计.md
> 模块编号：M14
> 模块职责：通用工具函数（token计数、时间戳格式化、视频信息探测、日志）

## 一、模块概述

工具集模块提供系统通用的工具函数，包括 token 计数、时间戳格式化、视频信息探测、日志配置等。被多个模块共享使用，不包含业务逻辑。

---

## 二、接口列表

### 14.1 count_tokens

**功能**：统计文本的 token 数。

**签名**：
```python
def count_tokens(text: str, model: str = "qwen") -> int
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| text | str | 是 | — | 待统计文本 |
| model | str | 否 | "qwen" | 模型名（不同模型 tokenizer 不同） |

**输出**：int（token 数）

**实现说明**：使用 tiktoken 或模型对应的 tokenizer。Qwen 模型使用 tiktoken 的 cl100k_base 近似。

---

### 14.2 format_timestamp

**功能**：将秒数格式化为时间戳字符串。

**签名**：
```python
def format_timestamp(seconds: float, fmt: str = "mm:ss") -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| seconds | float | 是 | — | 秒数 |
| fmt | str | 否 | "mm:ss" | 格式："mm:ss" / "hh:mm:ss" |

**输出**：str（格式化后的时间戳字符串）

**示例**：
- `format_timestamp(95.5)` → `"01:35"`
- `format_timestamp(3661, "hh:mm:ss")` → `"01:01:01"`

---

### 14.3 parse_timestamp

**功能**：将时间戳字符串解析为秒数。

**签名**：
```python
def parse_timestamp(timestamp_str: str) -> float
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| timestamp_str | str | 是 | 时间戳字符串（"mm:ss" 或 "hh:mm:ss"） |

**输出**：float（秒数）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| InvalidTimestampError | 时间戳格式无效 |

**示例**：
- `parse_timestamp("01:35")` → `95.0`
- `parse_timestamp("01:01:01")` → `3661.0`

---

### 14.4 probe_video

**功能**：探测视频文件信息（时长、分辨率、帧率、音轨编码等）。

**签名**：
```python
def probe_video(video_path: str) -> VideoInfo
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 视频文件路径 |

**输出**：VideoInfo（视频信息对象）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFprobeError | ffprobe 执行失败 |
| InvalidVideoError | 不是有效的视频文件 |

---

### 14.5 setup_logger

**功能**：配置日志记录器。

**签名**：
```python
def setup_logger(
    name: str,
    log_dir: str = "./logs",
    level: str = "INFO",
    console_output: bool = True
) -> logging.Logger
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| name | str | 是 | — | 日志记录器名称 |
| log_dir | str | 否 | "./logs" | 日志文件目录 |
| level | str | 否 | "INFO" | 日志级别（DEBUG/INFO/WARNING/ERROR） |
| console_output | bool | 否 | True | 是否同时输出到控制台 |

**输出**：logging.Logger（日志记录器对象）

---

### 14.6 ensure_dir

**功能**：确保目录存在，不存在则创建。

**签名**：
```python
def ensure_dir(dir_path: str) -> None
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| dir_path | str | 是 | 目录路径 |

**输出**：None

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| DirectoryCreateError | 目录创建失败 |

---

### 14.7 file_hash

**功能**：计算文件的 MD5 哈希（用于缓存键）。

**签名**：
```python
def file_hash(file_path: str, algorithm: str = "md5") -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| file_path | str | 是 | — | 文件路径 |
| algorithm | str | 否 | "md5" | 哈希算法（md5/sha1/sha256） |

**输出**：str（哈希值十六进制字符串）

**异常**：FileNotFoundError

## 三、数据结构

### 3.1 VideoInfo（dataclass）

```python
@dataclass
class VideoInfo:
    path: str              # 文件路径
    duration: float        # 时长（秒）
    width: int             # 宽度（像素）
    height: int            # 高度（像素）
    fps: float             # 帧率
    video_codec: str       # 视频编码
    audio_codec: str       # 音频编码
    audio_channels: int    # 音频声道数
    audio_sample_rate: int # 音频采样率
    size_bytes: int        # 文件大小（字节）
    has_audio: bool        # 是否有音轨
    has_video: bool        # 是否有视频流
```

## 四、第三方库调用

### 4.1 tiktoken（token 计数）

```python
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
tokens = enc.encode(text)
return len(tokens)
```

### 4.2 ffprobe（视频信息探测）

```bash
ffprobe -v quiet -print_format json -show_format -show_streams {video_path}
```

使用 `subprocess.run()` 调用，解析 JSON 输出。
