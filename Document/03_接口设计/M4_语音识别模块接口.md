# M4 语音识别模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M4
> 模块职责：语音识别业务逻辑（批量处理、缓存、时间戳管理），通过适配层调用具体 ASR 引擎

---

## 一、模块概述

语音识别模块负责将音轨转换为带时间戳的逐字稿。包含批量处理、缓存管理、时间戳管理等业务逻辑。**不直接依赖 FunASR 的 API**，而是通过 M15 语音识别适配层调用具体 ASR 引擎。

---

## 二、接口列表

### 4.1 transcribe

**功能**：对音频文件进行语音识别，返回带时间戳的句子列表。

**签名**：
```python
def transcribe(
    audio_path: str,
    use_cache: bool = True
) -> List[Sentence]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| audio_path | str | 是 | — | 输入音频文件路径（WAV 格式） |
| use_cache | bool | 否 | True | 是否使用缓存（命中则跳过识别） |

**输出**：List[Sentence]（带时间戳的句子列表，按时间排序）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 音频文件不存在 |
| ASRError | ASR 引擎识别失败 |
| ModelLoadError | ASR 模型加载失败 |

---

### 4.2 transcribe_batch

**功能**：批量识别多个音频文件。

**签名**：
```python
def transcribe_batch(
    audio_paths: List[str],
    use_cache: bool = True
) -> List[List[Sentence]]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| audio_paths | List[str] | 是 | — | 音频文件路径列表 |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：List[List[Sentence]]（每个音频对应一个句子列表）

**异常**：同 transcribe

---

### 4.3 load_model

**功能**：加载 ASR 模型（通过适配层）。

**签名**：
```python
def load_model(config: ASRConfig) -> None
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | ASRConfig | 是 | ASR 配置（模型名、设备等） |

**输出**：None

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| ModelLoadError | 模型加载失败 |

---

### 4.4 unload_model

**功能**：卸载 ASR 模型，释放 GPU 显存。

**签名**：
```python
def unload_model() -> None
```

**输入参数**：无

**输出**：None

**异常**：无

## 三、数据结构

### 3.1 Sentence（dataclass）

```python
@dataclass
class Sentence:
    start_time: float    # 句子起始时间（秒）
    end_time: float      # 句子结束时间（秒）
    text: str            # 识别文本（含标点）
    confidence: float    # 置信度（0-1）
```

---

## 四、第三方库调用（通过适配层）

本模块**不直接调用** FunASR，而是通过 M15 语音识别适配层的统一接口调用：

```python
from adapters.asr_adapter import ASRAdapter, FunASRAdapter

# 通过适配层调用
adapter: ASRAdapter = FunASRAdapter()
adapter.load_model(config)
sentences = adapter.transcribe(audio_path)
```

适配层统一接口详见：`M15_语音识别适配层接口.md`

## 五、缓存机制

### 5.1 缓存键

```
cache_key = md5(audio_path + file_size + file_mtime + asr_model_name)
```

### 5.2 缓存格式

JSON 文件，存储于 `cache/asr/{cache_key}.json`：
```json
{
  "audio_path": "...",
  "model": "paraformer-zh",
  "sentences": [
    {"start_time": 0.0, "end_time": 3.5, "text": "...", "confidence": 0.95}
  ]
}
```
