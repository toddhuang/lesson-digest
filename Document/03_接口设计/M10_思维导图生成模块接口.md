# M10 思维导图生成模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M10
> 模块职责：基于全文本和知识点，生成课程知识结构（OPML 格式）

---

## 一、模块概述

思维导图生成模块调用 LLM（云端 DeepSeek），基于带时间戳的全文本和知识点列表，生成课程知识结构。输出标准 OPML 格式，可导入 XMind、幕布、MindMaster 等工具渲染，也可交给 AI 工具生成美观的思维导图。

---

## 二、接口列表

### 10.1 generate

**功能**：基于全文本和知识点列表，生成 OPML 格式的思维导图。

**签名**：
```python
def generate(
    full_text: str,
    knowledge_points: List[KnowledgePoint],
    video_title: str = "",
    use_cache: bool = True
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| full_text | str | 是 | — | 带时间戳的全文本 |
| knowledge_points | List[KnowledgePoint] | 是 | — | 知识点列表 |
| video_title | str | 否 | "" | 视频标题（作为思维导图根节点），为空则用"课程笔记" |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：str（OPML 格式的 XML 字符串）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| LLMError | LLM 调用失败 |
| LLMResponseParseError | LLM 返回结果解析失败 |
| OPMLValidationError | 生成的 OPML 格式校验失败 |

---

### 10.2 save_opml

**功能**：将 OPML 字符串保存为文件。

**签名**：
```python
def save_opml(opml_content: str, output_path: str) -> None
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| opml_content | str | 是 | OPML 格式字符串 |
| output_path | str | 是 | 输出文件路径（.opml） |

**输出**：None

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileWriteError | 文件写入失败 |

## 四、OPML 格式规范

### 4.1 OPML 2.0 结构

```xml
<?xml version="1.0" encoding="UTF-8"?>
<opml version="2.0">
  <head>
    <title>课程标题</title>
  </head>
  <body>
    <outline text="第一章 主题名">
      <outline text="1.1 知识点1" _note="时间戳: 05:23"/>
      <outline text="1.2 知识点2" _note="时间戳: 12:45"/>
    </outline>
    <outline text="第二章 主题名">
      ...
    </outline>
  </body>
</opml>
```

### 4.2 节点层级

- 第1层：章节（如"第一章 一元二次方程"）
- 第2层：知识点（如"1.1 定义"、"1.2 求根公式"）
- 第3层（可选）：子知识点或要点

### 4.3 时间戳标注

在知识点节点的 `_note` 属性中标注时间戳，格式：`时间戳: mm:ss`

## 五、LLM Prompt 设计

### 5.1 System Prompt

```
你是一个教学内容结构整理助手。请根据以下教学视频的全文本和知识点列表，生成课程知识结构的思维导图。

【要求】
1. 根据视频内容和知识点列表，整理出课程的章节结构
2. 每个章节下包含相关的知识点
3. 知识点名称使用知识点列表中的名称
4. 为每个知识点标注时间戳（在 _note 属性中）
5. 层级不超过3层
6. 输出标准 OPML 2.0 格式
7. 根节点标题使用提供的视频标题
8. 不要遗漏任何知识点

【输出格式】
标准 OPML 2.0 XML 格式，直接输出 XML，不要包含 Markdown 代码块标记。
```

### 5.2 User Prompt

```
【视频标题】{video_title}

【知识点列表】
{knowledge_points_formatted}

【视频全文本】
{full_text}
```

## 七、结果校验

### 7.1 XML 格式校验

使用 `xml.etree.ElementTree` 解析生成的 OPML，确保 XML 格式合法：
```python
import xml.etree.ElementTree as ET
try:
    root = ET.fromstring(opml_content)
except ET.ParseError as e:
    raise OPMLValidationError(f"OPML 格式校验失败: {e}")
```

### 7.2 结构校验

- 根节点必须是 `<opml version="2.0">`
- 必须包含 `<head>` 和 `<body>`
- `<body>` 下至少有一个 `<outline>` 节点
- 知识点节点必须有 `text` 属性

### 7.3 知识点完整性校验

- 所有输入的知识点都应出现在思维导图中
- 缺失的知识点记录警告日志
