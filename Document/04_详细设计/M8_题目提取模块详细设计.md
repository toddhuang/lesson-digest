## 三、核心流程

### 3.1 extract 流程

```
1. 计算缓存键
2. 缓存命中 → 加载缓存，返回
3. 构造 System Prompt（题目提取指令）
4. 构造 User Prompt（视频时长 + 全文本）
5. 调用 llm_client.chat(backend="cloud", temperature=0.1, max_tokens=8000)
6. 解析 LLM 返回的 JSON
7. 校验每道题的完整性（question_text 非空、solution_steps 非空、时间戳合法）
8. 按开始时间排序
9. 重新编号（index 从1开始）
10. 写入缓存
11. 返回 Problem 列表
```

### 3.2 LLM 调用

```python
response = self.llm.chat(
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": user_prompt}
    ],
    backend="cloud",  # 云端 DeepSeek，128K 上下文，强智力
    temperature=0.1,
    max_tokens=8000  # 题目提取输出较长
)
```

**为什么用云端**：题目提取是全文一次性语义判断，需要理解老师讲题的各种过渡语（"这道题""我们来看""去年考了"等），只有强模型能准确识别。本地 8K 上下文也可能不够。

## 四、Prompt 设计

### 4.1 System Prompt（完整版）

```
你是一个教学视频内容分析助手。请从以下带时间戳的教学视频全文本中，识别老师讲解的所有题目，并提取原题和解题步骤。

【识别要求】
1. 识别视频中老师讲解的所有题目（例题、习题、考试题、练习题等）
2. 老师引入题目的方式多样，注意语义判断：
   - "这道题""接下来这道题""我们来看这道题"
   - "某某地区的考试真题""去年中考考了这样一道题"
   - "例1""例题""练习"
   - 老师直接开始念题目内容
   不要遗漏任何题目
3. 为每道题标注开始时间和结束时间（格式 mm:ss）
4. 开始时间 = 老师开始引入或念题的时间
5. 结束时间 = 老师讲完这道题、开始下一题或切换话题的时间

【提取要求】
6. 提取原题文字：综合老师口述的题目内容 + PPT/板书上的题目文字（OCR文本）
7. 提取解题步骤：分步骤列出，每个步骤标注在视频中的时间戳
8. 标注题目是否含图（几何图、函数图、实验装置图、示意图等）
9. 含图题目简要描述图片内容（基于老师口述和OCR文本推断）
10. 如果老师提到题目来源（如"2023年上海中考题"），记录来源

【输出要求】
11. 按开始时间顺序输出
12. 输出严格的 JSON 数组格式，不要包含 Markdown 代码块标记，不要有其他文字
13. 如果视频中没有题目，输出空数组 []

【输出格式】
[
  {
    "index": 1,
    "start_time": "05:23",
    "end_time": "12:45",
    "question_text": "原题文字...",
    "solution_steps": [
      {"step_number": 1, "content": "步骤内容...", "timestamp": "06:10"},
      {"step_number": 2, "content": "步骤内容...", "timestamp": "08:30"}
    ],
    "has_image": true,
    "image_description": "直角三角形ABC，角C为直角...",
    "source": "2023年上海中考题",
    "confidence": 0.9
  }
]
```

### 5.2 题目完整性校验

```python
def validate_problem(problem: dict, video_duration: float) -> bool:
    # 原题文字非空
    if not problem.get("question_text", "").strip():
        logger.warning(f"题目 {problem.get('index')} 原题文字为空，跳过")
        return False
    # 解题步骤非空（允许老师只念题不讲解，但标记 has_solution=False）
    steps = problem.get("solution_steps", [])
    if not steps:
        logger.warning(f"题目 {problem.get('index')} 无解题步骤")
        problem["has_solution"] = False
    else:
        problem["has_solution"] = True
    # 时间戳校验
    try:
        start = parse_timestamp(problem["start_time"])
        end = parse_timestamp(problem["end_time"])
        if not (0 <= start <= video_duration and 0 <= end <= video_duration):
            logger.warning(f"题目 {problem['index']} 时间戳超出范围")
            return False
        if end <= start:
            logger.warning(f"题目 {problem['index']} 结束时间 <= 开始时间")
            return False
        problem["start_time_seconds"] = start
        problem["end_time_seconds"] = end
    except (InvalidTimestampError, KeyError):
        logger.warning(f"题目 {problem['index']} 无效时间戳")
        return False
    # 解题步骤时间戳校验
    for step in steps:
        try:
            ts = parse_timestamp(step["timestamp"])
            if not (start <= ts <= end):
                logger.warning(f"题目 {problem['index']} 步骤 {step['step_number']} 时间戳不在题目范围内")
        except (InvalidTimestampError, KeyError):
            pass  # 步骤时间戳无效不跳过题目，仅记录警告
    return True
```

```markdown
> 时间范围：[05:23 - 12:45]

## 原题

已知一元二次方程 x² - 5x + 6 = 0，求方程的两个根。

## 解题步骤

### 步骤1 [06:10]
判断方程是否可以因式分解。常数项6可以分解为2×3，且2+3=5，符合一次项系数。

### 步骤2 [08:30]
因式分解：(x-2)(x-3)=0

### 步骤3 [10:15]
解得：x₁=2，x₂=3
```

## 八、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| LLMError | LLM 调用失败 | 抛出，中断流水线 |
| LLMResponseParseError | 返回结果无法解析 | 抛出，记录原始响应 |
| EmptyResultError | 返回空数组 | 记录警告，返回空列表（视频可能无题目） |
