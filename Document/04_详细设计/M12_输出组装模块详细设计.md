### 2.1 OutputAssembler 类

```python
class OutputAssembler:
    def __init__(self, config: OutputConfig):
        self.config = config

    def assemble(self, result: ProcessResult, output_dir: str) -> OutputFiles
    def write_transcript(self, asr_results, output_path, timestamp_format="mm:ss") -> str
    def write_knowledge_list(self, knowledge_points, output_path, timestamp_format="mm:ss") -> str
    def write_problems(self, problems, screenshot_paths, output_dir, timestamp_format="mm:ss") -> List[str]
    def write_mindmap(self, opml_content, output_path) -> str
```

## 三、核心流程

### 3.1 assemble 流程

```
1. 从视频路径提取视频名（不含扩展名）作为输出子目录名
2. 构造输出目录结构：
   {output_dir}/{视频名}/
   ├── 01_逐字稿.md
   ├── 02_知识点清单.md
   ├── 03_思维导图.opml
   ├── 习题/
   └── 截图/
3. 确保所有目录存在
4. 调用 write_transcript() 生成逐字稿
5. 调用 write_knowledge_list() 生成知识点清单
6. 调用 write_problems() 生成习题文件（原题+解析+截图）
7. 调用 write_mindmap() 保存思维导图
8. 收集所有输出文件路径
9. 返回 OutputFiles
```

### 3.2 视频名提取

```python
import os

def get_video_name(video_path: str) -> str:
    base = os.path.basename(video_path)
    name, _ = os.path.splitext(base)
    return name
```

### 3.3 目录创建

```python
video_name = get_video_name(result.video_path)
```

## 四、各输出文件生成

### 4.1 逐字稿

调用 M6 的 `to_transcript()` 生成 Markdown 字符串，写入文件：

```markdown
# 逐字稿

> 视频：{视频名}
> 时长：{时长}
> 生成时间：{YYYY-MM-DD HH:MM:SS}

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
```

### 4.2 知识点清单

调用 M7 的 `to_markdown()` 生成：

```markdown
# 知识点清单

> 视频：{视频名}
> 知识点数量：{N}

1. 一元二次方程的定义 [05:23]
2. 配方法解一元二次方程 [12:45]
```

### 4.3 习题文件

遍历每道题，生成两个文件：

**原题文件**：`习题/题目{index:02d}_原题.md`
```markdown
# 题目01

> 时间范围：[05:23 - 12:45]
> 来源：2023年上海中考题
> 含图：是

## 原题

{原题文字}

## 题目截图

![题目01截图](../截图/题目01.png)
```

**解析文件**：`习题/题目{index:02d}_解析.md`
```markdown
# 题目01 解析

> 时间范围：[05:23 - 12:45]

## 原题

{原题文字}

## 解题步骤

### 步骤1 [06:10]
{步骤内容}
```

**截图处理**：
- 如果 `screenshot_paths[i]` 不为 None，将截图复制到 `截图/题目{index:02d}.png`
- 原题文件中引用相对路径 `../截图/题目{index:02d}.png`
- 截图为 None 时，原题文件不插入截图 section

### 4.4 思维导图

直接将 OPML 字符串写入 `03_思维导图.opml`。

## 七、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| DirectoryCreateError | 目录创建失败 | 抛出 |
| FileWriteError | 文件写入失败 | 抛出 |
| 无 | 部分模块结果为空 | 生成空内容文件（如无题目则不生成习题目录） |

### 7.1 空结果处理

- 无知识点：知识点清单文件内容为"本视频未识别到明确知识点"
- 无题目：不创建习题和截图目录
- 无思维导图：不生成 OPML 文件（或生成空 OPML）

## 八、性能考虑

- 纯文件操作，速度极快
- 截图复制是 IO 操作，10 张截图约 1-2 秒
- 总耗时通常 < 5 秒
