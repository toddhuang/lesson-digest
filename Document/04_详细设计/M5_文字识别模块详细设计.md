## 三、核心流程

### 3.1 recognize_batch 流程

```
1. 确保模型已加载
2. 遍历每张图片：
   a. 计算缓存键
   b. 缓存命中 → 加载缓存
   c. 缓存未命中 → 调用 adapter.recognize(image_path)
   d. 写入缓存
3. 将每张图片的 OCRResult 列表包装为 OCRFrameResult（含 timestamp、image_path、full_text）
4. 如果 dedup=True，执行相邻帧去重
5. 返回 OCRFrameResult 列表
```

### 3.2 full_text 生成

将单帧的所有 OCRResult 按阅读顺序合并为完整文本：

```python
def build_full_text(results: List[OCRResult]) -> str:
    # 按 y 坐标排序（从上到下），同一行按 x 坐标排序（从左到右）
    sorted_results = sorted(results, key=lambda r: (r.bounding_box[1], r.bounding_box[0]))
    lines = []
    current_line = []
    current_y = None

    for r in sorted_results:
        y = r.bounding_box[1]
        if current_y is None or abs(y - current_y) < 0.05:  # 同一行（5%容差）
            current_line.append(r.text)
        else:
            lines.append(" ".join(current_line))
            current_line = [r.text]
        current_y = y

    if current_line:
        lines.append(" ".join(current_line))
    return "\n".join(lines)
```

### 3.3 相邻帧去重

```python
from difflib import SequenceMatcher

def deduplicate(frames: List[OCRFrameResult], threshold=0.9) -> List[OCRFrameResult]:
    for i in range(1, len(frames)):
        prev_text = frames[i-1].full_text
        curr_text = frames[i].full_text
        if prev_text and curr_text:
            similarity = SequenceMatcher(None, prev_text, curr_text).ratio()
            if similarity > threshold:
                frames[i].is_duplicate = True
    return frames
```

## 四、PaddleOCR 返回数据解析

PaddleOCR `ocr.ocr()` 返回格式：

```python
[
  [
    [[28.0, 27.0], [172.0, 27.0], [172.0, 56.0], [28.0, 56.0]],  # 文本框四角坐标
    ("一元二次方程", 0.985)  # (文本, 置信度)
  ],
  ...
]
```

转换为 OCRResult：
- `text` = 识别文本
- `confidence` = 置信度
- `bounding_box` = [min_x/width, min_y/height, max_x/width, max_y/height]（归一化到 0-1）

## 六、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 图片文件不存在 | 抛出 |
| ModelLoadError | 模型加载失败 | 抛出 |
| OCRError | 识别失败 | 单帧失败时记录警告，返回空结果，不中断批量处理 |

### 6.1 单帧失败降级

批量识别时，单帧 OCR 失败不中断整个流程：
```python
try:
    results = self.adapter.recognize(image_path)
except OCRError as e:
    logger.warning(f"OCR 识别失败: {image_path}, 错误: {e}")
    results = []  # 降级为空结果
```

## 八、性能考虑

- PaddleOCR 在 RTX 3080 上，单帧识别约 0.2-0.5 秒
- 45分钟视频，30秒间隔 → 约90帧，总识别时间 20-45 秒
- MVP 阶段不做批量推理（PaddleOCR 的 batch 推理支持有限），逐帧识别
- 去重后实际输出的非重复帧通常只有 20-40 帧
