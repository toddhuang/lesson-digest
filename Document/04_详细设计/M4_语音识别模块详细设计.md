## 二、类设计

### 2.1 ASRRecognizer 类

```python
class ASRRecognizer:
    def __init__(self, config: ASRConfig, adapter: ASRAdapter = None):
        self.config = config
        self.adapter = adapter or FunASRAdapter()
        self._model_loaded = False
        self._cache_dir = "./cache/asr"

    def load_model(self) -> None
    def unload_model(self) -> None
    def transcribe(self, audio_path, use_cache=True) -> List[Sentence]
    def transcribe_batch(self, audio_paths, use_cache=True) -> List[List[Sentence]]
```

## 三、核心流程

### 3.1 transcribe 流程

```
1. 检查音频文件是否存在
2. 计算缓存键（md5(audio_path + file_size + file_mtime + model_name)）
3. use_cache=True 且缓存存在 → 加载缓存，直接返回
4. 确保模型已加载（未加载则调用 load_model()）
5. 调用 adapter.transcribe(audio_path)
6. 适配器返回 List[Sentence]
7. 写入缓存（JSON 格式）
8. 返回结果
```

### 3.2 load_model 流程

```
1. 构造配置 dict（从 ASRConfig 转换）
2. 调用 adapter.load_model(config)
3. 设置 _model_loaded = True
4. 记录日志：模型加载完成，设备=xxx
```

### 3.3 模型加载时机

- **懒加载**：第一次调用 transcribe() 时自动加载模型
- **显式加载**：流水线启动时可提前调用 load_model()，避免首次识别延迟
- GPU 显存管理：ASR 和 OCR 不同时加载（流水线中 ASR 完成后卸载，再加载 OCR）

### 4.1 分句策略

FunASR 的 `ct-punc` 标点模型会在文本中添加标点。按标点符号分句：

```python
import re

def split_sentences(text, timestamps):
    # 按句号、问号、感叹号分句
    sentence_endings = r'[。？！]'
    sentences = []
    current_text = ""
    current_start = timestamps[0][0] if timestamps else 0

    for i, char in enumerate(text):
        current_text += char
        if re.match(sentence_endings, char):
            current_end = timestamps[i][1] if i < len(timestamps) else current_start
            sentences.append(Sentence(
                start_time=current_start / 1000,  # 毫秒转秒
                end_time=current_end / 1000,
                text=current_text.strip(),
                confidence=1.0
            ))
            current_text = ""
            if i + 1 < len(timestamps):
                current_start = timestamps[i + 1][0]

    return sentences
```

## 六、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 音频文件不存在 | 抛出 |
| ModelLoadError | 模型加载失败 | 抛出，检查模型名和网络 |
| ASRError | 识别失败 | 抛出，含适配器错误信息 |
| ModelNotLoadedError | 模型未加载就调用 transcribe | 自动触发懒加载 |

## 七、GPU 显存管理

ASR 模型（paraformer-zh + punc + vad）约占 2-3GB 显存。

流水线中的显存管理策略：
1. ASR 阶段：加载 ASR 模型
2. ASR 完成后：调用 `unload_model()` 释放显存
3. OCR 阶段：加载 OCR 模型
4. OCR 完成后：卸载 OCR 模型
5. LLM 调用不占本地 GPU（vLLM 在 4090 上，DeepSeek 在云端）

---

## 八、性能考虑

- FunASR paraformer-zh 在 RTX 3080 上，45分钟音频识别约 2-5 分钟（实时率约 0.1x）
- 批量处理 `batch_size_s=300` 可提高 GPU 利用率
- MVP 阶段不做增量识别，整段音频一次性识别
