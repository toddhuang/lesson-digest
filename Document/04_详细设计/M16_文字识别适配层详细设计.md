## 二、抽象基类 OCRAdapter

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List

@dataclass
class OCRResult:
    text: str
    confidence: float
    bounding_box: List[float]  # [x1, y1, x2, y2] 归一化 0-1

class OCRAdapter(ABC):
    @abstractmethod
    def load_model(self, config: dict) -> None: ...

    @abstractmethod
    def unload_model(self) -> None: ...

    @abstractmethod
    def recognize(self, image_path: str) -> List[OCRResult]: ...

    @abstractmethod
    def get_device(self) -> str: ...
```

## 三、PaddleOCRAdapter 实现

### 3.1 类属性与初始化

```python
class PaddleOCRAdapter(OCRAdapter):
    def __init__(self):
        self.ocr = None
        self.config = {}
        self._device = "cuda"
```

### 3.2 load_model

```python
def load_model(self, config: dict) -> None:
    self.config = config
    self._device = "cuda" if config.get("use_gpu", True) else "cpu"

    from paddleocr import PaddleOCR
    self.ocr = PaddleOCR(
        use_angle_cls=config.get("use_angle_cls", True),
        lang=config.get("lang", "ch"),
        det_db_box_thresh=config.get("det_db_box_thresh", 0.5),
        use_gpu=config.get("use_gpu", True),
        show_log=False,
    )
```

**模型说明**：
- PaddleOCR 默认使用 PP-OCRv4 系列模型（检测+方向分类+识别）
- `use_angle_cls=True`：启用方向分类器（处理旋转文字）
- `lang="ch"`：中文模型
- `det_db_box_thresh`：检测框置信度阈值

### 3.3 recognize

```python
from PIL import Image

def recognize(self, image_path: str) -> List[OCRResult]:
    if self.ocr is None:
        raise ModelNotLoadedError("OCR 模型未加载")

    # 获取图片尺寸（用于坐标归一化）
    with Image.open(image_path) as img:
        width, height = img.size

    # PaddleOCR 识别
    result = self.ocr.ocr(image_path, cls=True)

    if not result or not result[0]:
        return []

    ocr_results = []
    for line in result[0]:
        box = line[0]  # [[x1,y1], [x2,y2], [x3,y3], [x4,y4]]
        text, confidence = line[1]

        # 计算边界框 [min_x, min_y, max_x, max_y]
        x_coords = [p[0] for p in box]
        y_coords = [p[1] for p in box]
        bounding_box = [
            min(x_coords) / width,
            min(y_coords) / height,
            max(x_coords) / width,
            max(y_coords) / height,
        ]

        ocr_results.append(OCRResult(
            text=text,
            confidence=confidence,
            bounding_box=bounding_box,
        ))

    return ocr_results
```

### 3.4 unload_model

```python
def unload_model(self) -> None:
    if self.ocr is not None:
        import paddle
        del self.ocr
        paddle.device.cuda.empty_cache()
        self.ocr = None
```

### 3.5 get_device

```python
def get_device(self) -> str:
    return self._device
```

## 四、适配器工厂

```python
def create_ocr_adapter(adapter_type: str, config: dict) -> OCRAdapter:
    adapters = {
        "paddleocr": PaddleOCRAdapter,
        # 后续新增适配器在此注册
    }
    if adapter_type not in adapters:
        raise ValueError(f"不支持的 OCR 适配器: {adapter_type}")
    adapter = adapters[adapter_type]()
    adapter.load_model(config)
    return adapter
```

## 五、坐标归一化说明

PaddleOCR 返回的是像素坐标，适配层将其归一化为 0-1 的相对坐标：

```
归一化 x = 像素 x / 图片宽度
归一化 y = 像素 y / 图片高度
```

这样做的好处：
1. 不同分辨率的图片结果可比较
2. 裁剪/缩放图片后坐标仍然有效
3. 存储和传输更简洁
