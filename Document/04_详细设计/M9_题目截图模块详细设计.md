## 三、核心流程

### 3.1 capture 流程（MVP 简化版）

```
1. 检查视频文件是否存在
2. 检查 timestamp 是否在视频时长范围内
3. 确保输出目录存在
4. 如果 crop_question_area=True：
   a. 构造带裁剪的 ffmpeg 命令（裁剪掉底部20%）
   b. 执行 ffmpeg
5. 否则：
   a. 构造普通单帧提取命令
   b. 执行 ffmpeg
6. 检查输出文件是否生成成功
7. 返回输出路径
```

### 3.2 带裁剪的 ffmpeg 命令

```python
cmd = [
    "ffmpeg",
    "-ss", str(timestamp),
    "-i", video_path,
    "-vframes", "1",
    "-vf", "crop=iw:ih*0.8:0:0",  # 裁剪：宽度不变，高度取顶部80%
    "-q:v", "2",
    "-y",
    output_path
]
```

### 3.3 capture_batch 流程

```
1. 确保输出目录存在
2. 遍历 problems：
   a. 构造输出文件名：题目{index:02d}.png
   b. 输出路径：{output_dir}/题目{index:02d}.png
   c. 调用 capture(video_path, problem.start_time, output_path)
   d. 收集输出路径
3. 返回路径列表
```

## 四、最佳帧选取（后续迭代，MVP 不实现）

### 4.1 算法设计

在 `[timestamp - window, timestamp + window]` 范围内每秒提取一帧，对每帧评分：

| 评分维度 | 权重 | 计算方式 |
|---|---|---|
| OCR 文字完整度 | 0.5 | 该帧 OCR 识别出的文字与题目文字的相似度 |
| 画面清晰度 | 0.3 | Laplacian 方差（模糊检测） |
| 时间接近度 | 0.2 | 1 - |frame_time - timestamp| / window |

选择得分最高的帧。

### 4.2 实现要点

- 需要调用 OCR 适配器快速识别（轻量模式，只识别不缓存）
- 画面清晰度用 OpenCV 的 Laplacian 方差
- MVP 阶段跳过此优化，直接在 timestamp 时间点提取

## 五、裁剪策略

### 5.1 为什么裁剪底部

- PPT 讲课视频：底部 20% 通常是老师人像、字幕条或水印
- 题目内容通常在画面中上部
- 裁剪后截图更聚焦题目，减少无关内容

### 5.2 可配置

裁剪比例通过配置项控制：
```python
crop_ratio = 0.8  # 保留顶部80%
crop_offset_y = 0  # 从顶部开始
```

### 5.3 板书视频

板书视频题目通常占满画面，可设置 `crop_question_area=False` 不裁剪。

## 七、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 视频文件不存在 | 抛出 |
| FFmpegError | ffmpeg 执行失败 | 抛出，含 stderr |
| TimestampOutOfRangeError | 时间戳超出视频时长 | 抛出，含有效范围 |

### 7.1 单题截图失败降级

批量截图时，单题失败不中断整个流程：
```python
try:
    path = self.capture(...)
except (FFmpegError, TimestampOutOfRangeError) as e:
    logger.warning(f"题目 {problem.index} 截图失败: {e}")
    path = None  # 标记为无截图
screenshot_paths.append(path)
```

输出组装时，截图路径为 None 的题目不插入截图引用。

## 八、性能考虑

- 单帧提取约 0.5-1 秒（ffmpeg seek + 解码）
- 10 道题约 5-10 秒
- MVP 阶段不做最佳帧选取（避免额外 OCR 开销）
