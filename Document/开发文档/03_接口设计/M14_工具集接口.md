## 一、模块概述

工具集模块提供系统通用的工具函数，包括 token 计数、时间戳格式化、视频信息探测、日志配置、ASR 纠错、图像预处理（颜色过滤）等。被多个模块共享使用，不包含业务逻辑。

## 二、接口列表

### 14.1 count_tokens

**功能**：统计文本的 token 数。

**签名**：
```python
def count_tokens(text: str, model: str = "cl100k_base") -> int
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| text | str | 是 | — | 待统计文本 |
| model | str | 否 | "cl100k_base" | tokenizer 名称（豆包/DeepSeek 均使用 cl100k_base） |

**输出**：int（token 数）

**实现说明**：使用 tiktoken 的 cl100k_base 编码。

---

### 14.2 format_timestamp

**功能**：将秒数格式化为时间戳字符串。

**签名**：
```python
def format_timestamp(seconds: float, fmt: str = "mm:ss") -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| seconds | float | 是 | — | 秒数 |
| fmt | str | 否 | "mm:ss" | 格式："mm:ss" / "hh:mm:ss" |

**输出**：str（格式化后的时间戳字符串）

**示例**：
- `format_timestamp(95.5)` → `"01:35"`
- `format_timestamp(3661, "hh:mm:ss")` → `"01:01:01"`

---

### 14.3 parse_timestamp

**功能**：将时间戳字符串解析为秒数。

**签名**：
```python
def parse_timestamp(timestamp_str: str) -> float
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| timestamp_str | str | 是 | 时间戳字符串（"mm:ss" 或 "hh:mm:ss"） |

**输出**：float（秒数）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| InvalidTimestampError | 时间戳格式无效 |

**示例**：
- `parse_timestamp("01:35")` → `95.0`
- `parse_timestamp("01:01:01")` → `3661.0`

### 14.8 correct_asr_text（ASR 纠错工具）

**功能**：用云端 LLM（默认豆包）对 ASR 逐字稿进行纠错，修正同音词错误。

**签名**：
```python
def correct_asr_text(
    sentences: List[Sentence],
    llm_client: LLMClient,
    backend: str = "cloud"
) -> List[Sentence]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| sentences | List[Sentence] | 是 | — | ASR 句子列表（带时间戳） |
| llm_client | LLMClient | 是 | — | LLM 客户端实例 |
| backend | str | 否 | "cloud" | LLM 后端（默认 cloud=豆包） |

**输出**：List[Sentence]（纠错后的句子列表，时间戳保持不变）

**纠错流程**：
1. 去掉时间戳，提取纯文本（减少 token，避免时间戳误导 LLM 断句）
2. 调用豆包 LLM 进行纠错（修正同音词错误，如"地物"→"生物"）
3. 将纠错后的纯文本按原句子拆分，加回时间戳
4. 返回纠错后的句子列表

**实现位置**：`utils/asr_corrector.py`

### 14.9 remove_color_keep_black（图像颜色过滤工具）

**功能**：去除图片中的彩色部分，只保留黑色印刷体文字（用于板书视频，题目黑色，老师手写彩色）。

**签名**：
```python
def remove_color_keep_black(
    image_path: str,
    output_path: str = None,
    saturation_threshold: int = 30,
    value_threshold: int = 50
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| image_path | str | 是 | — | 输入图片路径 |
| output_path | str | 否 | None | 输出图片路径，None 则覆盖原文件 |
| saturation_threshold | int | 否 | 30 | 饱和度阈值，低于此值视为非彩色（保留） |
| value_threshold | int | 否 | 50 | 亮度阈值，低于此值视为黑色（保留） |

**输出**：str（输出图片路径）

**处理逻辑**：
1. 将图片转换为 HSV 色彩空间
2. 高饱和度（彩色）且高亮度的像素 → 替换为白色（去除）
3. 低饱和度或低亮度的像素 → 保留（黑色印刷体）
4. 输出处理后的图片

**实现位置**：`utils/image_preprocess.py`
