# M12 输出组装模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M12
> 模块职责：将各模块结果格式化为输出文件，按规范目录组织，ASR 纠错后写入逐字稿

---

## 一、模块概述

输出组装模块将各模块的处理结果（逐字稿、知识点清单、习题、思维导图）格式化为输出文件，按规范目录结构组织到输出目录。是流水线的最后一个模块。

> **ASR 纠错**：逐字稿生成后，用云端 LLM（默认豆包）进行纠错，修正同音词错误（如"地物"→"生物"）。纠错后直接写入 `01_逐字稿.md`，不保留原始未纠错版本，不输出双版本对比。纠错失败时降级使用原始逐字稿。

> **截图处理说明**：题目截图由 M9 题目截图模块直接输出到 `{output_dir}/截图/` 目录（不经 cache），M12 只负责在原题 Markdown 文件中引用截图路径，不负责截图的生成和移动。

---

## 二、接口列表

### 12.1 assemble

**功能**：将所有处理结果组装为输出文件，保存到指定目录。

**签名**：
```python
def assemble(
    result: ProcessResult,
    output_dir: str
) -> OutputFiles
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| result | ProcessResult | 是 | 完整处理结果（含所有模块输出） |
| output_dir | str | 是 | 输出根目录 |

> 注：`OutputConfig` 在 `OutputAssembler` 构造函数中传入，不在 `assemble` 方法参数中。

**输出**：OutputFiles（输出文件路径列表）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileWriteError | 文件写入失败 |
| DirectoryCreateError | 目录创建失败 |

---

### 12.2 write_transcript（含 ASR 纠错）

**功能**：生成逐字稿 Markdown 文件。先生成原始逐字稿，然后用云端 LLM（豆包）纠错，纠错后直接写入文件。

**签名**：
```python
def write_transcript(
    asr_results: List[Sentence],
    output_path: str,
    timestamp_format: str = "mm:ss",
    enable_correction: bool = True
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| asr_results | List[Sentence] | 是 | — | ASR 语音识别结果 |
| output_path | str | 是 | — | 输出文件路径 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |
| enable_correction | bool | 否 | True | 是否启用 ASR 纠错（默认启用，豆包后端） |

**输出**：str（输出文件路径）

**纠错流程**：
1. 生成原始逐字稿（带时间戳）
2. 去掉时间戳，提取纯文本（减少 token，避免时间戳误导 LLM 断句）
3. 调用豆包 LLM 进行纠错（修正同音词错误）
4. 将纠错后的纯文本按原句子拆分，加回时间戳
5. 写入 `01_逐字稿.md`
6. 纠错失败时降级使用原始逐字稿

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |

| problems | List[Problem] | 是 | — | 题目列表 |

| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：List[str]（生成的文件路径列表）

## 三、数据结构

### 3.1 ProcessResult（dataclass）

```python
@dataclass
class ProcessResult:
    video_path: str                          # 视频文件路径
    video_info: VideoInfo                    # 视频元信息
    asr_results: List[Sentence]              # ASR 语音识别结果
    ocr_results: List[OCRFrameResult]       # OCR 文字识别结果（不混入逐字稿，供 M8/M9 使用）
    full_text: str                           # 纯 ASR 全文本
    knowledge_points: List[KnowledgePoint]   # 知识点列表
    problems: List[Problem]                  # 题目列表
    screenshot_paths: List[str]              # 题目截图路径列表
    mindmap_opml: str                        # 思维导图 OPML 内容
```

### 3.2 OutputFiles（dataclass）

```python
@dataclass
class OutputFiles:
    transcript_path: str          # 逐字稿路径（纠错后）
    knowledge_path: str           # 知识点清单路径
    mindmap_path: str             # 思维导图路径
    problem_files: List[str]      # 习题文件路径列表
    output_dir: str               # 输出根目录
```

### 3.3 OutputConfig（dataclass）

```python
@dataclass
class OutputConfig:
    transcript_filename: str = "01_逐字稿.md"
    knowledge_filename: str = "02_知识点清单.md"
    mindmap_filename: str = "03_思维导图.opml"
    problems_dirname: str = "习题"
    screenshots_dirname: str = "截图"
    timestamp_format: str = "mm:ss"
    asr_correction_enabled: bool = True  # 是否启用 ASR 纠错（豆包后端）
```

## 四、输出目录结构

```
{output_dir}/{视频名}/
├── 01_逐字稿.md          （豆包纠错后）
├── 02_知识点清单.md       （含核心内容 + 补充内容）
├── 03_思维导图.opml
├── 习题/

│   ├── 题目02.md
│   └── ...
└── 截图/
    ├── 题目01.png
    ├── 题目02.png
    └── ...
```

## 五、文件格式规范

### 5.1 逐字稿格式

```markdown
# 逐字稿

> 视频：{视频名}
> 时长：{时长}
> 生成时间：{时间}
> ASR 纠错：已启用（豆包）

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
```

### 5.2 知识点清单格式

```markdown
# 知识点清单

> 视频：{视频名}
> 知识点数量：{N}

1. 一元二次方程的定义 [05:23]
2. 配方法解一元二次方程 [12:45]
3. 求根公式推导 [20:10]
4. 判别式与根的关系 [28:30]
```

### 5.3 原题文件格式

```markdown
# 题目01

> 时间范围：[05:23 - 12:45]
> 来源：2023年上海中考题
> 含图：是
> 原题来源：OCR 印刷体

## 原题

{原题文字}

## 题目截图

![题目01截图](../截图/题目01.png)
```

### 5.4 解析文件格式

```markdown
# 题目01 解析

> 时间范围：[05:23 - 12:45]

## 原题

{原题文字}

## 解题步骤

### 步骤1 [06:10]
{步骤内容}

### 步骤2 [08:30]
{步骤内容}

...
```
