# M7 知识点提取模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M7
> 模块职责：基于全文本，识别视频中的知识点并标注时间戳

---

## 一、模块概述

知识点提取模块调用 LLM（云端 DeepSeek），基于带时间戳的全文本识别视频中讲解的所有知识点，为每个知识点标注起始时间戳。输出极简的知识点清单，不做过度解读，不标注重点难点。

---

## 二、接口列表

### 7.1 extract

**功能**：从全文本中提取知识点列表，每个知识点带起始时间戳。

**签名**：
```python
def extract(
    full_text: str,
    video_duration: float,
    use_cache: bool = True
) -> List[KnowledgePoint]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| full_text | str | 是 | — | 带时间戳的全文本（ASR+OCR 合并） |
| video_duration | float | 是 | — | 视频总时长（秒），用于校验时间戳 |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：List[KnowledgePoint]（知识点列表，按时间戳排序）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| LLMError | LLM 调用失败 |
| LLMResponseParseError | LLM 返回结果解析失败 |
| EmptyResultError | LLM 返回空结果 |

---

### 7.2 to_markdown

**功能**：将知识点列表转换为 Markdown 格式（用于输出文件）。

**签名**：
```python
def to_markdown(
    knowledge_points: List[KnowledgePoint],
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| knowledge_points | List[KnowledgePoint] | 是 | — | 知识点列表 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：str（Markdown 格式的知识点清单）

**异常**：无

---

## 三、数据结构

### 3.1 KnowledgePoint（dataclass）

```python
@dataclass
class KnowledgePoint:
    index: int           # 序号（从1开始）
    name: str            # 知识点名称（极简，1-2句话）
    start_time: float    # 起始时间戳（秒）
    confidence: float    # 置信度（0-1），LLM 自评
```

## 四、LLM Prompt 设计

### 4.1 System Prompt

```
你是一个教学视频内容分析助手。请从以下带时间戳的教学视频全文本中，识别老师讲解的所有知识点。

【要求】
1. 识别视频中讲解的所有知识点（定义、定理、公式、方法、概念等）
2. 为每个知识点标注在视频中的起始时间戳
3. 知识点名称要极简，1-2句话概括，不做详细解释
4. 不标注重点、难点、考点（不同学生掌握程度不同）
5. 不遗漏任何知识点
6. 按时间戳顺序输出
7. 输出 JSON 格式，便于程序解析

【输出格式】
[
  {"index": 1, "name": "知识点名称", "start_time": "05:23", "confidence": 0.9},
  ...
]
```

### 4.2 User Prompt

```
【视频时长】{video_duration} 秒

【视频全文本】
{full_text}
```

## 五、LLM 调用方式

通过 M11 LLM 客户端模块调用，后端选择 `cloud`（云端 DeepSeek，128K 上下文）：

```python
from core.llm_client import LLMClient

llm_client = LLMClient(config)
response = llm_client.chat(
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": user_prompt}
    ],
    backend="cloud",
    temperature=0.1,  # 低温度，保证稳定性
    max_tokens=4000
)
```

## 六、结果解析与校验

### 6.1 JSON 解析

LLM 返回的文本可能包含 Markdown 代码块标记，需要先清理再解析：
```python
import json, re

# 清理 Markdown 代码块标记
clean_text = re.sub(r'```json\s*', '', response.content)
clean_text = re.sub(r'```\s*', '', clean_text)
data = json.loads(clean_text)
```

### 6.2 时间戳校验

- 时间戳格式：`mm:ss` 或 `hh:mm:ss`
- 转换为秒后校验：`0 <= start_time <= video_duration`
- 超出范围的时间戳标记为无效，记录警告日志

### 6.3 去重

- 相同名称的知识点只保留最早的时间戳
- 名称相似度 > 0.8 的知识点合并

### 7.2 缓存格式
