# M9 题目截图模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M9
> 模块职责：根据题目提取结果，在视频中截取题目画面

---

## 一、模块概述

题目截图模块根据题目提取模块返回的题目开始时间，在视频中该时间点 ±5秒 范围内选取最佳帧，裁剪题目区域（排除老师人像等无关区域），输出题目截图图片文件。截图作为原题文件的参考附件，不追求 100% 准确。

---

## 二、接口列表

### 9.1 capture

**功能**：在视频指定时间点附近截取题目画面。

**签名**：
```python
def capture(
    video_path: str,
    timestamp: float,
    output_path: str,
    window: int = 5,
    crop_question_area: bool = True
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 视频文件路径 |
| timestamp | float | 是 | — | 题目开始时间（秒） |
| output_path | str | 是 | — | 输出图片路径 |
| window | int | 否 | 5 | 搜索窗口（秒），在 timestamp±window 范围内选最佳帧 |
| crop_question_area | bool | 否 | True | 是否裁剪题目区域（排除老师人像） |

**输出**：str（输出图片路径）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFmpegError | ffmpeg 执行失败 |
| TimestampOutOfRangeError | 时间戳超出视频时长 |

---

### 9.2 capture_batch

**功能**：批量截取多道题目的截图。

**签名**：
```python
def capture_batch(
    video_path: str,
    problems: List[Problem],
    output_dir: str,
    window: int = 5
) -> List[str]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 视频文件路径 |
| problems | List[Problem] | 是 | — | 题目列表 |
| output_dir | str | 是 | — | 输出图片目录 |
| window | int | 否 | 5 | 搜索窗口（秒） |

**输出**：List[str]（截图路径列表，与 problems 一一对应）

**异常**：同 capture

## 四、最佳帧选取算法

### 4.1 候选帧生成

在 `[timestamp - window, timestamp + window]` 范围内，每秒提取一帧，生成候选帧列表（最多 2*window+1 帧）。

### 4.2 最佳帧评分

对每个候选帧进行评分，选择得分最高的帧：

| 评分维度 | 权重 | 说明 |
|---|---|---|
| OCR 文字完整度 | 0.5 | 帧中题目文字越完整得分越高（通过 M5 OCR 适配层快速识别） |
| 画面清晰度 | 0.3 | 无模糊、无运动模糊 |
| 时间接近度 | 0.2 | 越接近 timestamp 得分越高 |

### 4.3 简化版（MVP）

MVP 阶段可简化为：在 `timestamp` 时间点直接提取一帧，不做最佳帧选取。后续迭代再加入评分算法。

## 五、题目区域裁剪

### 5.1 裁剪策略

- PPT 讲课视频：题目通常在画面中上部，裁剪掉底部 20%（可能有老师人像或字幕）
- 板书视频：题目通常占满画面，不裁剪或轻微裁剪边缘
- 裁剪比例可配置

### 5.2 裁剪命令（ffmpeg）

```bash
ffmpeg -ss {timestamp} -i {video_path} -vframes 1 -vf "crop=iw:ih*0.8:0:0" {output_path} -y
```

参数说明：
- `crop=iw:ih*0.8:0:0`：裁剪宽度=原宽度，高度=原高度的80%，起始点=(0,0)即顶部

## 六、第三方库调用

### 6.1 ffmpeg（单帧提取）

```bash
ffmpeg -ss {timestamp} -i {video_path} -vframes 1 -q:v 2 {output_path} -y
```

### 6.2 Python 调用方式

使用 `subprocess.run()` 调用 ffmpeg，详见 M3 关键帧提取模块。
