# M9 题目截图模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M9
> 模块职责：根据题目提取结果，在视频中截取题目画面

---

## 一、模块概述

题目截图模块根据题目提取模块返回的题目开始时间，在视频中该时间点提取单帧图片，作为原题文件的参考附件。截图不追求 100% 准确，仅作兜底参考。

> **MVP 范围**：直接在题目开始时间点提取单帧，不做最佳帧选取、不做画面裁剪。最佳帧选取（OCR评分+清晰度+时间接近度）列为 P2 迭代。

---

## 二、接口列表

### 9.1 capture

**功能**：在视频指定时间点提取单帧图片。

**签名**：
```python
def capture(
    video_path: str,
    timestamp: float,
    output_path: str
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 视频文件路径 |
| timestamp | float | 是 | 题目开始时间（秒） |
| output_path | str | 是 | 输出图片路径（直接输出到最终目录，不经 cache） |

**输出**：str（输出图片路径）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 视频文件不存在 |
| FFmpegError | ffmpeg 执行失败 |
| TimestampOutOfRangeError | 时间戳超出视频时长 |

---

### 9.2 capture_batch

**功能**：批量截取多道题目的截图，直接输出到指定目录。

**签名**：
```python
def capture_batch(
    video_path: str,
    problems: List[Problem],
    output_dir: str
) -> List[str]
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 视频文件路径 |
| problems | List[Problem] | 是 | 题目列表 |
| output_dir | str | 是 | 输出图片目录（最终输出目录下的"截图"子目录） |

**输出**：List[str]（截图路径列表，与 problems 一一对应，失败的为 None）

**异常**：同 capture（单题失败不中断批量处理，返回 None）

## 三、数据结构

本模块无特殊数据结构，使用 M8 模块定义的 `Problem` 数据结构（见 `00_数据模型.md`）。

---

## 四、第三方库调用

### 4.1 ffmpeg（单帧提取）

```bash
ffmpeg -ss {timestamp} -i {video_path} -vframes 1 -q:v 2 {output_path} -y
```

参数说明：
- `-ss {timestamp}`：定位到指定时间点（快速 seek 模式）
- `-vframes 1`：只提取一帧
- `-q:v 2`：JPG 高质量（2=最高质量）

## 六、P2 迭代规划（非 MVP）

以下功能在 MVP 阶段不实现，列为 P2 迭代：

| 功能 | 说明 |
|---|---|
| 最佳帧选取 | 在 timestamp±5秒 范围内，按 OCR 文字完整度(0.5) + 画面清晰度(0.3) + 时间接近度(0.2) 评分选最佳帧 |
| 题目区域裁剪 | 基于 OCR 文本框位置自动计算裁剪区域，排除老师人像等无关区域 |
| 场景变化检测 | 检测题目开始时间点附近是否有 PPT 翻页，选择翻页后的稳定帧 |
