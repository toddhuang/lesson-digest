# M16 文字识别适配层 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M16
> 模块职责：定义统一 OCR 接口，封装具体 OCR 引擎，隔离第三方库变化

---

## 一、模块概述

文字识别适配层采用**适配器模式（Adapter Pattern）**，定义统一的 OCR 调用接口，封装具体 OCR 引擎的 API 差异。当前实现为 PaddleOCR 适配器，将来更换 OCR 引擎（如 EasyOCR、MMOCR、Tesseract）时只需新增适配器，核心业务代码（M5 文字识别模块）零修改。

---

## 二、统一接口定义

### 2.1 OCRAdapter（抽象基类）

```python
from abc import ABC, abstractmethod
from typing import List

# OCRResult 数据结构统一定义见 00_数据模型.md 第 2.2 节

class OCRAdapter(ABC):
    """文字识别适配器抽象基类"""

    @abstractmethod
    def load_model(self, config: dict) -> None:
        """加载 OCR 模型"""
        pass

    @abstractmethod
    def unload_model(self) -> None:
        """卸载模型，释放 GPU 显存"""
        pass

    @abstractmethod
    def recognize(self, image_path: str) -> List[OCRResult]:
        """
        文字识别，返回识别结果列表

        Args:
            image_path: 图片文件路径

        Returns:
            识别结果列表，按阅读顺序排序
        """
        pass
```

## 三、当前实现：两引擎并行（R-008 定案）

R-008 定案：PP-OCRv6（文字）+ PP-FormulaNet（公式）两引擎并行，OCR 只是"线索提供者"，LLM 才是最终识别器（手写碎片交 LLM 补全）。两引擎均继承 `OCRAdapter`，由 M5 文字识别模块（`core/ocr.py`）并行调用后合并结果。

### 3.1 PaddleOCRAdapter（PP-OCRv6 识文字）

```python
class PaddleOCRAdapter(OCRAdapter):
    """PaddleOCR 3.x 适配器，使用 PP-OCRv6 检测+识别模型"""

    def __init__(self):
        self._ocr = None
        self._config = {}
```

**load_model 配置项**：
| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| text_detection_model_name | str | "PP-OCRv6_small_det" | 文字检测模型 |
| text_recognition_model_name | str | "PP-OCRv6_small_rec" | 文字识别模型 |

**PaddleOCR 3.x 调用方式**：
```python
from paddleocr import PaddleOCR

self._ocr = PaddleOCR(
    text_detection_model_name=det_model,
    text_recognition_model_name=rec_model,
    use_textline_orientation=False,
    use_doc_orientation_classify=False,
    use_doc_unwarping=False,
)
```

**recognize 输出**：`List[OCRResult]`，`block_type=text/handwritten`（印刷体直接用，手写碎片置信度偏低）。

### 3.2 FormulaNetAdapter（PP-FormulaNet 识公式→LaTeX）

```python
class FormulaNetAdapter(OCRAdapter):
    """PP-FormulaNet 公式识别适配器（PaddleOCR 3.x）"""

    def __init__(self):
        self._pipeline = None
        self._config = {}
```

**load_model 配置项**：
| 键 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| formula_model_name | str | "PP-FormulaNet_plus-M" | 公式识别模型 |

**PaddleOCR 3.x 调用方式**：
```python
from paddleocr import FormulaRecognitionPipeline

self._pipeline = FormulaRecognitionPipeline(
    formula_recognition_model_name=model_name,
    use_doc_orientation_classify=False,
    use_doc_unwarping=False,
)
```

**recognize 输出**：`List[OCRResult]`，含版面分类（`block_type=formula/title/text/image`）和公式 LaTeX（`block_type=formula` + `latex` 字段）。

### 3.3 unload_model（两引擎共用）

卸载模型，释放 GPU 显存：
```python
import paddle
del self._ocr  # 或 self._pipeline
paddle.device.cuda.empty_cache()
```

## 四、可扩展实现

| 适配器 | 引擎 | 说明 |
|---|---|---|
| PaddleOCRAdapter | PaddleOCR 3.x（PP-OCRv6） | **当前实现**（文字识别，R-008） |
| FormulaNetAdapter | PaddleOCR 3.x（PP-FormulaNet） | **当前实现**（公式→LaTeX，R-008） |
| EasyOCRAdapter | EasyOCR | 多语言支持，安装简单 |
| MMOCRAdapter | OpenMMLab MMOCR | 学术研究用，模型丰富 |
| TesseractAdapter | Tesseract | 老牌 OCR，CPU 推理，无需 GPU |
| RapidOCRAdapter | RapidOCR | ONNX 推理，轻量快速 |

---

## 五、依赖关系

- **被依赖**：M5 文字识别模块（通过 OCRAdapter 接口调用）
- **依赖**：无（隔离第三方库）
- **第三方依赖**：PaddleOCR（当前实现）、Pillow（图片尺寸读取）、paddlepaddle-gpu（GPU 显存管理）
