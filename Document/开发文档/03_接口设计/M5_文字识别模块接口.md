# M5 文字识别模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M5
> 模块职责：文字识别业务逻辑（两引擎并行、缓存、时间戳管理），通过适配层调用具体 OCR 引擎

---

## 一、模块概述

文字识别模块负责将关键帧图片中的文字和公式转换为带时间戳的文本。R-008 定案为**两引擎并行**：PP-OCRv6 识文字 + PP-FormulaNet 识公式（→LaTeX），OCR 只是"线索提供者"，手写碎片交 LLM 补全。**不直接依赖 PaddleOCR 的 API**，而是通过 M16 文字识别适配层调用具体 OCR 引擎。

> **颜色过滤预处理**（R-008 降级 P2 可选）：MVP 默认关闭（`enable_color_filter=False`），保留配置可开启。原设想去除彩色手写保留黑色印刷体，但 PPT 可能用彩色字体分章节，故 MVP 不启用。

> **帧去重**：dHash 去重已前置到 M3 关键帧提取模块（R-009，阈值 0.02），本模块仅做相邻帧 `full_text` 相等判定的轻量去重（标记 `is_duplicate`）。

---

## 二、接口列表

### 2.1 recognize_frames

**功能**：对关键帧列表进行文字识别（两引擎并行），返回每帧的识别结果。

**签名**：
```python
def recognize_frames(
    self,
    frame_paths: List[str],
    frame_timestamps: List[float],
    use_cache: bool = True
) -> List[OCRFrameResult]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| frame_paths | List[str] | 是 | — | 关键帧图片路径列表 |
| frame_timestamps | List[float] | 是 | — | 每张图片对应的视频时间戳（秒），与 frame_paths 一一对应 |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：`List[OCRFrameResult]`（每帧的识别结果，含时间戳、合并后的 full_text、is_duplicate 标记）

**流程**：
1. 懒加载两引擎适配器（`text_adapter` + `formula_adapter`，按 adapter_type 创建）
2. 逐帧处理：
   - 缓存命中 → 直接恢复 `OCRFrameResult`
   - 缓存未命中 → 颜色过滤预处理（若开启）→ 两引擎并行 `recognize` → 合并 `text_results + formula_results` → 生成 `full_text`（文字拼接 + 公式 LaTeX）→ 相邻帧 `full_text` 相等则 `is_duplicate=True`
3. 写入缓存（若 `use_cache=True`）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| OCRError | OCR 引擎识别失败 |
| ModelLoadError | OCR 模型加载失败 |

> **初始化参数**（构造函数）：`OCRRecognizer(text_adapter_type="paddleocr", formula_adapter_type="formula_net", config=Config, cache_dir="./cache/ocr")`。颜色过滤配置从 `config.ocr.enable_color_filter` 读取，默认 `False`。

## 四、第三方库调用（通过适配层）

本模块**不直接调用** PaddleOCR，而是通过 M16 文字识别适配层的统一接口调用：

```python
from adapters.ocr import create_ocr_adapter, OCRAdapter

text_adapter = create_ocr_adapter("paddleocr", text_config)       # PP-OCRv6 识文字
formula_adapter = create_ocr_adapter("formula_net", formula_config)  # PP-FormulaNet 识公式

text_results = text_adapter.recognize(frame_path)      # block_type=text/handwritten
formula_results = formula_adapter.recognize(frame_path)  # block_type=formula + latex
merged_results = text_results + formula_results
```

适配层统一接口详见：`M16_文字识别适配层接口.md`

## 五、帧去重策略

dHash 去重已前置到 M3 关键帧提取模块（R-009 定案，阈值 0.02），本模块不重复做图像级去重。

本模块的轻量去重：相邻两帧的 `full_text` 完全相等时，标记后一帧 `is_duplicate=True`，下游模块（如 M8 题目提取的 OCR 补充原题）可跳过重复帧。

```python
if results and results[-1].full_text == full_text:
    is_duplicate = True
```

## 六、缓存机制

### 6.1 缓存键

```
cache_key = md5(os.path.abspath(frame_path))[:16]
cache_path = f"{cache_dir}/{cache_key}.json"
```

### 6.2 缓存格式

JSON 文件，存储 `timestamp` / `image_path` / `results`（含 block_type / latex） / `full_text` / `is_duplicate`。
