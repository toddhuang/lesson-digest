# M5 文字识别模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M5
> 模块职责：文字识别业务逻辑（帧去重、缓存、时间戳管理），通过适配层调用具体 OCR 引擎

---

## 一、模块概述

文字识别模块负责将关键帧图片中的文字转换为带时间戳的文本。包含帧去重、缓存管理、时间戳管理、颜色过滤预处理等业务逻辑。**不直接依赖 PaddleOCR 的 API**，而是通过 M16 文字识别适配层调用具体 OCR 引擎。

> **颜色过滤预处理**：OCR 识别前应用 `remove_color_keep_black` 函数，去除彩色手写部分，只保留黑色印刷体文字（板书特征：题目黑色，老师手写彩色），减少干扰，提高 OCR 准确率。

---

## 二、接口列表

### 5.1 recognize

**功能**：对单张图片进行 OCR 识别，返回识别结果列表。

**签名**：
```python
def recognize(
    image_path: str,
    use_cache: bool = True
) -> List[OCRResult]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| image_path | str | 是 | — | 输入图片路径 |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：List[OCRResult]（识别结果列表）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 图片文件不存在 |
| OCRError | OCR 引擎识别失败 |
| ModelLoadError | OCR 模型加载失败 |

---

### 5.2 recognize_batch

**功能**：批量识别多张图片，自动去重（相邻帧相同文字只保留一次），识别前应用颜色过滤预处理。

**签名**：
```python
def recognize_batch(
    image_paths: List[str],
    timestamps: List[float],
    use_cache: bool = True,
    dedup: bool = True,
    enable_color_filter: bool = True
) -> List[OCRFrameResult]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| image_paths | List[str] | 是 | — | 图片路径列表 |
| timestamps | List[float] | 是 | — | 每张图片对应的视频时间戳（秒），与 image_paths 一一对应 |
| use_cache | bool | 否 | True | 是否使用缓存 |
| dedup | bool | 否 | True | 是否启用相邻帧去重 |
| enable_color_filter | bool | 否 | True | 是否启用颜色过滤（去除彩色手写，保留黑色印刷体） |

**输出**：List[OCRFrameResult]（每帧的识别结果，含时间戳）

**异常**：同 recognize

---

### 5.3 load_model

**功能**：加载 OCR 模型（通过适配层）。

**签名**：
```python
def load_model(config: OCRConfig) -> None
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | OCRConfig | 是 | OCR 配置 |

**输出**：None

**异常**：ModelLoadError

---

### 5.4 unload_model

**功能**：卸载 OCR 模型，释放 GPU 显存。

**签名**：
```python
def unload_model() -> None
```

## 三、数据结构

### 3.1 OCRResult（dataclass）

```python
@dataclass
class OCRResult:
    text: str                    # 识别文本
    confidence: float            # 置信度（0-1）
    bounding_box: List[float]    # 文本框坐标 [x1, y1, x2, y2]（相对坐标 0-1）
```

### 3.2 OCRFrameResult（dataclass）

```python
@dataclass
class OCRFrameResult:
    timestamp: float             # 帧在视频中的时间点（秒）
    image_path: str              # 图片路径
    results: List[OCRResult]    # 该帧的所有识别结果
    full_text: str               # 该帧所有文本合并（按阅读顺序）
    is_duplicate: bool           # 是否为重复帧（与前一帧文字相同）
```

## 四、第三方库调用（通过适配层）

本模块**不直接调用** PaddleOCR，而是通过 M16 文字识别适配层的统一接口调用：

```python
from adapters.ocr_adapter import OCRAdapter, PaddleOCRAdapter

adapter: OCRAdapter = PaddleOCRAdapter()
adapter.load_model(config)
results = adapter.recognize(image_path)
```

适配层统一接口详见：`M16_文字识别适配层接口.md`

## 五、帧去重算法

### 5.1 去重规则

相邻两帧的 `full_text` 相似度 > 0.9 时，标记后一帧为重复帧（`is_duplicate=True`），输出时只保留非重复帧。

### 5.2 相似度计算

使用文本相似度（如 `difflib.SequenceMatcher` 或 Jaccard 相似度）：
```python
similarity = SequenceMatcher(None, text_a, text_b).ratio()
```
