# M6 文本合并模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M6
> 模块职责：合并 ASR 和 OCR 结果，生成带时间戳的全文本

---

## 一、模块概述

文本合并模块将语音识别结果（ASR）和文字识别结果（OCR）按时间戳合并，生成统一的带时间戳全文本。全文本用于后续 LLM 处理（知识点提取、题目提取、思维导图生成）。

---

## 二、接口列表

### 6.1 merge

**功能**：合并 ASR 和 OCR 结果，按时间戳排序，生成合并文本列表。

**签名**：
```python
def merge(
    asr_results: List[Sentence],
    ocr_results: List[OCRFrameResult],
    include_ocr: bool = True
) -> List[MergedText]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| asr_results | List[Sentence] | 是 | — | ASR 语音识别结果 |
| ocr_results | List[OCRFrameResult] | 是 | — | OCR 文字识别结果（已去重） |
| include_ocr | bool | 否 | True | 是否包含 OCR 文本（逐字稿不包含，全文本包含） |

**输出**：List[MergedText]（合并后的文本列表，按时间戳排序）

**异常**：无

---

### 6.2 to_full_text

**功能**：将合并文本列表转换为带时间戳的全文本字符串（用于 LLM 输入）。

**签名**：
```python
def to_full_text(
    merged_texts: List[MergedText],
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| merged_texts | List[MergedText] | 是 | — | 合并文本列表 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式（mm:ss / hh:mm:ss） |

**输出**：str（全文本字符串，每条文本前标注时间戳和来源）

**异常**：无

---

### 6.3 to_transcript

**功能**：将 ASR 结果转换为逐字稿 Markdown 格式（不含 OCR）。

**签名**：
```python
def to_transcript(
    asr_results: List[Sentence],
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| asr_results | List[Sentence] | 是 | — | ASR 语音识别结果 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：str（逐字稿 Markdown 字符串）

**异常**：无

## 三、数据结构

### 3.1 MergedText（dataclass）

```python
@dataclass
class MergedText:
    timestamp: float       # 时间戳（秒）
    text: str              # 文本内容
    source: str            # 来源："asr" / "ocr"
    confidence: float      # 置信度（0-1）
```

## 四、全文本格式

### 4.1 LLM 输入格式

```
[00:00] [ASR] 今天我们来讲一元二次方程...
[00:30] [OCR] 一元二次方程 ax²+bx+c=0
[00:35] [ASR] 首先我们来看定义...
[01:00] [OCR] 求根公式 x = (-b±√(b²-4ac))/2a
...
```

### 4.2 逐字稿格式

```markdown
# 逐字稿

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
```

---

## 五、合并规则

### 5.1 排序规则

所有文本（ASR 和 OCR）按 `timestamp` 升序排序。同一时间戳的 ASR 文本排在 OCR 文本之前。

### 5.2 OCR 去重

OCR 结果已在 M5 模块完成相邻帧去重，合并时直接使用去重后的结果。

### 5.3 来源标记

每条文本标注来源（`[ASR]` / `[OCR]`），便于 LLM 区分语音内容和课件内容。
