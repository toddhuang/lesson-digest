# M6 文本整理模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M6
> 模块职责：整理 ASR 结果，生成带时间戳的纯 ASR 全文本（OCR 不混入，避免语句逻辑混乱）

---

## 一、模块概述

文本整理模块将语音识别结果（ASR）按时间戳整理，生成统一的带时间戳纯 ASR 全文本。全文本用于后续 LLM 处理（知识点提取、题目提取、思维导图生成）和逐字稿生成。

> **重要设计决策**：OCR 结果**不混入**全文本和逐字稿。原因：OCR 文本是课件文字，与老师讲解语音按时间戳混合后，LLM 难以区分哪些是老师说的、哪些是课件上的，会导致语句逻辑混乱。OCR 结果保留在 `result.ocr_results` 中，供 M8 题目提取（补充原题）和 M9 题目截图使用。

---

## 二、接口列表

### 6.1 organize

**功能**：整理 ASR 结果，按时间戳排序，生成整理后的文本列表。

**签名**：
```python
def organize(
    asr_results: List[Sentence]
) -> List[OrganizedText]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| asr_results | List[Sentence] | 是 | — | ASR 语音识别结果 |

**输出**：List[OrganizedText]（整理后的文本列表，按时间戳排序）

**异常**：无

---

### 6.2 to_full_text

**功能**：将整理后的文本列表转换为带时间戳的全文本字符串（用于 LLM 输入）。

**签名**：
```python
def to_full_text(
    organized_texts: List[OrganizedText],
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| organized_texts | List[OrganizedText] | 是 | — | 整理后的文本列表 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式（mm:ss / hh:mm:ss） |

**输出**：str（全文本字符串，每条文本前标注时间戳）

**异常**：无

---

### 6.3 to_transcript

**功能**：将 ASR 结果转换为逐字稿 Markdown 格式。

**签名**：
```python
def to_transcript(
    asr_results: List[Sentence],
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| asr_results | List[Sentence] | 是 | — | ASR 语音识别结果 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：str（逐字稿 Markdown 字符串）

**异常**：无

## 三、数据结构

### 3.1 OrganizedText（dataclass）

```python
@dataclass
class OrganizedText:
    timestamp: float       # 时间戳（秒）
    text: str              # 文本内容
    confidence: float      # 置信度（0-1）
```

---

## 四、全文本格式

### 4.1 LLM 输入格式

```
[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
...
```

> 注意：全文本只包含 ASR 结果，不包含 OCR 结果，不标注来源（因为全部是 ASR）。

### 4.2 逐字稿格式

```markdown
# 逐字稿

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
```

---

## 五、整理规则

### 5.1 排序规则

所有 ASR 句子按 `start_time` 升序排序。

### 5.2 空文本过滤

过滤掉空字符串或仅含空白字符的句子。
