# M8 题目提取模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M8
> 模块职责：基于全文本 + OCR 结果，识别所有题目，提取原题和解题步骤

---

## 一、模块概述

题目提取模块调用 LLM（云端，默认豆包），基于带时间戳的纯 ASR 全文本识别视频中老师讲解的所有题目。采用**全文一次性语义判断**，不硬编码关键词。提取每道题的开始时间、结束时间、原题文字、解题步骤，并标注题目是否含图。

> **重要设计决策**：结合 ASR + OCR 提取原题。ASR 可能把老师推导语音当成题目（如"地物里面你要研究公鸡和蛤蟆"实际是"生物里面你要研究公鸡和蛤蟆"），而 PPT/板书上的 OCR 印刷体题目更准确。因此，对每道题在时间范围内找 OCR 帧，用 OCR 印刷体题目补充/替换 ASR 原题。

> **MVP 设计原则**：质量优先，不考虑成本。全文本一次性传入云端 LLM（128K 上下文），不做分段、不做摘要压缩，保证全局视角不漏题。老师引入题目的方式多样，由 LLM 语义判断而非关键词匹配。

## 二、接口列表

### 8.1 extract

**功能**：从全文本中提取所有题目，返回结构化题目列表。

**签名**：
```python
def extract(
    full_text: str,
    video_duration: float,
    ocr_results: List[OCRFrameResult] = None,
    use_cache: bool = True
) -> List[Problem]
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| full_text | str | 是 | — | 带时间戳的纯 ASR 全文本（OCR 不混入） |
| video_duration | float | 是 | — | 视频总时长（秒） |
| ocr_results | List[OCRFrameResult] | 否 | None | OCR 文字识别结果，用于补充原题（印刷体题目更准确） |
| use_cache | bool | 否 | True | 是否使用缓存 |

**输出**：List[Problem]（题目列表，按开始时间排序）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| LLMError | LLM 调用失败 |
| LLMResponseParseError | LLM 返回结果解析失败 |
| EmptyResultError | LLM 返回空结果（视频中无题目） |

---

### 8.2 _enrich_with_ocr（内部方法）

**功能**：用 OCR 印刷体题目补充/替换 ASR 原题。

**签名**：
```python
def _enrich_with_ocr(
    problems: List[Problem],
    ocr_results: List[OCRFrameResult]
) -> List[Problem]
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| problems | List[Problem] | 是 | LLM 提取的题目列表（原题来自 ASR） |
| ocr_results | List[OCRFrameResult] | 是 | OCR 文字识别结果 |

**输出**：List[Problem]（补充 OCR 原题后的题目列表）

**处理逻辑**：
1. 对每道题，在 `[start_time, end_time]` 时间范围内找 OCR 帧
2. 从 OCR 帧中提取印刷体题目文字（应用颜色过滤后，只保留黑色印刷体）
3. 如果 OCR 题目比 ASR 题目更完整、更准确，用 OCR 题目替换 ASR 原题
4. 增加题目特征判断（必须含"求/已知/设/？/数学符号/选项"，排除知识点列表）
5. 增加完整性判断（必须包含题目开头关键词，不能以异常符号结尾）

### 8.3 to_question_markdown

**功能**：将单道题转换为原题 Markdown 格式（含截图引用）。

**签名**：
```python
def to_question_markdown(
    problem: Problem,
    screenshot_path: str = None,
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| problem | Problem | 是 | — | 题目对象 |
| screenshot_path | str | 否 | None | 题目截图路径（相对路径），无截图则为 None |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：str（原题 Markdown 字符串）

**异常**：无

---

### 8.4 to_solution_markdown

**功能**：将单道题转换为解析 Markdown 格式（含题目+解题步骤+时间戳）。

**签名**：
```python
def to_solution_markdown(
    problem: Problem,
    timestamp_format: str = "mm:ss"
) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| problem | Problem | 是 | — | 题目对象 |
| timestamp_format | str | 否 | "mm:ss" | 时间戳格式 |

**输出**：str（解析 Markdown 字符串）

**异常**：无

## 三、数据结构

### 3.1 Problem（dataclass）

```python
@dataclass
class Problem:
    index: int                    # 题号（从1开始）
    start_time: float             # 题目开始时间（秒）
    end_time: float               # 题目结束时间（秒）
    question_text: str            # 原题文字（优先使用 OCR 印刷体，ASR 作为补充）
    question_source: str          # 原题来源："ocr" / "asr" / "mixed"
    solution_steps: List[SolutionStep]  # 解题步骤列表
    has_image: bool               # 是否含图（几何图、函数图、实验装置图等）
    image_description: str        # 图片内容描述（LLM 基于文字推断）
    source: str                   # 题目来源（如"2023年中考题"，无则为空）
    confidence: float             # 置信度（0-1）
```

### 3.2 SolutionStep（dataclass）

```python
@dataclass
class SolutionStep:
    step_number: int              # 步骤序号（从1开始）
    content: str                  # 步骤内容
    timestamp: float              # 该步骤在视频中的时间戳（秒），存疑时可回看
```

## 四、LLM Prompt 设计

### 4.1 System Prompt

```
你是一个教学视频内容分析助手。请从以下带时间戳的教学视频全文本中，识别老师讲解的所有题目，并提取原题和解题步骤。

【要求】
1. 识别视频中老师讲解的所有题目（例题、习题、考试题等）
2. 老师引入题目的方式多样（"这道题""我们来看""去年考了"等），注意语义判断，不要遗漏
3. 为每道题标注开始时间和结束时间
4. 提取原题文字（老师口述的题目内容）
5. 提取解题步骤，分步骤列出，每个步骤标注时间戳
6. 标注题目是否含图（几何图、函数图、实验装置图等），并简要描述图片内容
7. 如果老师提到题目来源（如"2023年中考题"），记录来源
8. 按开始时间顺序输出
9. 输出 JSON 格式，便于程序解析

【输出格式】
[
  {
    "index": 1,
    "start_time": "05:23",
    "end_time": "12:45",
    "question_text": "原题文字...",
    "solution_steps": [
      {"step_number": 1, "content": "步骤内容...", "timestamp": "06:10"},
      ...
    ],
    "has_image": true,
    "image_description": "直角三角形ABC，角C为直角...",
    "source": "2023年上海中考题",
    "confidence": 0.9
  },
  ...
]
```

### 4.2 User Prompt

```
【视频时长】{video_duration} 秒

【视频全文本】
{full_text}
```

## 六、结果解析与校验

### 6.1 JSON 解析

同 M7 模块，清理 Markdown 代码块标记后解析 JSON。

### 6.2 时间戳校验

- `start_time` 和 `end_time` 必须在 `[0, video_duration]` 范围内
- `end_time` 必须 > `start_time`
- 解题步骤的 `timestamp` 必须在 `[start_time, end_time]` 范围内
- 无效时间戳标记为警告，不中断处理

### 6.3 题目完整性校验

- `question_text` 不能为空
- `solution_steps` 不能为空（老师只念题不讲解的情况标记为 `has_solution=False`）
- 含图题目必须有 `image_description`
- 题目特征判断：必须含"求/已知/设/？/数学符号/选项"，排除知识点列表
- 完整性判断：必须包含题目开头关键词，不能以异常符号结尾

### 6.4 OCR 原题补充

- 对每道题，在时间范围内找 OCR 帧
- 用 OCR 印刷体题目补充/替换 ASR 原题
- 记录 `question_source` 字段（"ocr"/"asr"/"mixed"）

## 七、缓存机制

### 7.1 缓存键


### 7.2 缓存格式

JSON 文件，存储于 `cache/problems/{cache_key}.json`。
