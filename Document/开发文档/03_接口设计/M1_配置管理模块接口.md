# M1 配置管理模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M1
> 模块职责：加载/校验配置，集中管理所有参数，支持多服务商配置

---

## 一、模块概述

配置管理模块负责加载 YAML 配置文件，校验配置参数合法性，提供统一的配置访问接口。管理敏感信息（API Key 从环境变量读取，不硬编码）。采用 `ConfigManager` 类式接口，支持点号路径访问。支持多 LLM 服务商配置（默认豆包，备选 DeepSeek），可通过 `default_provider` 切换。

---

## 二、接口列表

### 2.1 ConfigManager.load

**功能**：加载并解析 YAML 配置文件，返回 Config 对象。

**签名**：
```python
class ConfigManager:
    def load(self, config_path: str) -> Config
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config_path | str | 是 | 配置文件路径（YAML 格式） |

**输出**：Config 对象

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| FileNotFoundError | 配置文件不存在 |
| ConfigValidationError | 配置参数校验失败 |
| yaml.YAMLError | YAML 解析失败 |

---

### 2.2 ConfigManager.get

**功能**：获取配置项的值，支持点号路径访问（如 `config.get("llm.default_provider")`）。

**签名**：
```python
def get(self, key: str, default: Any = None) -> Any
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| key | str | 是 | 配置项键名，支持点号路径 |
| default | Any | 否 | 键不存在时返回的默认值 |

**输出**：配置项的值

**异常**：无（键不存在时返回 default）

---

### 2.3 ConfigManager.validate

**功能**：校验配置参数的合法性（必填项、类型、范围、依赖关系）。

**签名**：
```python
def validate(self, config: dict) -> bool
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | dict | 是 | 配置字典（YAML 解析后的原始字典） |

**输出**：bool（校验通过返回 True）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| ConfigValidationError | 校验失败，异常信息包含具体错误字段和原因 |

**校验规则**：
- `llm.default_provider`：必须是已注册的服务商（如 "volcengine"/"deepseek"）
- `llm.providers.{provider}.api_key`：必须存在（或对应环境变量已设置）
- `llm.providers.{provider}.base_url`：必须是合法 URL
- `video.frame_interval`：必须 > 0
- `output.timestamp_format`：必须是 "mm:ss" 或 "hh:mm:ss"
- `asr.adapter_type`：必须是已注册的适配器类型（如 "funasr"）
- `ocr.adapter_type`：必须是已注册的适配器类型（如 "paddleocr"）

## 三、数据结构

> 共享数据结构统一定义见 `00_数据模型.md`，此处仅列配置相关结构。

### 3.1 Config（dataclass）

```python
@dataclass
class Config:
    video: VideoConfig
    llm: LLMConfig
    asr: ASRConfig
    ocr: OCRConfig
    output: OutputConfig
    paths: PathsConfig
    cache: CacheConfig
```

### 3.2 子配置结构

```python
@dataclass
class VideoConfig:
    audio_sample_rate: int = 16000
    audio_channels: int = 1
    frame_interval: int = 30
    scene_change_detection: bool = False
    scene_change_threshold: float = 0.3

@dataclass
class LLMConfig:
    default_provider: str = "volcengine"  # 默认服务商：volcengine=豆包, deepseek=DeepSeek
    providers: Dict[str, LLMProviderConfig]  # 多服务商配置
    max_retries: int = 5
    connect_timeout: int = 10
    stream_chunk_timeout: int = 30
    cache_enabled: bool = True

@dataclass
class LLMProviderConfig:
    adapter_type: str  # 适配器类型："volcengine"/"deepseek"/"mock"
    base_url: str      # API 地址
    model: str         # 模型名（必须带日期后缀，如 doubao-seed-2-1-pro-260628）
    context_length: int = 131072  # 上下文长度
    api_key: str       # API Key（从环境变量读取，不硬编码）
    temperature: float = 0.3
    top_p: float = 0.9

@dataclass
class ASRConfig:
    adapter_type: str = "funasr"
    model: str = "paraformer-zh"
    punc_model: str = "ct-punc"
    vad_model: str = "fsmn-vad"
    batch_size_s: int = 300
    device: str = "cuda"

@dataclass
class OCRConfig:
    adapter_type: str = "paddleocr"
    use_angle_cls: bool = True
    lang: str = "ch"
    det_db_box_thresh: float = 0.5
    use_gpu: bool = True
    color_filter_enabled: bool = True  # 是否启用颜色过滤（去除彩色手写，保留黑色印刷体）

@dataclass
class OutputConfig:
    transcript_filename: str = "01_逐字稿.md"
    knowledge_filename: str = "02_知识点清单.md"
    mindmap_filename: str = "03_思维导图.opml"
    problems_dirname: str = "习题"
    screenshots_dirname: str = "截图"
    timestamp_format: str = "mm:ss"
    asr_correction_enabled: bool = True  # 是否启用 ASR 纠错（豆包后端）

@dataclass
class PathsConfig:
    cache_dir: str = "./cache"
    output_dir: str = "./output"
    log_dir: str = "./logs"

@dataclass
class CacheConfig:
    """缓存管理配置"""
    enabled: bool = True
    max_cache_size_gb: int = 400  # 缓存空间上限（GB），超过时按 LRU 清理
    ocr_frame_cache: bool = True   # 是否缓存 OCR 原始帧图片（MVP阶段为保证不丢失信息，默认开启）
    llm_cache: bool = True          # LLM 响应缓存
    asr_cache: bool = True          # ASR 结果缓存
```

## 四、环境变量配置（.env）

敏感信息（API Key）通过 `.env` 文件配置，不硬编码到 `config.yaml` 中。

### 4.1 .env 示例

```ini
# 火山引擎豆包 API（默认推荐）
VOLCENGINE_API_KEY=ark-你的API_Key
VOLCENGINE_MODEL=doubao-seed-2-1-pro-260628
VOLCENGINE_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

# DeepSeek API（备选）
DEEPSEEK_API_KEY=sk-你的API_Key
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

### 4.2 配置加载顺序

1. 加载 `config.yaml` 中的默认配置
2. 加载 `.env` 文件中的环境变量
3. 用环境变量覆盖配置中的 `api_key`、`model`、`base_url` 等字段

## 五、第三方库调用

| 库 | 用途 | 调用方式 |
|---|---|---|
| PyYAML | YAML 配置文件解析 | `yaml.safe_load(file)` |
| 自实现 .env 解析器 | 环境变量加载（API Key） | 不依赖 python-dotenv，自实现简单解析 |
| dataclasses | 配置数据结构 | `@dataclass` 装饰器 |
