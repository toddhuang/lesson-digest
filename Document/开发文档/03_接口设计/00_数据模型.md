## 一、视频与音频相关

### 1.1 VideoInfo

视频元信息，由 M14 工具集的 `probe_video()` 返回。

```python
@dataclass
class VideoInfo:
    path: str              # 文件路径
    duration: float        # 时长（秒）
    width: int             # 宽度（像素）
    height: int            # 高度（像素）
    fps: float             # 帧率
    video_codec: str       # 视频编码
    audio_codec: str       # 音频编码
    audio_channels: int    # 音频声道数
    audio_sample_rate: int # 音频采样率
    size_bytes: int        # 文件大小（字节）
    has_audio: bool        # 是否有音轨
    has_video: bool        # 是否有视频流
```

### 1.2 AudioInfo

音频提取结果，由 M2 音轨提取模块返回。

```python
@dataclass
class AudioInfo:
    path: str              # 输出 WAV 文件路径
    duration: float        # 音频时长（秒）
    sample_rate: int       # 采样率（Hz）
    channels: int          # 声道数
    size_bytes: int        # 文件大小（字节）
```

### 1.3 FrameInfo

关键帧信息，由 M3 关键帧提取模块返回。

```python
@dataclass
class FrameInfo:
    path: str           # 图片文件路径
    timestamp: float    # 帧在视频中的时间点（秒）
    format: str         # 图片格式（jpg/png）
    size_bytes: int     # 文件大小（字节）
    width: int          # 图片宽度（像素）
    height: int         # 图片高度（像素）
```

## 二、识别结果相关

### 2.1 ASR 结果（字级时间戳）

ASR 识别结果由 M15 ASR 适配层返回，M4 语音识别模块使用。架构 v2.0 起由旧的句级 `Sentence` 升级为**字级时间戳**结构，作为时间戳的唯一权威来源。

#### 2.1.1 CharTime

单个字符的时间戳（毫秒），是字级时间戳的最小单元。

```python
@dataclass
class CharTime:
    start_ms: int    # 字符起始时间（毫秒）
    end_ms: int      # 字符结束时间（毫秒）
```

#### 2.1.2 RawTranscript

ASR 原始输出，时间戳的唯一权威来源。`text` 与 `char_timestamps` 等长，标点/空格等无语音字符对应位置为 `None`。

```python
@dataclass
class RawTranscript:
    text: str                              # 识别文本（含标点）
    char_timestamps: List[Optional[CharTime]]  # 每个字符的时间戳，无语音字符为 None
```

提供 `get_time_range(start_idx, end_idx)` 返回字符区间的起止时间（秒），跳过 None。

#### 2.1.3 AlignedTranscript

纠错后文本 + 与原始文本的对齐映射。`text` 与 `raw_align` 等长，`raw_align[i]` 指向 `RawTranscript.text` 的字符索引，`None` 表示 LLM 新增字（无直接时间戳），通过回溯 `raw` 取时间戳。

```python
@dataclass
class AlignedTranscript:
    text: str                       # 纠错后文本
    raw_align: List[Optional[int]]  # 对齐映射，指向 RawTranscript.text 字符索引
    raw: Optional[RawTranscript]    # 原始 ASR 输出（时间戳来源）
```

提供 `get_time_range(start_idx, end_idx)` 沿 `raw_align` 回溯到 `RawTranscript` 取时间戳。

> **旧结构 Sentence（已废弃）**：句级 `Sentence`（start_time/end_time/text/confidence）为旧版结构，代码中保留但逐步废弃，新代码使用上述字级结构。

### 2.2 OCRResult

OCR 文字识别结果（单条文本或公式），由 M16 OCR 适配层返回，M5 文字识别模块使用。R-008 定案扩展 `block_type` / `latex` 字段，支持两引擎并行输出。

```python
@dataclass
class OCRResult:
    text: str                    # 识别文本
    confidence: float            # 置信度（0-1）
    bounding_box: List[float]    # 文本框坐标 [x1, y1, x2, y2]（归一化 0-1）
    block_type: str = "text"     # R-008：块类型 text / handwritten / formula / title / image
    latex: str = ""              # R-008：公式 LaTeX（仅 block_type=formula 时有效）
```

**两引擎并行说明（R-008）**：
- `block_type=text` + 文本：PP-OCRv6 识别的印刷体文字行
- `block_type=handwritten` + 文本：PP-OCRv6 识别的手写体碎片（置信度偏低，交 LLM 补全）
- `block_type=formula` + `latex`：PP-FormulaNet 识别的印刷体公式 → LaTeX

### 2.3 OCRFrameResult

OCR 单帧识别结果，由 M5 文字识别模块返回。

```python
@dataclass
class OCRFrameResult:
    timestamp: float             # 帧在视频中的时间点（秒）
    image_path: str              # 图片路径
    results: List[OCRResult]    # 该帧的所有识别结果
    full_text: str               # 该帧所有文本合并（按阅读顺序，从上到下、从左到右）
    is_duplicate: bool           # 是否为重复帧（与前一帧文字相似度 > 0.9）
```

## 三、提取结果相关

### 3.1 KnowledgePoint

知识点，由 M7 知识点提取模块返回。

```python
@dataclass
class KnowledgePoint:
    index: int           # 序号（从1开始）
    name: str            # 知识点名称（极简，1-2句话）
    start_time: float    # 起始时间戳（秒）
    confidence: float    # 置信度（0-1），LLM 自评
```

### 3.2 Problem

题目，由 M8 题目提取模块返回。

```python
@dataclass
class Problem:
    index: int                    # 题号（从1开始）
    start_time: float             # 题目开始时间（秒）
    end_time: float               # 题目结束时间（秒）
    question_text: str            # 原题文字
    solution_steps: List[SolutionStep]  # 解题步骤列表
    has_image: bool               # 是否含图（几何图、函数图、实验装置图等）
    image_description: str        # 图片内容描述（LLM 基于文字推断）
    source: str                   # 题目来源（如"2023年中考题"，无则为空字符串）
    confidence: float             # 置信度（0-1）
    asr_question_text: str        # ASR识别的原题文本（用于与OCR原题对比，保留原始ASR记录）
```

### 3.3 SolutionStep

解题步骤，属于 Problem 的子结构（09 设计：扩展 start_time/end_time 用于解题过程截图定位）。

```python
@dataclass
class SolutionStep:
    step_number: int              # 步骤序号（从1开始）
    content: str                  # 步骤内容（ASR+OCR 融合，公式用 LaTeX）
    start_time: float             # 该步骤开始时间（秒，用于解题过程截图）
    end_time: float               # 该步骤结束时间（秒）
```

## 四、LLM 相关

### 4.1 TokenUsage

Token 使用统计，由 M17 LLM 适配层返回。

```python
@dataclass
class TokenUsage:
    prompt_tokens: int       # 输入 token 数
    completion_tokens: int   # 输出 token 数
    total_tokens: int        # 总 token 数
```

### 4.2 LLMResponse

LLM 非流式响应，由 M17 LLM 适配层返回，M11 LLM 客户端使用。

```python
@dataclass
class LLMResponse:
    content: str             # 生成的文本内容
    model: str               # 使用的模型名
    usage: TokenUsage        # token 使用统计
    finish_reason: str       # 结束原因（stop/length/content_filter）
```

### 4.3 LLMChunk

LLM 流式响应块，由 M17 LLM 适配层返回。

```python
@dataclass
class LLMChunk:
    delta_content: str               # 增量文本内容
    finish_reason: Optional[str]     # 结束原因（最后一个 chunk 有值）
    usage: Optional[TokenUsage]      # token 使用统计（最后一个 chunk 有值）
```

## 五、输出与流水线相关

### 5.1 ProcessResult

完整处理结果，由 M13 主流程编排模块返回，M12 输出组装模块使用。

```python
@dataclass
class ProcessResult:
    video_path: str                          # 视频文件路径
    video_info: Optional[VideoInfo]          # 视频元信息
    asr_results: Optional[RawTranscript]     # ASR 原始识别结果（字级时间戳）
    corrected_transcript: Optional[AlignedTranscript]  # 纠错后对齐文本
    ocr_results: List[OCRFrameResult]       # OCR 文字识别结果
    full_text: str                           # 纯 ASR 全文本（OCR 不混入，仅作原题补充）
    knowledge_points: List[KnowledgePoint]   # 知识点列表
    problems: List[Problem]                  # 题目列表
    screenshot_paths: List[str]              # 题目截图路径列表（与 problems 一一对应，失败的为 None）
    mindmap_opml: str                        # 思维导图 OPML 内容
```

### 5.2 OutputFiles

输出文件路径列表，由 M12 输出组装模块返回。

```python
@dataclass
class OutputFiles:
    transcript_path: str          # 逐字稿路径
    knowledge_path: str           # 知识点清单路径
    mindmap_path: str             # 思维导图路径
    problem_files: List[str]      # 习题文件路径列表（原题+解析）
    output_dir: str               # 输出根目录
```

### 5.3 PipelineContext

流水线上下文，M13 主流程编排模块内部使用，在各阶段间传递数据。

```python
@dataclass
class PipelineContext:
    video_path: str                          # 视频路径
    video_info: Optional[VideoInfo]          # 视频信息（阶段1后填充）
    audio_path: Optional[str]                # 音轨路径（阶段2后填充）
    frame_paths: Optional[List[str]]         # 关键帧路径列表（阶段3后填充）
    frame_timestamps: Optional[List[float]]  # 关键帧时间戳列表（秒），与 frame_paths 一一对应（阶段3后填充）
    asr_results: Optional[RawTranscript]    # ASR 原始结果（字级时间戳，阶段4后填充）
    corrected_transcript: Optional[AlignedTranscript]  # 纠错后对齐文本（阶段6后填充）
    ocr_results: Optional[List[OCRFrameResult]]  # OCR 结果（阶段5后填充）
    full_text: Optional[str]                  # 纯 ASR 全文本（阶段7后填充）
    knowledge_points: Optional[List[KnowledgePoint]]  # 知识点（阶段6后填充）
    problems: Optional[List[Problem]]        # 题目（阶段6后填充）
    screenshot_paths: Optional[List[str]]    # 截图路径（阶段8后填充）
    mindmap_opml: Optional[str]              # 思维导图（阶段9后填充）
    output_files: Optional[OutputFiles]      # 输出文件（阶段10后填充）
    completed_stages: List[str]              # 已完成阶段列表
```

### 5.4 PipelineProgress

流水线进度信息，由 M13 主流程编排模块的 `get_progress()` 返回。

```python
@dataclass
class PipelineProgress:
    current_stage: str           # 当前执行阶段
    completed_stages: List[str]  # 已完成阶段
    total_stages: int            # 总阶段数
    progress_percent: float      # 进度百分比（0-100）
    is_running: bool             # 是否正在执行
    is_cancelled: bool           # 是否已取消
    error: Optional[str]         # 错误信息（无错误则为 None）
```

## 六、配置相关

> 配置数据结构的完整定义见 `M1_配置管理模块接口.md` 第三节。此处仅列名称索引。

| 数据结构 | 说明 |
|---|---|
| `Config` | 全局配置根对象 |
| `VideoConfig` | 视频处理参数（帧格式、质量） |
| `LLMConfig` | LLM 配置（模型注册表 models[] + 服务商 providers + 重试策略） |
| `ModelConfig` | 模型注册表条目（name / provider / capabilities / context_length / max_output） |
| `ProviderConfig` | 服务商配置（base_url / api_key / litellm_prefix） |
| `TaskConfig` | 任务-模型映射（model / temperature），每个 LLM 调用点独立配置 |
| `ASRConfig` | 语音识别配置（adapter_type / sample_rate / channels / model_name） |
| `OCRConfig` | 文字识别配置（text_adapter_type / formula_adapter_type / enable_color_filter） |
| `FrameDedupConfig` | 帧去重配置（algorithm=dhash / threshold=0.02 / interval_sec=1.0），R-009 |
| `TextOCRConfig` | 文字 OCR 引擎配置（PP-OCRv6 检测/识别模型名） |
| `FormulaOCRConfig` | 公式 OCR 引擎配置（PP-FormulaNet 模型名） |
| `OutputConfig` | 输出配置（文件名 / 目录名 / 时间戳格式） |
| `PathsConfig` | 路径配置（cache / output / temp / log 目录） |
| `CacheConfig` | 缓存管理配置（含 400GB 上限、OCR 帧缓存开关） |

> **已废弃**：`LocalLLMConfig`、`CloudLLMConfig`（架构 v2.0 纯云端化后删除，改为统一的 `LLMConfig` + `ModelConfig` + `ProviderConfig` + `TaskConfig` 模型注册表方案）

## 七、数据流向速查

```
VideoInfo (M14)
  └→ PipelineContext.video_info

AudioInfo (M2)
  └→ audio_path → M4 → List[Sentence]

FrameInfo (M3)
  └→ frame_paths + frame_timestamps → M5 → List[OCRFrameResult]

List[Sentence] + List[OCRFrameResult]
  └→ M6 → List[MergedText] → full_text (str)

full_text
  ├→ M7 → List[KnowledgePoint]
  ├→ M8 → List[Problem] (含 List[SolutionStep])
  └→ M10 → mindmap_opml (str)

List[Problem]
  └→ M9 → screenshot_paths (List[str])

全部结果
  └→ M12 → OutputFiles
```
