# M13 主流程编排模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M13
> 模块职责：串联所有模块，管理执行顺序、断点续传（缓存）、错误处理

---

## 一、模块概述

主流程编排模块（Pipeline）是系统的核心调度模块，负责串联所有功能模块，管理执行顺序、中间结果缓存、错误处理和日志记录。是整个流水线的入口和指挥中心。

> **重要**：ASR 纠错阶段（correct_asr）在文本合并（merge_text）之前执行，纠错后替换 `context.asr_results`，确保后续知识点提取、题目提取、思维导图生成都基于纠错后的文本。

## 二、接口列表

### 13.1 __init__

**功能**：初始化流水线，加载配置，创建所有功能模块实例。

**签名**：
```python
def __init__(self, config: Config)
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| config | Config | 是 | 全局配置对象（由 ConfigManager 加载） |

---

### 13.2 run

**功能**：执行完整的视频处理流水线，返回处理结果。

**签名**：
```python
def run(
    self,
    video_path: str,
    output_dir: str,
    force: bool = False
) -> ProcessResult
```

**输入参数**：
| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| video_path | str | 是 | — | 输入视频文件路径 |
| output_dir | str | 是 | — | 输出根目录 |
| force | bool | 否 | False | 是否强制重新处理（忽略缓存） |

**输出**：ProcessResult（完整处理结果）

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| VideoNotFoundError | 视频文件不存在 |
| PipelineError | 流水线执行失败（包含具体失败阶段） |

## 三、流水线阶段

### 3.1 阶段列表

| 序号 | 阶段名 | 模块 | 说明 | 可并行 |
|---|---|---|---|---|
| 1 | probe | M14 | 探测视频信息 | ❌ |
| 2 | extract_audio | M2 | 提取音轨 | ✅ 与3并行 |
| 3 | extract_frames | M3 | 提取关键帧 | ✅ 与2并行 |
| 4 | asr | M4 | 语音识别 | ✅ 与5并行 |
| 5 | ocr | M5 | 文字识别（含颜色过滤预处理） | ✅ 与4并行 |
| 6 | correct_asr | utils/asr_corrector | ASR 纠错（默认服务商，纠错后替换 asr_results） | ❌（依赖4） |
| 7 | merge_text | M6 | 纯 ASR 文本整理（OCR 不混入，生成 full_text） | ❌（依赖6） |
| 8 | extract_knowledge | M7 | 知识点提取 | ✅ 与9、11并行 |
| 9 | extract_problems | M8 | 题目提取（结合 ASR+OCR） | ✅ 与8、11并行 |
| 10 | capture_screenshots | M9 | 题目截图 | ❌（依赖9） |
| 11 | generate_mindmap | M10 | 思维导图生成 | ✅ 与8、9并行 |
| 12 | assemble_output | M12 | 输出组装 | ❌ |

### 3.2 执行顺序图

```
probe
  ├─ extract_audio ──→ asr ──┐
  └─ extract_frames ─→ ocr ──┴─→ correct_asr（纠错后替换 asr_results）
                                      └─→ merge_text（纯ASR → full_text）
                                            ├─ extract_knowledge ──┐
                                            ├─ extract_problems ──→ capture_screenshots ──┤
                                            └─ generate_mindmap ────┴─→ assemble_output
```

## 四、数据结构

### 4.1 PipelineContext（dataclass）

```python
@dataclass
class PipelineContext:
    video_path: str                          # 视频路径
    video_info: Optional[VideoInfo]          # 视频信息（阶段1后填充）
    audio_path: Optional[str]                # 音轨路径（阶段2后填充）
    frame_paths: Optional[List[str]]         # 关键帧路径列表（阶段3后填充）
    frame_timestamps: Optional[List[float]]  # 关键帧时间戳列表（秒），与 frame_paths 一一对应
    asr_results: Optional[List[Sentence]]    # ASR 结果（阶段4后填充，阶段6纠错后替换）
    ocr_results: Optional[List[OCRFrameResult]]  # OCR 结果（阶段5后填充）
    full_text: Optional[str]                  # 合并全文本（阶段7后填充，纯ASR）
    knowledge_points: Optional[List[KnowledgePoint]]  # 知识点（阶段8后填充）
    problems: Optional[List[Problem]]        # 题目（阶段9后填充）
    screenshot_paths: Optional[List[str]]    # 截图路径（阶段10后填充）
    mindmap_opml: Optional[str]              # 思维导图（阶段11后填充）
    output_files: Optional[OutputFiles]      # 输出文件（阶段12后填充）
    completed_stages: List[str]              # 已完成阶段列表
```

### 4.2 PipelineProgress（dataclass）

```python
@dataclass
class PipelineProgress:
    current_stage: str           # 当前执行阶段
    completed_stages: List[str]  # 已完成阶段
    total_stages: int            # 总阶段数
    progress_percent: float      # 进度百分比（0-100）
    is_running: bool             # 是否正在执行
    is_cancelled: bool           # 是否已取消
    error: Optional[str]         # 错误信息（无错误则为 None）
```

## 五、缓存机制

### 5.1 缓存策略

ASR、OCR、LLM 调用结果缓存到本地，避免重复计算：
- ASR 缓存键：`md5(os.path.abspath(audio_path))[:16]`
- OCR 缓存键：`md5(os.path.abspath(frame_path))[:16]`
- LLM 缓存键：`md5(messages + backend + model + temperature + top_p + max_tokens)`

### 5.2 续传逻辑

执行每个阶段前，检查缓存：
- 缓存存在且 `force=False` → 加载缓存，跳过该阶段
- 缓存不存在或 `force=True` → 执行该阶段，完成后写入缓存

## 六、错误处理

### 6.1 错误分级

| 级别 | 处理方式 | 示例 |
|---|---|---|
| 可恢复错误 | 重试（最多5次），成功则继续 | 网络超时、LLM 5xx |
| 降级错误 | 跳过该步骤，记录警告，继续执行 | OCR 某帧失败、截图截错 |
| 致命错误 | 中断流水线，返回错误信息 | 视频无音轨、ASR 模型加载失败 |

### 6.2 ASR 纠错降级

correct_asr 阶段如果 LLM 调用失败，不中断流水线，继续使用原始 ASR 结果，记录警告日志。
