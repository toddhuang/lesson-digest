# M3 关键帧提取模块 — 接口设计

> 所属文档：02_架构设计.md
> 模块编号：M3
> 模块职责：从视频中按间隔提取关键帧图片 + dHash 去重

---

## 一、模块概述

关键帧提取模块 R-009 定案：按 **1 秒间隔**用 OpenCV `VideoCapture` 抽帧 + **dHash 差异哈希去重**（阈值 0.02），输出带时间戳的关键帧图片列表。相比旧版 30 秒 ffmpeg 抽帧，1 秒间隔保证不漏过短暂出现的板书变化，dHash 去重过滤无变化的相邻帧，减少 OCR 计算量。

单点截图（`extract_frame_at`）仍用 ffmpeg 保证时间精度，供 M9 题目截图模块使用，不参与 dHash 去重。

### 帧缓存策略

> **MVP 设计原则**：为保证最大可能不丢失信息，提取的所有关键帧原始图片均缓存到本地，OCR 完成后不删除（保留用于调试、重新 OCR、题目截图参考）。

- 缓存目录：`cache/{video_hash}/frames/`
- 开关：由 `M1 CacheConfig.cache_ocr_frames` 控制，默认 `True`
- 空间上限：`CacheConfig.max_cache_size_gb`，默认 `400` GB
- 清理策略：超过上限时，按 LRU（最近最少使用）清理最旧的视频缓存目录
- 单帧提取（`extract_frame_at`）不缓存，直接输出到目标路径（用于题目截图）

## 二、接口列表

### 2.1 extract_frames

**功能**：按间隔抽帧并 dHash 去重，输出到指定目录。

**签名**：
```python
def extract_frames(self, video_path: str, output_dir: str) -> List[FrameInfo]
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 输入视频文件路径 |
| output_dir | str | 是 | 输出图片目录 |

> 抽帧间隔、图片格式、质量、dHash 阈值等参数在构造函数 `__init__` 中设置，不在每次调用传入。

**构造函数参数**：
| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| interval | float | 1.0 | 抽帧间隔（秒），R-009 默认 1.0 |
| fmt | str | "jpg" | 图片格式（jpg/png） |
| quality | int | 90 | JPG 质量 1-100，仅 jpg 生效 |
| dedup_threshold | float | 0.02 | dHash 去重阈值 0~1，R-009 默认 0.02 |
| enable_dedup | bool | True | 是否启用 dHash 去重 |

**输出**：`List[FrameInfo]`（仅保留通过去重的帧，按时间排序）

**流程**：
1. 缓存检查：输出目录已有 `frame_*` 前缀图片直接按文件名恢复 FrameInfo 列表
2. `cv2.VideoCapture` 打开视频，读取 fps / 总帧数
3. 按 `interval` 计算步长 `step = round(fps * interval)`，逐帧 `cap.read()`
4. `FrameDeduplicator.should_keep(frame)` 判定：低于阈值（无变化）丢弃，高于阈值保留
5. 保留的帧 `cv2.imwrite` 保存，记录 FrameInfo

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| InvalidVideoError | 视频文件不存在 |
| FFmpegError | OpenCV 无法打开视频 |

### 2.2 extract_frame_at

**功能**：在视频指定时间点提取单帧图片（用于题目截图）。

**签名**：
```python
def extract_frame_at(self, video_path: str, timestamp: float, output_path: str) -> str
```

**输入参数**：
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| video_path | str | 是 | 输入视频文件路径 |
| timestamp | float | 是 | 提取时间点（秒） |
| output_path | str | 是 | 输出图片路径 |

**输出**：`str`（输出图片路径）

> 使用 ffmpeg 单点截帧保证时间精度，不参与 dHash 去重。若 output_path 已存在则跳过。

**异常**：
| 异常类型 | 触发条件 |
|---|---|
| InvalidVideoError | 视频文件不存在 |
| TimestampOutOfRangeError | 时间戳为负数 |
| FFmpegError | ffmpeg 执行失败或未找到 |

## 三、数据结构

### 3.1 FrameInfo（dataclass）

```python
@dataclass
class FrameInfo:
    path: str           # 图片文件路径
    timestamp: float    # 帧在视频中的时间点（秒）
    format: str         # 图片格式（jpg/png）
    size_bytes: int     # 文件大小（字节）
    width: int          # 图片宽度（像素）
    height: int         # 图片高度（像素）
```

## 四、dHash 去重算法（R-009 定案）

### 4.1 算法原理

`FrameDeduplicator`（`core/frame_dedup.py`）使用 dHash 差异哈希：
1. 帧转灰度，缩放到 9×8
2. 比较相邻列像素，左 > 右 为 True，输出 64 位布尔哈希
3. 比较当前帧与上一保留帧的汉明距离 / 64 = 差异分数
4. 差异分数 < 阈值（0.02）视为同一画面，丢弃；≥ 阈值保留并更新上一帧哈希

### 4.2 阈值选择

阈值 0.02 = 64 位哈希中仅 1-2 位差异即判定为无变化。R-009 调研在测试视频上对比 dHash / pHash / absdiff / SSIM 四种算法后定案 dHash + 0.02。

## 五、第三方库调用

### 5.1 OpenCV（按间隔抽帧）

```python
import cv2

cap = cv2.VideoCapture(video_path)
cap.set(cv2.CAP_PROP_POS_FRAMES, idx)
ok, frame = cap.read()
cv2.imwrite(frame_path, frame, [cv2.IMWRITE_JPEG_QUALITY, quality])
```

### 5.2 ffmpeg（单点截图）

```bash
ffmpeg -ss {timestamp} -i {video_path} -vframes 1 -q:v {quality} {output_path} -y
```

### 5.3 Python 调用方式

抽帧用 `cv2.VideoCapture`；单点截图用 `subprocess.run()` 调用 ffmpeg。
