# 验收标准清单

> 所属文档：开发文档
> 用途：定义 MVP 阶段各输出物的验收标准，用于判断一个视频处理结果是否"合格"

---

## 一、系统级验收标准

### 1.1 流水线完整性

| 检查项 | 标准 |
|---|---|
| 完整运行 | 一条命令完成从视频输入到输出目录生成的全流程 |
| 无崩溃 | 处理过程中不出现未捕获异常导致程序退出 |
| 输出完整 | 输出目录包含所有预期文件（逐字稿、知识点清单、思维导图、习题目录、截图目录） |
| 断点续传 | 中断后重新运行，已完成阶段从缓存加载，不重复执行 |

### 1.2 错误处理

| 检查项 | 标准 |
|---|---|
| 视频无音轨 | 明确提示"视频无音轨"，不崩溃 |
| 视频损坏 | 明确提示"视频文件无效"，不崩溃 |
| 云端 API 不可用 | 明确提示错误信息，已完成的中间结果保留在缓存中 |
| API 限流 | 自动重试（指数退避），重试耗尽后明确提示 |

### 1.3 性能基准（参考，非硬性要求）

| 视频时长 | 预期总处理时间 |
|---|---|
| 10 分钟 | < 5 分钟 |
| 45 分钟 | < 15 分钟 |
| 2 小时 | < 40 分钟 |

> MVP 阶段质量优先，性能仅作参考，不作为验收硬性指标。

## 二、逐字稿验收标准

| 检查项 | 标准 |
|---|---|
| 文件存在 | `01_逐字稿.md` 生成成功 |
| 格式正确 | Markdown 格式，每句带 `[mm:ss]` 时间戳前缀 |
| 时间戳有序 | 时间戳按升序排列，无倒序 |
| 时间戳范围 | 所有时间戳在 `[0, 视频时长]` 范围内 |
| 内容完整 | 覆盖视频全部语音内容，无大段缺失 |
| 标点正确 | 句子末尾有标点符号（。？！） |
| 元信息 | 文件头部包含视频名、时长、生成时间 |

**质量评估方法**：随机抽取 3 个时间段（开头/中间/结尾），人工对比视频语音与逐字稿，准确率 > 85% 为合格。

---

## 三、知识点清单验收标准

| 检查项 | 标准 |
|---|---|
| 文件存在 | `02_知识点清单.md` 生成成功 |
| 格式正确 | Markdown 格式，编号列表，每项带时间戳 |
| 非空 | 至少提取到 1 个知识点（纯习题讲解视频可能为 0，需标注） |
| 时间戳有效 | 所有时间戳在 `[0, 视频时长]` 范围内 |
| 极简性 | 每个知识点名称 1-2 句话，不包含详细解释 |
| 无过度解读 | 不标注"重点""难点""考点"等主观判断 |
| 按时间排序 | 知识点按起始时间戳升序排列 |

**质量评估方法**：人工浏览视频目录/章节，对比知识点清单，覆盖率 > 70% 为合格（不要求 100%，老师可能讲非知识点内容）。

---

## 四、习题整理验收标准

### 4.1 原题文件

| 检查项 | 标准 |
|---|---|
| 文件存在 | `习题/题目XX_原题.md` 生成成功（每题一个文件） |
| 原题文字 | 包含题目文字内容，非空 |
| 时间范围 | 包含题目开始/结束时间戳 |
| 截图引用 | 含图题目包含截图引用（`![题目XX截图](../截图/题目XX.png)`） |
| 截图存在 | 引用的截图文件实际存在于 `截图/` 目录 |
| 来源标注 | 老师提到来源时标注（如"2023年中考题"） |

### 4.2 解析文件

| 检查项 | 标准 |
|---|---|
| 文件存在 | `习题/题目XX_解析.md` 生成成功（每题一个文件） |
| 原题复述 | 包含原题文字 |
| 解题步骤 | 分步骤列出，每步带时间戳 |
| 步骤有序 | 步骤序号从 1 开始递增 |
| 时间戳有效 | 解题步骤时间戳在题目时间范围内 |

### 4.3 题目覆盖率

| 检查项 | 标准 |
|---|---|
| 漏题率 | 人工对比视频中老师讲解的题目数量，漏题率 < 30% 为合格 |
| 误判率 | 非题目内容被误判为题目的比例 < 20% 为合格 |

> 题目提取是 MVP 阶段最难的部分，验收标准相对宽松，重点验证"可能性"而非"完美性"。

## 五、思维导图验收标准

| 检查项 | 标准 |
|---|---|
| 文件存在 | `03_思维导图.opml` 生成成功 |
| XML 格式 | OPML 2.0 格式合法，可被 XML 解析器解析 |
| 根节点 | 包含 `<head><title>` 和 `<body>` |
| 知识点覆盖 | 输入的知识点列表中 > 80% 出现在思维导图中 |
| 层级合理 | 不超过 3 层，章节→知识点→子知识点 |
| 时间戳标注 | 知识点节点在 `_note` 属性中标注时间戳 |
| 可导入 | 可被 XMind/幕布/MindMaster 等工具正常导入 |

## 六、输出目录结构验收标准

```
{output_dir}/{视频名}/
├── 01_逐字稿.md          ✓ 必须存在
├── 02_知识点清单.md      ✓ 必须存在
├── 03_思维导图.opml      ✓ 必须存在
├── 习题/                  ✓ 必须存在（即使无题目，目录应存在）
│   ├── 题目01_原题.md
│   ├── 题目01_解析.md
│   └── ...
└── 截图/                  ✓ 必须存在（即使无截图，目录应存在）
    ├── 题目01.png
    └── ...
```

| 检查项 | 标准 |
|---|---|
| 目录结构 | 与规范完全一致 |
| 文件命名 | 文件名与规范一致（`题目XX_原题.md`、`题目XX.png` 等） |
| 无多余文件 | 输出目录不包含临时文件、缓存文件 |
| 相对路径 | Markdown 中的截图引用使用相对路径（`../截图/题目XX.png`） |

---

## 七、MVP 验收通过条件

满足以下全部条件，视为 MVP 验收通过：

1. **系统级**：流水线完整运行无崩溃，输出目录结构正确，断点续传可用
2. **逐字稿**：文件生成成功，时间戳有序，内容覆盖完整
3. **知识点**：文件生成成功，非空，时间戳有效
4. **习题**：至少能正确提取视频中 50% 的题目（原题+解析+截图）
5. **思维导图**：OPML 格式合法，可被工具导入，知识点覆盖率 > 80%
6. **错误处理**：视频无音轨、API 不可用等异常场景有明确提示，不崩溃

> MVP 阶段重点验证"项目可能性"，输出质量不追求完美。验收通过后进入 P1 迭代，重点优化题目提取准确率和输出质量。
