## 一、项目概述

### 1.1 项目名称

教学视频内容提取与总结工具（暂定名）

### 1.2 项目定位

面向初高中学生的公益开源工具，自动提取教学视频中的讲解要点、习题和知识点，生成结构化的学习资料，辅助学生课下复习刷题。

### 1.3 项目阶段

- **当前阶段**：MVP（最小可行产品），验证核心需求可行性
- **后期规划**：客户群体扩大后考虑商业内容开发

## 二、客户画像

### 2.1 目标用户

初高中学生（初一至高三）

### 2.2 用户特征

| 维度 | 描述 |
|---|---|
| 年龄段 | 12-18 岁 |
| 学习场景 | 自主网课学习、课后复习、刷题备考 |
| 技术能力 | 能使用基本电脑操作，不要求编程能力 |

## 三、核心使用场景

### 3.1 场景一：网课学习后整理笔记

**触发**：学生看完一段 20-45 分钟的网课后，想要一份结构化的复习资料。

**过程**：
1. 学生将网课视频文件导入工具
2. 工具自动处理视频，生成逐字稿、知识点清单、习题整理、思维导图
3. 学生查看输出资料，用于课下复习

**期望结果**：学生无需手动记笔记，直接获得可用于复习的结构化资料。

### 3.2 场景二：复习时快速定位知识点

**触发**：学生复习时，想要回顾某个知识点的讲解，但不想从头看视频。

**过程**：
1. 学生查看知识点清单，找到目标知识点
2. 根据知识点旁的起始时间戳，跳转到视频对应位置
3. 观看该知识点的讲解片段

**期望结果**：学生能在 10 秒内定位到目标知识点的视频位置，无需从头浏览。

### 3.3 场景三：整理习题用于刷题

**触发**：学生想要整理老师讲解过的习题，用于日后刷题复习。

**过程**：
1. 工具自动识别视频中老师讲解的所有题目
2. 生成每道题的原题文件（含截图）和解析文件（含解题步骤+时间戳）
3. 学生刷题时查看原题，做完后对照解析，存疑时根据时间戳回看视频

**期望结果**：学生无需手动抄题，直接获得可刷题的习题集，解析存疑时可快速回看视频验证。

## 四、用户痛点分析

### 4.1 痛点清单

| 编号 | 痛点 | 严重程度 | 现有解决方案 | 现有方案缺陷 |
|---|---|---|---|---|
| P1 | 老师语速太快，手动记笔记跟不上 | 高 | 暂停视频记笔记 | 频繁打断观看节奏，效率低 |
| P2 | 视频太长，复习时从头看浪费时间 | 高 | 拖动进度条找位置 | 难以精确定位，反复拖动耗时 |
| P3 | 手动抄题耗时太多 | 高 | 手抄题目到笔记本 | 一道题可能抄 5-10 分钟，效率极低 |
| P4 | 公式/结构图/多学科内容抄录麻烦 | 中高 | 截图保存 | 截图零散，无法搜索，复习时难以关联 |
| P5 | 题目带图，手动画图麻烦 | 中 | 截图保存 | 同 P4 |

### 4.2 痛点优先级

**核心痛点（必须解决）**：P1、P2、P3
**重要痛点（应该解决）**：P4、P5

## 五、功能需求拆分

### 5.1 需求分层

```
总需求：自动提取教学视频内容，生成结构化学习资料
├── F1. 视频内容提取
│   ├── F1.1 语音转文字（生成逐字稿）
│   ├── F1.2 课件文字提取（OCR 识别 PPT/板书文字）
│   └── F1.3 关键帧截图（题目截图、课件截图）
├── F2. 知识点提取
│   ├── F2.1 识别视频中的知识点
│   ├── F2.2 为每个知识点标注起始时间戳
│   └── F2.3 生成知识点清单
├── F3. 习题提取与整理
│   ├── F3.1 识别视频中老师讲解的所有题目
│   ├── F3.2 提取每道题的原题内容
│   ├── F3.3 提取每道题的解题步骤
│   ├── F3.4 为每道题截取题目截图
│   └── F3.5 生成原题文件和解析文件
├── F4. 思维导图生成
│   ├── F4.1 基于视频内容生成课程知识结构
│   └── F4.2 输出 OPML 格式思维导图
└── F5. 输出管理
    ├── F5.1 按规范目录结构组织输出文件
    ├── F5.2 支持断点续传（中间结果缓存）
    └── F5.3 错误处理与日志
```

### 5.2 功能需求详细说明

#### F1. 视频内容提取

| 子需求 | 描述 | 输入 | 输出 |
|---|---|---|---|
| F1.1 语音转文字 | 将视频中的老师语音转换为带时间戳的文字 | 视频文件 | 带时间戳的逐字稿（句子级） |
| F1.2 课件文字提取 | 识别视频关键帧中的 PPT/板书文字 | 关键帧图片 | 带时间戳的 OCR 文字 |
| F1.3 关键帧截图 | 在指定时间点截取视频帧 | 时间点 | 截图图片文件 |

#### F2. 知识点提取

| 子需求 | 描述 | 输入 | 输出 |
|---|---|---|---|
| F2.1 识别知识点 | 基于语音文字和课件文字，识别视频中讲解的知识点 | 逐字稿 + OCR 文字 | 知识点列表 |
| F2.2 标注时间戳 | 为每个知识点标注在视频中的起始时间 | 知识点列表 + 逐字稿 | 带时间戳的知识点列表 |
| F2.3 生成清单 | 输出知识点清单 Markdown 文件 | 带时间戳的知识点列表 | 知识点清单.md |

**关键约束**：
- 知识点清单应**极简**，只包含知识点名称和起始时间戳
- **不做过度解读**，不标注重点/难点（不同学生掌握程度不同）
- 不提供知识点的详细解释（学生可根据时间戳回看视频）

#### F3. 习题提取与整理

| 子需求 | 描述 | 输入 | 输出 |
|---|---|---|---|
| F3.1 识别题目 | 识别视频中老师讲解的所有题目 | 逐字稿（全文） | 题目列表（含开始/结束时间） |
| F3.2 提取原题 | 提取每道题的原题文字内容 | 题目时间段 + 逐字稿 + OCR | 原题文字 |
| F3.3 提取解析 | 提取每道题的解题步骤 | 题目时间段 + 逐字稿 | 结构化解题步骤 |
| F3.4 截取题目截图 | 在题目开始时间点附近截取题目画面 | 题目开始时间 + 视频 | 题目截图图片 |
| F3.5 生成文件 | 为每道题生成原题文件和解析文件 | 原题文字 + 解析 + 截图 | 题目XX_原题.md + 题目XX_解析.md |

**关键约束**：
- 题目识别采用 **LLM 全文语义判断**，不硬编码关键词
- 原题文件包含题目文字和截图引用
- 解析文件包含题目文字、解题步骤、关键时间戳（方便存疑时回看视频）
- 截图作为参考附件，不追求 100% 准确

#### F4. 思维导图生成

| 子需求 | 描述 | 输入 | 输出 |
|---|---|---|---|
| F4.1 生成知识结构 | 基于视频内容生成课程知识结构 | 逐字稿 + 知识点清单 | 思维导图结构数据 |
| F4.2 输出 OPML | 输出标准 OPML 格式文件 | 思维导图结构数据 | 思维导图.opml |

**关键约束**：
- 输出格式为 **OPML**（可导入 XMind、幕布等工具渲染）
- 学生也可将 OPML 交给 AI 工具渲染为美观的思维导图

#### F5. 输出管理

| 子需求 | 描述 |
|---|---|
| F5.1 目录结构 | 按规范目录结构组织输出文件（见第七章） |
| F5.2 断点续传 | 中间结果缓存到本地，重新运行时跳过已完成步骤 |
| F5.3 错误处理 | LLM 调用失败重试，识别失败降级，不中断整体流程 |

## 六、输出物详细定义

### 6.1 输出物清单

| 编号 | 输出物 | 格式 | 必选/可选 | 说明 |
|---|---|---|---|---|
| O1 | 逐字稿 | Markdown | 必选 | 全文，带时间戳 |
| O2 | 知识点清单 | Markdown | 必选 | 极简，知识点名称+起始时间戳 |
| O3 | 习题整理 | 多 Markdown 文件 | 必选 | 原题文件+解析文件，每题一组 |
| O4 | 思维导图 | OPML | 必选 | 课程知识结构 |
| O5 | 题目截图 | PNG | 必选（有题时） | 题目画面截图，作为原题文件的参考附件 |

### 6.2 逐字稿（O1）规范

- 格式：Markdown
- 内容：视频中所有语音识别文字，按时间顺序排列
- 时间戳格式：`[mm:ss]`，每句话前标注
- 分段：按自然段落或固定时间间隔分段
- 不包含 OCR 文字（OCR 文字用于内部处理，不输出到逐字稿）

### 6.3 知识点清单（O2）规范

- 格式：Markdown
- 内容：编号列表，每条包含知识点名称和起始时间戳
- 示例：
  ```
  ## 知识点清单

  1. 一元二次方程的定义 [05:23]
  2. 配方法解一元二次方程 [12:45]
  3. 求根公式推导 [20:10]
  4. 判别式与根的关系 [28:30]
  ```
- **约束**：极简，不做过度解读，不标注重点/难点，不提供详细解释

### 6.4 习题整理（O3）规范

每道题生成两个文件：

**原题文件**（`题目XX_原题.md`）：
- 题目文字内容
- 题目截图引用（`![题目截图](../截图/题目XX.png)`）
- 题目在视频中的时间范围

**解析文件**（`题目XX_解析.md`）：
- 题目文字内容（重复，方便单独查看）
- 解题步骤（分步骤列出）
- 关键步骤的时间戳（存疑时可回看视频）
- 题目在视频中的时间范围

### 6.5 思维导图（O4）规范

- 格式：OPML 2.0
- 内容：课程知识结构，根节点为课程主题，子节点为章节/知识点
- 可导入 XMind、幕布、MindMaster 等工具渲染

> **详细格式规范**：以上为需求层面的输出物定义。具体的 Markdown 模板、字段定义、文件命名规范等实现细节，统一见 `03_接口设计/M12_输出组装模块接口.md` 第五章。后续格式调整只需更新 M12 接口文档，需求分析文档保持稳定。

## 八、输入特征

### 8.1 视频来源

- 本地文件（MVP 阶段）
- 后期可扩展：在线课程 URL、直播录屏

### 8.2 视频长度

| 范围 | 占比 | 说明 |
|---|---|---|
| 10-20 分钟 | 部分 | 短视频/知识点讲解 |
| 20-45 分钟 | **大部分** | 标准课时长度 |
| 45 分钟-2 小时 | 部分 | 长课程/专题讲座 |

### 8.3 视频类型

- **PPT 讲课为主**：老师讲解 + PPT 展示
- **手写推导居多**：老师在黑板/数位板上手写公式和推导过程

### 8.4 学科领域

- 数学（基础入门、解题思路方法）
- 物理（基础入门、解题思路方法）
- 化学（基础入门、解题思路方法）

**特征**：公式多、推导过程多、题目带图（几何图、函数图、实验装置图）。

## 九、非功能需求

### 9.1 质量需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NF1 | 逐字稿准确率 | 中文语音识别准确率 ≥ 95% |
| NF2 | 知识点识别 | 主要知识点不遗漏（允许少量次要知识点遗漏） |
| NF3 | 题目识别 | 老师讲解的题目不遗漏（允许边界时间戳有 ±10秒误差） |
| NF4 | 解题步骤提取 | 主要解题步骤完整（允许细节遗漏） |
| NF5 | 截图准确性 | 题目截图应包含题目主体内容（允许少量无关区域） |

### 9.2 性能需求（MVP 阶段不优先）

| 编号 | 需求 | 说明 |
|---|---|---|
| NF6 | 处理时间 | MVP 不做硬性要求，质量优先 |
| NF7 | 并发处理 | MVP 不要求，单次处理一个视频 |

### 9.3 可用性需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NF8 | 操作简单 | 学生只需提供视频文件，无需复杂配置 |
| NF9 | 输出规范 | 输出文件结构清晰，命名规范，学生可直接使用 |
| NF10 | 错误提示 | 处理失败时给出明确的错误信息和恢复建议 |

### 9.4 兼容性需求

| 编号 | 需求 | 说明 |
|---|---|---|
| NF11 | 视频格式 | 支持常见视频格式（MP4、AVI、MKV、MOV 等） |
| NF12 | 操作系统 | Windows 10/11（MVP 阶段） |
| NF13 | 输出格式 | Markdown、OPML、PNG（通用格式，无需专用软件查看） |

## 十一、约束与假设

### 11.1 约束条件

| 编号 | 约束 | 说明 |
|---|---|---|
| C1 | 硬件约束 | 本地处理端：RTX 3080 10GB；推理端：RTX 4090 24GB |
| C2 | 模型约束 | 本地大模型上下文 8K；云端大模型上下文 128K |
| C3 | 成本约束 | 公益开源项目，云端 API 成本应极低（单次处理 < ¥0.5） |
| C4 | 开源约束 | 项目开源，使用的工具和模型应支持开源使用 |

### 11.2 假设条件

| 编号 | 假设 | 说明 |
|---|---|---|
| A1 | 视频有清晰音轨 | 老师语音清晰，无严重背景噪音 |
| A2 | 视频有可见内容 | PPT/板书文字清晰可识别 |
| A3 | 老师讲题有明确引入 | 老师开始讲题时通常有过渡语（如"这道题""我们来看"） |
| A4 | 学生有基本电脑操作能力 | 能运行命令行工具，能查看 Markdown 文件 |
| A5 | 本地 GPU 环境已配置 | FunASR、PaddleOCR、vLLM 已部署并可正常运行 |

## 十二、术语表

| 术语 | 定义 |
|---|---|
| 逐字稿 | 视频中所有语音识别为文字后的完整文本，带时间戳 |
| 知识点清单 | 视频中讲解的知识点的极简列表，每条带起始时间戳 |
| 原题 | 老师讲解的题目的原始文字内容（不含解答） |
| 解析 | 老师对题目的解题步骤和讲解过程 |
| OPML | Outline Processor Markup Language，思维导图的标准交换格式 |
| OCR | Optical Character Recognition，光学字符识别，将图片中的文字转换为文本 |
| ASR | Automatic Speech Recognition，自动语音识别，将语音转换为文本 |
| LLM | Large Language Model，大语言模型 |
| MVP | Minimum Viable Product，最小可行产品 |
