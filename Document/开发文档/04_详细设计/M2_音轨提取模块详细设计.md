## 二、类设计

### 2.1 AudioExtractor 类

```python
class AudioExtractor:
    def __init__(self, config: VideoConfig):
        self.sample_rate = config.audio_sample_rate
        self.channels = config.audio_channels

    def extract_audio(self, video_path, output_path, ...) -> AudioInfo
    def has_audio(self, video_path) -> bool
```

---

## 三、核心流程

### 3.1 extract_audio 流程

```
1. 检查视频文件是否存在
2. 调用 has_audio() 检测是否有音轨
3. 无音轨 → 抛出 InvalidVideoError
4. 确保输出目录存在
5. 构造 ffmpeg 命令
6. 执行 ffmpeg（subprocess.run，capture_output）
7. 检查返回码，非0 → 抛出 FFmpegError（含 stderr）
8. 调用 ffprobe 获取输出音频信息（时长、采样率、大小）
9. 返回 AudioInfo
```

### 3.2 ffmpeg 命令构造

```python
cmd = [
    "ffmpeg",
    "-i", video_path,
    "-vn",                    # 不处理视频流
    "-acodec", "pcm_s16le",  # PCM 16位小端
    "-ar", str(self.sample_rate),
    "-ac", str(self.channels),
    "-y",                     # 覆盖已存在文件
    output_path
]
```

### 3.3 has_audio 流程

```python
cmd = [
    "ffprobe", "-v", "error",
    "-select_streams", "a:0",
    "-show_entries", "stream=codec_type",
    "-of", "csv=p=0",
    video_path
]
result = subprocess.run(cmd, capture_output=True, text=True)
return "audio" in result.stdout
```

## 四、缓存策略

音轨提取是流水线的早期阶段，提取后的 WAV 文件缓存到 `cache/{video_hash}/audio.wav`。

缓存键：`md5(video_path + file_size + file_mtime)`

下次运行时，如果缓存文件存在且视频未变更，直接返回缓存的 AudioInfo，跳过 ffmpeg 提取。

## 五、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 视频文件不存在 | 抛出 |
| InvalidVideoError | 视频无音轨 | 抛出，提示用户检查视频 |
| FFmpegError | ffmpeg 执行失败 | 抛出，包含错误码和 stderr |
| FFmpegNotFoundError | 系统未安装 ffmpeg | 抛出，提示安装 ffmpeg |

### 5.1 ffmpeg 可用性检测

模块初始化时检测 ffmpeg 是否可用：
```python
try:
    subprocess.run(["ffmpeg", "-version"], capture_output=True, check=True)
except (FileNotFoundError, subprocess.CalledProcessError):
    raise FFmpegNotFoundError("请先安装 ffmpeg 并添加到 PATH")
```

## 六、性能考虑

- ffmpeg 提取音轨是 IO 密集型操作，速度取决于磁盘读写
- 45分钟视频提取音轨通常 10-30 秒
- MVP 阶段不做进度显示，后续可加入 `-progress` 参数解析进度
