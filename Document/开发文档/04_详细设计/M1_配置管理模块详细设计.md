## 二、类设计

### 2.1 ConfigManager 类

```python
class ConfigManager:
    def __init__(self):
        self._config: Optional[Config] = None

    def load(self, config_path: str) -> Config
    def get(self, key: str, default: Any = None) -> Any
    def validate(self, config_dict: dict) -> bool
```

---

## 三、核心流程

### 3.1 load 流程

```
1. 检查配置文件是否存在
2. 读取 YAML 文件，解析为 dict
3. 调用 validate() 校验配置
4. 从环境变量读取 API Key（覆盖配置文件中的值）
   - VOLCENGINE_API_KEY → llm.providers.volcengine.api_key
   - DEEPSEEK_API_KEY → llm.providers.deepseek.api_key
   - VOLCENGINE_MODEL → llm.providers.volcengine.model
   - DEEPSEEK_MODEL → llm.providers.deepseek.model
5. 将 dict 转换为 Config dataclass（递归转换）
6. 缓存到 self._config
7. 返回 Config
```

### 3.2 环境变量读取

API Key 不硬编码在配置文件中，从环境变量（.env 文件）读取：

```python
import os
from dotenv import load_dotenv

load_dotenv()  # 加载 .env 文件

# 多服务商 API Key
volcengine_key = os.environ.get("VOLCENGINE_API_KEY", "")
deepseek_key = os.environ.get("DEEPSEEK_API_KEY", "")

# 模型配置（可通过环境变量切换模型）
volcengine_model = os.environ.get("VOLCENGINE_MODEL", "doubao-seed-2-1-pro-260628")
deepseek_model = os.environ.get("DEEPSEEK_MODEL", "deepseek-v4-flash")
```

配置文件中 `llm.providers.*.api_key` 可以留空，运行时从环境变量注入。

## 五、适配器类型配置

`adapter_type` 字段支持通过配置切换第三方引擎，无需修改代码：

| 配置项 | 可选值 | 默认值 | 说明 |
|---|---|---|---|
| `asr.adapter_type` | funasr / whisper / sensevoice | funasr | 语音识别引擎 |
| `ocr.adapter_type` | paddleocr / easyocr / rapidocr | paddleocr | 文字识别引擎 |
| `llm.default_provider` | volcengine / deepseek | volcengine | 默认 LLM 服务商 |
| `llm.providers.*.enabled` | true / false | true | 服务商启用状态 |

新增服务商时，在 M17 LLM 适配层工厂中注册即可，配置文件直接切换。

## 七、缓存管理

### 7.1 缓存空间上限

`cache.max_cache_size_gb: 400` — 缓存目录总大小不超过 400GB。超过时按 LRU（最近最少使用）策略清理最旧的缓存文件。

### 7.2 OCR 帧缓存

`cache.ocr_frame_cache: true` — MVP 阶段默认开启，缓存所有关键帧原始图片。目的是在 OCR 识别效果不佳时，可以重新识别或人工核对，保证不丢失信息。后续迭代可根据实际磁盘使用情况调整。

### 7.3 缓存清理策略

```
1. 每次流水线启动时检查缓存目录总大小
2. 超过 max_cache_size_gb 时，按文件修改时间排序，删除最旧的 20%
3. 记录清理日志（删除了多少文件、释放了多少空间）
```
