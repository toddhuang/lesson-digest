## 二、类设计

### 2.1 Config 类

```python
@dataclass
class Config:
    video: VideoConfig
    segmentation: SegmentationConfig
    llm: LLMConfig
    asr: ASRConfig
    ocr: OCRConfig
    output: OutputConfig
    paths: PathsConfig
```

所有子配置均为 `@dataclass`，字段定义见接口文档。

### 2.2 ConfigManager 类

```python
class ConfigManager:
    def __init__(self):
        self._config: Optional[Config] = None

    def load(self, config_path: str) -> Config
    def get(self, key: str, default: Any = None) -> Any
    def validate(self, config_dict: dict) -> bool
```

## 三、核心流程

### 3.1 load 流程

```
1. 检查配置文件是否存在
2. 读取 YAML 文件，解析为 dict
3. 调用 validate() 校验配置
4. 从环境变量读取 API Key（覆盖配置文件中的值）
5. 将 dict 转换为 Config dataclass（递归转换）
6. 缓存到 self._config
7. 返回 Config
```

### 3.2 环境变量读取

API Key 不硬编码在配置文件中，从环境变量读取：

```python
import os
from dotenv import load_dotenv

load_dotenv()  # 加载 .env 文件
api_key = os.environ.get("DEEPSEEK_API_KEY", "")
```

配置文件中 `llm.cloud.api_key` 可以留空，运行时从环境变量注入。

## 四、配置文件示例

```yaml
# config.yaml
video:
  audio_sample_rate: 16000
  audio_channels: 1
  frame_interval: 30
  scene_change_detection: false

segmentation:
  target_input_tokens: 3000
  max_input_tokens: 4000
  overlap_tokens: 500
  max_output_tokens: 1500

llm:
  local:
    base_url: "http://192.168.x.x:8000/v1"
    model: "qwen3.6-27b-awq"
    temperature: 0.3
  cloud:
    base_url: "https://api.deepseek.com/v1"
    model: "deepseek-chat"
    api_key: ""  # 从环境变量 DEEPSEEK_API_KEY 读取
    temperature: 0.3
  stage_backend:
    knowledge_extraction: "cloud"
    problem_extraction: "cloud"
    mindmap: "cloud"
  max_retries: 5

asr:
  model: "paraformer-zh"
  punc_model: "ct-punc"
  vad_model: "fsmn-vad"
  device: "cuda"

ocr:
  use_angle_cls: true
  lang: "ch"
  use_gpu: true

output:
  timestamp_format: "mm:ss"
  formula_latex: true

paths:
  cache_dir: "./cache"
  output_dir: "./output"
  temp_dir: "./temp"
```

## 五、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 配置文件不存在 | 抛出，提示用户检查路径 |
| yaml.YAMLError | YAML 语法错误 | 抛出，包含错误行号 |
| ConfigValidationError | 配置校验失败 | 抛出，包含具体字段和原因 |
