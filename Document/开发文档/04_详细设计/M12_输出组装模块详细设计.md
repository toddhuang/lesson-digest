### 2.1 OutputAssembler 类

```python
class OutputAssembler:
    def __init__(self, config: OutputConfig, llm_client: LLMClient = None):
        self.config = config
        self.llm_client = llm_client  # 用于 ASR 纠错

    def assemble(self, result: ProcessResult, output_dir: str) -> OutputFiles
    def write_transcript(self, asr_results, output_path, timestamp_format="mm:ss",

    def write_knowledge_list(self, knowledge_points, output_path, timestamp_format="mm:ss") -> str
    def write_problems(self, problems, screenshot_paths, output_dir, timestamp_format="mm:ss") -> List[str]
```

## 三、核心流程

### 3.1 assemble 流程

```
1. 从视频路径提取视频名（不含扩展名）作为输出子目录名
2. 构造输出目录结构：
   {output_dir}/{视频名}/
   ├── 01_逐字稿.md          （豆包纠错后）
   ├── 02_知识点清单.md
   ├── 03_思维导图.opml
   ├── 习题/
   └── 截图/
3. 确保所有目录存在
4. 调用 write_transcript() 生成逐字稿（含 ASR 纠错）
5. 调用 write_knowledge_list() 生成知识点清单
6. 调用 write_problems() 生成习题文件（原题+解析+截图引用）
7. 调用 write_mindmap() 保存思维导图
8. 收集所有输出文件路径
9. 返回 OutputFiles
```

### 3.2 write_transcript 流程（含 ASR 纠错）

```
1. 生成原始逐字稿（带时间戳）
2. 如果 enable_correction=True 且 llm_client 不为 None：
   a. 调用 correct_asr_text() 进行 ASR 纠错（豆包后端）
      - 去掉时间戳，提取纯文本（减少 token，避免时间戳误导 LLM 断句）
      - 调用豆包 LLM 进行纠错（修正同音词错误，如"地物"→"生物"）
      - 将纠错后的纯文本按原句子拆分，加回时间戳
   b. 纠错成功 → 使用纠错后的句子列表
   c. 纠错失败 → 降级使用原始句子列表，记录警告日志
3. 将句子列表格式化为 Markdown
4. 写入 01_逐字稿.md
5. 返回文件路径
```

> **ASR 纠错说明**：纠错后直接替换原始逐字稿，不保留双版本对比。纠错失败时降级使用原始逐字稿，不中断流水线。

### 3.3 视频名提取

```python
import os

def get_video_name(video_path: str) -> str:
    base = os.path.basename(video_path)
    name, _ = os.path.splitext(base)
    return name
```

## 四、文件格式规范

### 4.1 逐字稿格式

```markdown
# 逐字稿

> 视频：{视频名}
> 时长：{时长}
> 生成时间：{时间}
> ASR 纠错：已启用（豆包）

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
```

### 4.2 知识点清单格式

```markdown
# 知识点清单

> 视频：{视频名}
> 知识点数量：{N}

1. 一元二次方程的定义 [05:23]
2. 配方法解一元二次方程 [12:45]
3. 求根公式推导 [20:10]
4. 判别式与根的关系 [28:30]
```

### 4.3 原题文件格式

```markdown
# 题目01

> 时间范围：[05:23 - 12:45]
> 来源：2023年上海中考题
> 含图：是
> 原题来源：OCR 印刷体

## 原题

{原题文字}

## 题目截图

![题目01截图](../截图/题目01.png)
```

### 4.4 解析文件格式

```markdown
# 题目01 解析

> 时间范围：[05:23 - 12:45]

## 原题

{原题文字}

## 解题步骤

### 步骤1 [06:10]
{步骤内容}

### 步骤2 [08:30]
{步骤内容}
```

## 五、输出目录结构

```
{output_dir}/{视频名}/
├── 01_逐字稿.md          （豆包纠错后）
├── 02_知识点清单.md       （含核心内容 + 补充内容）
├── 03_思维导图.opml
├── 习题/
│   ├── 题目01.md          （原题 + 解题步骤合并）
│   ├── 题目02.md
│   └── ...
└── 截图/
    ├── 题目01.png
    ├── 题目02.png
    └── ...
```

> **截图说明**：题目截图由 M9 题目截图模块直接输出到 `{output_dir}/{视频名}/截图/` 目录，M12 只负责在原题 Markdown 文件中引用截图路径。

## 六、异常处理

| 异常类型 | 触发条件 | 处理方式 |
|---|---|---|
| FileWriteError | 文件写入失败 | 抛出 |
| DirectoryCreateError | 目录创建失败 | 抛出 |
| ASR 纠错失败 | LLM 调用失败或返回空 | 降级使用原始逐字稿，记录警告，不中断 |
