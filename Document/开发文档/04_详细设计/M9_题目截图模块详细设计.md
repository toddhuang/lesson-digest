## 三、核心流程

### 3.1 capture 流程

```
1. 检查视频文件是否存在
2. 检查 timestamp 是否在视频时长范围内
3. 确保输出目录存在
4. 构造 ffmpeg 单帧提取命令
5. 执行 ffmpeg
6. 检查输出文件是否生成成功
7. 如果 enable_color_filter=True：
   a. 调用 remove_color_keep_black() 去除彩色手写部分，只保留黑色印刷体题目
   b. 处理后的图片覆盖原文件
8. 返回输出路径
```

### 3.2 ffmpeg 命令

```python
cmd = [
    "ffmpeg",
    "-ss", str(timestamp),  # 快速定位到时间点
    "-i", video_path,
    "-vframes", "1",         # 只提取一帧
    "-q:v", "2",             # JPG 最高质量
    "-y",
    output_path
]
```

**关于 seek 精度**：`-ss` 放在 `-i` 之前是快速定位（关键帧 seek），可能有 ±1-2 秒误差。MVP 阶段可接受。P2 迭代可改为 `-ss` 放在 `-i` 之后（精确解码定位），或在 seek 点附近提取多帧选最佳。

### 3.3 capture_batch 流程

```
1. 确保输出目录存在
2. 遍历 problems：
   a. 构造输出文件名：题目{index:02d}.png
   b. 输出路径：{output_dir}/题目{index:02d}.png
   c. 调用 capture(video_path, problem.start_time, output_path)
   d. 成功 → 收集路径；失败 → 记录警告，收集 None
3. 返回路径列表
```

**单题失败降级**：批量截图时，单题失败不中断整个流程，返回 None。输出组装时，截图路径为 None 的题目不插入截图引用。

## 四、输出路径

截图直接输出到最终输出目录，**不经过 cache**：

```
{output_dir}/{视频名}/截图/题目01.png
```

理由：
1. 截图是最终输出物，不是中间结果
2. 避免多余的文件复制 IO
3. 截图生成速度快（单帧约 0.5-1 秒），无需缓存加速

---

## 五、不裁剪策略

**MVP 阶段默认不做任何画面裁剪**，直接提取完整帧。

理由：
1. PPT 讲课视频题目可能在画面任意位置，固定裁剪底部 20% 可能裁掉关键内容
2. 板书视频题目占满画面，裁剪无意义
3. 截图仅作参考附件，学生可以看到完整画面自行判断题目位置
4. 基于 OCR 文本框位置的智能裁剪是 P2 迭代功能

## 六、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 视频文件不存在 | 抛出 |
| FFmpegError | ffmpeg 执行失败 | 抛出，含 stderr |
| TimestampOutOfRangeError | 时间戳超出视频时长 | 抛出，含有效范围 |

### 6.1 批量处理降级

```python
try:
    path = self.capture(video_path, problem.start_time, output_path)
except (FFmpegError, TimestampOutOfRangeError) as e:
    logger.warning(f"题目 {problem.index} 截图失败: {e}")
    path = None
screenshot_paths.append(path)
```

## 七、性能考虑

- 单帧提取约 0.5-1 秒（ffmpeg seek + 解码）
- 10 道题约 5-10 秒
- MVP 阶段不做最佳帧选取（避免额外 OCR 开销）

---

## 八、P2 迭代规划

| 功能 | 实现思路 |
|---|---|
| 最佳帧选取 | 在 timestamp±5秒 范围内每秒提取一帧，按 OCR 文字完整度(0.5) + Laplacian清晰度(0.3) + 时间接近度(0.2) 评分选最佳 |
| 智能裁剪 | 基于 OCR 文本框的外接矩形，自动计算裁剪区域，排除老师人像/字幕条 |
| 精确 seek | `-ss` 放在 `-i` 之后，精确解码到时间点，消除 ±1-2 秒误差 |
| 多帧合成 | 题目跨越多帧时（如老师逐步板书），合成多帧为一张长图或 GIF |
