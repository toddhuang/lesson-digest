## 二、类设计

### 2.1 Pipeline 类

```python
class Pipeline:
    def __init__(self, config: Config):
        self.config = config
        self.context = PipelineContext()
        self._is_running = False
        self._is_cancelled = False
        self._logger = setup_logger("pipeline")

        # 初始化各模块
        self.audio_extractor = AudioExtractor(config.video)
        self.frame_extractor = FrameExtractor(config.video)
        self.asr_recognizer = ASRRecognizer(config.asr)
        self.ocr_recognizer = OCRRecognizer(config.ocr)
        self.text_merger = TextMerger(config.output.timestamp_format)
        self.llm_client = LLMClient(config.llm)
        self.knowledge_extractor = KnowledgeExtractor(self.llm_client, config)
        self.problem_extractor = ProblemExtractor(self.llm_client, config)
        self.screenshot_capture = ScreenshotCapture(self.frame_extractor)
        self.mindmap_generator = MindmapGenerator(self.llm_client, config)
        self.output_assembler = OutputAssembler(config.output)

    def run(self, video_path, output_dir, force=False) -> ProcessResult
    def run_stage(self, stage, context, config, force=False) -> PipelineContext
    def get_progress(self) -> PipelineProgress
    def cancel(self) -> None
```

## 三、流水线阶段定义

### 3.1 阶段列表与执行顺序

```python
STAGES = [
    "probe",              # 1. 探测视频信息
    "extract_audio",      # 2. 提取音轨（与3并行）
    "extract_frames",     # 3. 提取关键帧（与2并行）
    "asr",                # 4. 语音识别（与5并行）
    "ocr",                # 5. 文字识别（与4并行）
    "merge_text",         # 6. 文本合并
    "extract_knowledge",  # 7. 知识点提取（与8、10并行）
    "extract_problems",   # 8. 题目提取（与7、10并行）
    "capture_screenshots",# 9. 题目截图（依赖8）
    "generate_mindmap",   # 10. 思维导图生成（与7、8并行）
    "assemble_output",    # 11. 输出组装
]
```

### 3.2 并行执行策略

MVP 阶段为简化实现，**不做真正的多线程并行**，按顺序执行各阶段。原因：
1. MVP 质量优先，不优化速度
2. 并行实现复杂，错误处理困难
3. ASR 和 OCR 共享 GPU，同时运行可能 OOM
4. 后续迭代可加入并行优化

并行关系在文档中记录，代码中按顺序执行。

## 四、核心流程

### 4.1 run 流程

```
1. 检查视频文件是否存在
2. 初始化 PipelineContext（video_path）
3. 设置 _is_running = True, _is_cancelled = False
4. 遍历 STAGES：
   a. 检查 _is_cancelled → 取消则中断
   b. 检查该阶段是否已完成（缓存命中）→ 跳过
   c. 调用 run_stage(stage)
   d. 阶段失败 → 抛出 PipelineError，记录错误
   e. 更新 context.completed_stages
5. 所有阶段完成后，从 context 构造 ProcessResult
6. 设置 _is_running = False
7. 返回 ProcessResult
```

### 4.2 run_stage 各阶段实现

#### stage: probe
```python
video_info = probe_video(video_path)
context.video_info = video_info
# 检查是否有音轨和视频流
if not video_info.has_audio:
    raise InvalidVideoError("视频无音轨")
if not video_info.has_video:
    raise InvalidVideoError("视频无视频流")
```

#### stage: extract_audio
```python
audio_path = f"{cache_dir}/{video_hash}/audio.wav"
audio_info = self.audio_extractor.extract_audio(video_path, audio_path)
context.audio_path = audio_path
```

#### stage: extract_frames
```python
frames_dir = f"{cache_dir}/{video_hash}/frames"
frame_infos = self.frame_extractor.extract_frames(video_path, frames_dir)
context.frame_paths = [fi.path for fi in frame_infos]
context.frame_timestamps = [fi.timestamp for fi in frame_infos]
```

#### stage: asr
```python
asr_results = self.asr_recognizer.transcribe(context.audio_path)
context.asr_results = asr_results
# ASR 完成后卸载模型，释放显存
self.asr_recognizer.unload_model()
```

#### stage: ocr
```python
ocr_results = self.ocr_recognizer.recognize_batch(
    context.frame_paths, context.frame_timestamps
)
context.ocr_results = ocr_results
# OCR 完成后卸载模型
self.ocr_recognizer.unload_model()
```

#### stage: merge_text
```python
merged = self.text_merger.merge(context.asr_results, context.ocr_results)
context.full_text = self.text_merger.to_full_text(merged)
```

#### stage: extract_knowledge
```python
knowledge_points = self.knowledge_extractor.extract(
    context.full_text, context.video_info.duration
)
context.knowledge_points = knowledge_points
```

#### stage: extract_problems
```python
problems = self.problem_extractor.extract(
    context.full_text, context.video_info.duration
)
context.problems = problems
```

#### stage: capture_screenshots
```python
if context.problems:
    screenshots_dir = f"{cache_dir}/{video_hash}/screenshots"
    screenshot_paths = self.screenshot_capture.capture_batch(
        video_path, context.problems, screenshots_dir
    )
    context.screenshot_paths = screenshot_paths
else:
    context.screenshot_paths = []
```

#### stage: generate_mindmap
```python
mindmap_opml = self.mindmap_generator.generate(
    context.full_text, context.knowledge_points, video_name
)
context.mindmap_opml = mindmap_opml
```

#### stage: assemble_output
```python
output_files = self.output_assembler.assemble(
    ProcessResult(
        video_path=video_path,
        video_info=context.video_info,
        asr_results=context.asr_results,
        ocr_results=context.ocr_results,
        full_text=context.full_text,
        knowledge_points=context.knowledge_points,
        problems=context.problems,
        screenshot_paths=context.screenshot_paths,
        mindmap_opml=context.mindmap_opml,
    ),
    output_dir
)
context.output_files = output_files
```

## 五、断点续传机制

### 5.1 缓存目录结构

```
cache/{video_hash}/
├── audio.wav              # extract_audio 缓存
├── frames/                # extract_frames 缓存
├── asr.json               # asr 缓存
├── ocr.json               # ocr 缓存
├── full_text.txt          # merge_text 缓存
├── knowledge.json         # extract_knowledge 缓存
├── problems.json          # extract_problems 缓存
├── screenshots/           # capture_screenshots 缓存
└── mindmap.opml           # generate_mindmap 缓存
```

### 5.2 缓存检查

每个阶段执行前检查对应缓存文件：
```python
def is_stage_cached(stage: str, video_hash: str) -> bool:
    cache_paths = {
        "extract_audio": f"cache/{video_hash}/audio.wav",
        "asr": f"cache/{video_hash}/asr.json",
        "extract_knowledge": f"cache/{video_hash}/knowledge.json",
        # ...
    }
    return os.path.exists(cache_paths[stage])
```

`force=True` 时忽略所有缓存，强制重新处理。

## 六、错误处理

### 6.1 错误分级

| 级别 | 处理方式 | 示例 |
|---|---|---|
| 致命错误 | 中断流水线，返回错误 | 视频无音轨、ASR 模型加载失败 |
| 可恢复错误 | 重试（模块内部处理） | LLM 超时、网络错误 |
| 降级错误 | 跳过该步骤，记录警告 | OCR 某帧失败、截图截错 |

### 6.2 PipelineError

```python
class PipelineError(Exception):
    def __init__(self, stage: str, message: str, original_error: Exception = None):
        self.stage = stage
        self.message = message
        self.original_error = original_error
        super().__init__(f"[{stage}] {message}")
```

## 七、入口程序 main.py

```python
def main():
    parser = argparse.ArgumentParser(description="教学视频内容提取工具")
    parser.add_argument("video", help="视频文件路径")
    parser.add_argument("-o", "--output", default="./output", help="输出目录")
    parser.add_argument("-c", "--config", default="config.yaml", help="配置文件路径")
    parser.add_argument("-f", "--force", action="store_true", help="强制重新处理（忽略缓存）")
    args = parser.parse_args()

    # 加载配置
    config_manager = ConfigManager()
    config = config_manager.load(args.config)

    # 执行流水线
    pipeline = Pipeline(config)
    try:
        result = pipeline.run(args.video, args.output, force=args.force)
        print(f"处理完成！输出目录: {result.output_files.output_dir}")
    except PipelineError as e:
        print(f"处理失败: {e}")
        sys.exit(1)

if __name__ == "__main__":
    main()
```

## 八、GPU 显存管理时序

```
时间 →
[加载ASR] → [ASR识别] → [卸载ASR] → [加载OCR] → [OCR识别] → [卸载OCR] → [LLM调用(不占本地GPU)]
```

ASR 和 OCR 不同时加载，避免 GPU OOM。LLM 调用通过网络（本地 vLLM 在 4090 上，云端 DeepSeek 在远程），不占 3080 的 GPU 显存。
