## 三、核心流程

### 3.1 recognize_batch 流程

```
1. 加载 OCR 模型（如果未加载）
2. 遍历每张图片：
   a. 如果 enable_color_filter=True：
      - 调用 remove_color_keep_black() 去除彩色手写部分，只保留黑色印刷体
      - 处理后的图片保存到临时文件（或覆盖原文件）
   b. 检查缓存（cache_key = md5(image_path + file_size + file_mtime + ocr_model_name)）
   c. 缓存命中 → 加载缓存结果
   d. 缓存未命中 → 调用适配器识别
   e. 写入缓存
3. 相邻帧去重（如果 dedup=True）：
   a. 比较相邻两帧的 full_text 相似度
   b. 相似度 > 0.9 → 标记后一帧为重复帧（is_duplicate=True）
4. 返回 OCRFrameResult 列表
```

### 3.2 颜色过滤预处理

> **板书特征**：题目部分字体为黑色印刷体，老师的手写部分为彩色。颜色过滤去除彩色手写部分，只保留黑色印刷体题目，减少 OCR 干扰，提高准确率。

```python
from utils.image_preprocess import remove_color_keep_black

if enable_color_filter:
    # 去除彩色手写，保留黑色印刷体
    processed_path = remove_color_keep_black(image_path, output_path=None)  # None=覆盖原文件
    image_path = processed_path
```

颜色过滤实现详见 `M14_工具集详细设计.md` 第 14.9 节。

### 3.3 帧去重算法

```python
from difflib import SequenceMatcher

def is_duplicate(text_a: str, text_b: str, threshold: float = 0.9) -> bool:
    similarity = SequenceMatcher(None, text_a, text_b).ratio()
    return similarity > threshold
```

## 四、数据结构

### 4.1 OCRResult（dataclass）

```python
@dataclass
class OCRResult:
    text: str                    # 识别文本
    confidence: float            # 置信度（0-1）
    bounding_box: List[float]    # 文本框坐标 [x1, y1, x2, y2]（相对坐标 0-1）
```

### 4.2 OCRFrameResult（dataclass）

```python
@dataclass
class OCRFrameResult:
    timestamp: float             # 帧在视频中的时间点（秒）
    image_path: str              # 图片路径
    results: List[OCRResult]    # 该帧的所有识别结果
    full_text: str               # 该帧所有文本合并（按阅读顺序）
    is_duplicate: bool           # 是否为重复帧（与前一帧文字相同）
```

## 六、OCR 结果的去向

OCR 结果**不**混入逐字稿和全文本（避免语句逻辑混乱），但保留供以下模块使用：

| 模块 | OCR 用途 |
|---|---|
| M8 题目提取 | OCR 印刷体题目作为原题主要来源，补充 ASR 可能遗漏的题目文字 |
| M9 题目截图 | OCR 结果辅助判断题目区域（可选，MVP 不实现） |

## 七、异常处理

| 异常类型 | 触发条件 | 处理方式 |
|---|---|---|
| FileNotFoundError | 图片文件不存在 | 抛出 |
| OCRError | OCR 引擎识别失败 | 单帧失败不中断批量处理，返回空结果 |
| ModelLoadError | OCR 模型加载失败 | 抛出 |
