## 二、抽象基类 ASRAdapter

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import List

@dataclass
class Sentence:
    start_time: float
    end_time: float
    text: str
    confidence: float

class ASRAdapter(ABC):
    @abstractmethod
    def load_model(self, config: dict) -> None: ...

    @abstractmethod
    def unload_model(self) -> None: ...

    @abstractmethod
    def transcribe(self, audio_path: str) -> List[Sentence]: ...

    @abstractmethod
    def get_sampling_rate(self) -> int: ...

    @abstractmethod
    def get_device(self) -> str: ...
```

### 3.1 类属性与初始化

```python
class FunASRAdapter(ASRAdapter):
    def __init__(self):
        self.model = None
        self.config = {}
        self._sampling_rate = 16000
        self._device = "cuda"
```

### 3.2 load_model

```python
def load_model(self, config: dict) -> None:
    self.config = config
    self._device = config.get("device", "cuda")
    self._sampling_rate = config.get("sampling_rate", 16000)

    from funasr import AutoModel
    self.model = AutoModel(
        model=config.get("model", "paraformer-zh"),
        punc_model=config.get("punc_model", "ct-punc"),
        vad_model=config.get("vad_model", "fsmn-vad"),
        device=self._device,
        ncpu=4,  # CPU 线程数
    )
```

**模型说明**：
- `paraformer-zh`：中文语音识别模型（非自回归，速度快）
- `ct-punc`：标点恢复模型（给识别结果加标点）
- `fsmn-vad`：语音端点检测（自动切分长音频）

### 3.3 transcribe

```python
def transcribe(self, audio_path: str) -> List[Sentence]:
    if self.model is None:
        raise ModelNotLoadedError("ASR 模型未加载，请先调用 load_model()")

    result = self.model.generate(
        input=audio_path,
        batch_size_s=self.config.get("batch_size_s", 300),
    )

    if not result:
        return []

    # FunASR 返回列表，取第一个元素
    item = result[0]
    text = item.get("text", "")
    timestamp = item.get("timestamp", [])

    # 按标点分句，分配时间戳
    sentences = self._split_sentences(text, timestamp)
    return sentences
```

### 3.4 _split_sentences（分句逻辑）

```python
import re

def _split_sentences(self, text: str, timestamp: list) -> List[Sentence]:
    """
    按标点符号分句，为每个句子分配起止时间戳。

    timestamp 格式：[[start_ms, end_ms], ...]，每个字对应一个时间区间
    """
    if not text:
        return []

    sentence_endings = r'[。？！]'
    sentences = []
    current_text = ""
    char_index = 0
    current_start = timestamp[0][0] if timestamp else 0

    for char in text:
        current_text += char
        # 标点符号作为句子结束
        if re.match(sentence_endings, char):
            if char_index < len(timestamp):
                current_end = timestamp[char_index][1]
            else:
                current_end = current_start
            sentences.append(Sentence(
                start_time=current_start / 1000.0,  # 毫秒转秒
                end_time=current_end / 1000.0,
                text=current_text.strip(),
                confidence=1.0  # FunASR 不返回句级置信度
            ))
            current_text = ""
            char_index += 1
            if char_index < len(timestamp):
                current_start = timestamp[char_index][0]
        else:
            char_index += 1

    # 处理最后一个未结束的句子（无标点结尾）
    if current_text.strip():
        end = timestamp[char_index-1][1] if timestamp and char_index > 0 else current_start
        sentences.append(Sentence(
            start_time=current_start / 1000.0,
            end_time=end / 1000.0,
            text=current_text.strip(),
            confidence=1.0
        ))

    return sentences
```

### 3.5 unload_model

```python
def unload_model(self) -> None:
    if self.model is not None:
        import torch
        del self.model
        torch.cuda.empty_cache()
        self.model = None
```

### 3.6 get_sampling_rate / get_device

```python
def get_sampling_rate(self) -> int:
    return self._sampling_rate

def get_device(self) -> str:
    return self._device
```

## 四、适配器工厂

```python
def create_asr_adapter(adapter_type: str, config: dict) -> ASRAdapter:
    adapters = {
        "funasr": FunASRAdapter,
        # 后续新增适配器在此注册
    }
    if adapter_type not in adapters:
        raise ValueError(f"不支持的 ASR 适配器: {adapter_type}")
    adapter = adapters[adapter_type]()
    adapter.load_model(config)
    return adapter
```

## 五、可扩展适配器

将来新增 ASR 引擎时，只需继承 ASRAdapter 并实现 5 个方法：

| 适配器 | 引擎 | 特点 |
|---|---|---|
| FunASRAdapter | FunASR | 当前实现，中文识别好 |
| WhisperAdapter | OpenAI Whisper | 多语言，英文好 |
