## 三、核心流程

### 3.1 extract 流程

```
1. 计算缓存键（md5(full_text + model + temperature + max_tokens)）
2. 缓存命中 → 加载缓存，返回
3. 构造 System Prompt（知识点提取指令）
4. 构造 User Prompt（视频时长 + 全文本）
5. 调用 llm_client.chat(backend="cloud", temperature=0.1, max_tokens=4000)
6. 解析 LLM 返回的 JSON
7. 校验时间戳合法性
8. 去重（相同/相似名称合并）
9. 按时间戳排序
10. 写入缓存
11. 返回 KnowledgePoint 列表
```

### 3.2 LLM 调用

```python
response = self.llm.chat(
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user", "content": user_prompt}
    ],
    backend="cloud",  # 云端 LLM（默认豆包），128K 上下文
    temperature=0.1,  # 低温度，保证稳定性
    max_tokens=4000
)
```

**为什么用云端**：知识点提取需要全局理解全文，本地 8K 上下文可能不够（长视频全文本可能超过 8K），且云端模型智力更强。

## 四、Prompt 设计

### 4.1 System Prompt（完整版）

```
你是一个教学视频内容分析助手。请从以下带时间戳的教学视频全文本中，识别老师讲解的所有知识点。

【要求】
1. 识别视频中讲解的所有知识点（定义、定理、公式、方法、概念、性质等）
2. 为每个知识点标注在视频中的起始时间戳（格式 mm:ss）
3. 知识点名称要极简，1-2句话概括核心内容，不做详细解释
4. 不标注重点、难点、考点（不同学生掌握程度不同，避免过度解读）
5. 不遗漏任何知识点，包括老师随口提到的概念
6. 按时间戳顺序输出
7. 输出严格的 JSON 数组格式，不要包含 Markdown 代码块标记，不要有其他文字

【输出格式】
[
  {"index": 1, "name": "知识点名称", "start_time": "05:23", "confidence": 0.9},
  ...
]
```

### 4.2 User Prompt

```
【视频时长】{video_duration} 秒

【视频全文本】
{full_text}
```

## 五、结果解析与校验

### 5.1 JSON 解析

LLM 可能返回带 Markdown 代码块的文本，需要清理：

```python
import json, re

def parse_llm_response(content: str) -> list:
    # 移除 Markdown 代码块标记
    content = re.sub(r'```json\s*', '', content)
    content = re.sub(r'```\s*', '', content)
    content = content.strip()
    # 找到第一个 [ 和最后一个 ]
    start = content.find('[')
    end = content.rfind(']')
    if start == -1 or end == -1:
        raise LLMResponseParseError("未找到 JSON 数组")
    json_str = content[start:end+1]
    return json.loads(json_str)
```

### 5.2 时间戳校验

```python
def validate_timestamps(points: list, video_duration: float) -> list:
    valid = []
    for p in points:
        try:
            seconds = parse_timestamp(p["start_time"])
            if 0 <= seconds <= video_duration:
                p["start_time_seconds"] = seconds
                valid.append(p)
            else:
                logger.warning(f"知识点时间戳超出范围: {p['name']} @ {p['start_time']}")
        except InvalidTimestampError:
            logger.warning(f"无效时间戳格式: {p['name']} @ {p['start_time']}")
    return valid
```

### 5.3 去重

```python
from difflib import SequenceMatcher

def deduplicate(points: list, threshold=0.8) -> list:
    unique = []
    for p in points:
        is_dup = False
        for u in unique:
            similarity = SequenceMatcher(None, p["name"], u["name"]).ratio()
            if similarity > threshold:
                is_dup = True
                # 保留更早的时间戳
                if p["start_time_seconds"] < u["start_time_seconds"]:
                    u["start_time_seconds"] = p["start_time_seconds"]
                break
        if not is_dup:
            unique.append(p)
    return unique
```

## 八、异常处理

| 异常 | 触发条件 | 处理方式 |
|---|---|---|
| LLMError | LLM 调用失败（重试耗尽） | 抛出，中断流水线 |
| LLMResponseParseError | 返回结果无法解析为 JSON | 抛出，记录原始响应便于调试 |
| EmptyResultError | LLM 返回空列表 | 记录警告，返回空列表（视频可能无明确知识点） |

## 九、性能考虑

- LLM 调用是主要耗时，云端 LLM（默认豆包）API 响应时间约 10-30 秒（取决于全文本长度）
- 45分钟视频纯 ASR 全文本约 1-2 万字，输入 token 约 1.5-3 万，在云端 LLM 128K 范围内
- 解析和校验是纯内存操作，毫秒级
