### 2.1 TextMerger 类

```python
class TextMerger:
    def __init__(self, timestamp_format: str = "mm:ss"):
        self.timestamp_format = timestamp_format

    def merge(self, asr_results, ocr_results, include_ocr=True) -> List[MergedText]
    def to_full_text(self, merged_texts, timestamp_format=None) -> str
    def to_transcript(self, asr_results, timestamp_format=None) -> str
```

## 三、核心流程

### 3.1 merge 流程

```
1. 将 ASR 结果转换为 MergedText 列表（source="asr"）
2. 如果 include_ocr=True：
   a. 过滤掉 OCR 结果中的重复帧（is_duplicate=True）
   b. 将非重复 OCR 帧转换为 MergedText（source="ocr"，text=full_text）
3. 合并两个列表
4. 按 timestamp 升序排序
5. 同一时间戳的 ASR 排在 OCR 之前
6. 返回 MergedText 列表
```

### 3.2 排序规则

```python
def sort_key(item: MergedText):
    # 主排序：时间戳
    # 次排序：ASR 在前（"asr" < "ocr" 字母序）
    return (item.timestamp, 0 if item.source == "asr" else 1)
```

### 3.3 to_full_text 格式

```
[00:00] [ASR] 今天我们来讲一元二次方程...
[00:30] [OCR] 一元二次方程 ax²+bx+c=0
[00:35] [ASR] 首先我们来看定义...
```

实现：
```python
def to_full_text(self, merged_texts, timestamp_format=None):
    fmt = timestamp_format or self.timestamp_format
    lines = []
    for mt in merged_texts:
        ts = format_timestamp(mt.timestamp, fmt)
        source_tag = "[ASR]" if mt.source == "asr" else "[OCR]"
        lines.append(f"[{ts}] {source_tag} {mt.text}")
    return "\n".join(lines)
```

### 3.4 to_transcript 格式

```markdown
# 逐字稿

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
```

逐字稿只包含 ASR 结果，不包含 OCR。

### 4.1 MergedText

```python
@dataclass
```

## 五、OCR 文本处理

### 5.1 空文本过滤

OCR 识别结果中可能存在空文本（图片中无文字），合并时过滤掉：
```python
ocr_texts = [
    MergedText(timestamp=ocr.timestamp, text=ocr.full_text, source="ocr", confidence=1.0)
    for ocr in ocr_results
    if not ocr.is_duplicate and ocr.full_text.strip()
]
```

### 5.2 OCR 置信度

OCR 帧级置信度取该帧所有 OCRResult 置信度的平均值：
```python
frame_confidence = sum(r.confidence for r in ocr.results) / len(ocr.results) if ocr.results else 0.0
```

## 七、性能考虑

- 纯内存操作，速度极快（毫秒级）
- 全文本字符串可能较长（45分钟视频约 1-2 万字），但 Python 字符串处理无压力
