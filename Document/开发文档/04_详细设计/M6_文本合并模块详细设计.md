## 二、类设计

### 2.1 TextMerger 类

```python
class TextMerger:
    def __init__(self, timestamp_format: str = "mm:ss"):
        self.timestamp_format = timestamp_format

    def organize(self, asr_results: List[Sentence]) -> List[Sentence]
    def to_full_text(self, sentences: List[Sentence], timestamp_format: str = None) -> str
    def to_transcript(self, sentences: List[Sentence], timestamp_format: str = None) -> str
```

> **重要变更**：移除 `merge()` 方法（不再合并 ASR+OCR），新增 `organize()` 方法（纯 ASR 文本整理）。OCR 结果保留供 M8/M9 使用，但不混入逐字稿和全文本。

## 三、核心流程

### 3.1 organize 流程（纯 ASR 文本整理）

```
1. 输入：ASR 句子列表（List[Sentence]）
2. 按时间戳升序排序
3. 过滤空句子（text 为空或仅空白字符）
4. 合并相邻的短句（可选，根据配置）
5. 返回整理后的句子列表
```

> **为什么不混入 OCR**：OCR 文本与 ASR 文本合并会导致语句逻辑混乱。OCR 是帧级文本（30秒粒度），ASR 是句子级文本（秒级粒度），合并后 LLM 难以准确理解语义。OCR 结果保留供 M8 题目提取（补充原题）和 M9 题目截图使用。

### 3.2 to_full_text 格式

```
[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
[01:05] 接下来我们推导求根公式...
```

实现：
```python
def to_full_text(self, sentences, timestamp_format=None):
    fmt = timestamp_format or self.timestamp_format
    lines = []
    for s in sentences:
        ts = format_timestamp(s.start_time, fmt)
        lines.append(f"[{ts}] {s.text}")
    return "\n".join(lines)
```

### 3.3 to_transcript 格式

```markdown
# 逐字稿

> 视频：{视频名}
> 时长：{时长}
> 生成时间：{时间}

[00:00] 今天我们来讲一元二次方程...
[00:35] 首先我们来看定义...
```

> **注意**：`to_transcript` 生成的是原始逐字稿（未纠错）。ASR 纠错在 M12 输出组装模块的 `write_transcript` 方法中完成，纠错后直接替换原始逐字稿。

## 四、数据结构

### 4.1 Sentence（dataclass）

> 统一定义见 `00_数据模型.md`。

```python
@dataclass
class Sentence:
    text: str           # 句子文本
    start_time: float   # 起始时间（秒）
    end_time: float     # 结束时间（秒）
    confidence: float   # 置信度（0-1）
```

## 五、OCR 结果的去向

OCR 结果**不**混入逐字稿和全文本，但保留供以下模块使用：

| 模块 | OCR 用途 |
|---|---|
| M8 题目提取 | OCR 印刷体题目作为原题主要来源，补充 ASR 可能遗漏的题目文字 |
| M9 题目截图 | OCR 结果辅助判断题目区域（可选，MVP 不实现） |
