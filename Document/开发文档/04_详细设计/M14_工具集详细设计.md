### 2.1 count_tokens（token 计数）

```python
import tiktoken

def count_tokens(text: str, model: str = "cl100k_base") -> int:
    enc = tiktoken.get_encoding(model)
    return len(enc.encode(text))
```

> 豆包和 DeepSeek 均使用 cl100k_base 编码。

### 2.2 format_timestamp（时间戳格式化）

```python
def format_timestamp(seconds: float, fmt: str = "mm:ss") -> str:
    seconds = int(seconds)
    h = seconds // 3600
    m = (seconds % 3600) // 60
    s = seconds % 60
    if fmt == "hh:mm:ss":
        return f"{h:02d}:{m:02d}:{s:02d}"
    return f"{m:02d}:{s:02d}"
```

### 2.3 parse_timestamp（时间戳解析）

```python
def parse_timestamp(timestamp_str: str) -> float:
    parts = timestamp_str.split(":")
    if len(parts) == 2:
        m, s = parts
        return int(m) * 60 + int(s)
    elif len(parts) == 3:
        h, m, s = parts
        return int(h) * 3600 + int(m) * 60 + int(s)
    raise InvalidTimestampError(f"无效的时间戳格式: {timestamp_str}")
```

## 三、ASR 纠错工具（新增，14.8）

### 3.1 功能说明

用云端 LLM（默认豆包）对 ASR 逐字稿进行纠错，修正同音词错误（如"地物"→"生物"）。纠错后直接替换原始逐字稿，不保留双版本对比。

### 3.2 纠错流程

```
1. 去掉时间戳，提取纯文本（减少 token，避免时间戳误导 LLM 断句）
2. 调用豆包 LLM 进行纠错（修正同音词错误）
3. 将纠错后的纯文本按原句子拆分，加回时间戳
4. 返回纠错后的句子列表
```

### 3.3 实现代码

```python
from core.llm_client import LLMClient

CORRECT_SYSTEM_PROMPT = """你是一个语音识别纠错助手。请修正以下教学视频逐字稿中的同音词错误和识别错误。

【要求】
1. 只修正明显的同音词错误和识别错误（如"地物"→"生物"）
2. 不要改变原文的语义和语序
3. 不要添加或删除内容
4. 不要修改正确的句子
5. 输出修正后的完整文本，不要输出解释
6. 保持原文的段落结构"""

def correct_asr_text(sentences, llm_client, backend="cloud"):
    # 1. 提取纯文本（去掉时间戳）
    raw_text = "\n".join([s.text for s in sentences])
    
    # 2. 调用 LLM 纠错
    response = llm_client.chat(
        messages=[
            {"role": "system", "content": CORRECT_SYSTEM_PROMPT},
            {"role": "user", "content": raw_text}
        ],
        backend=backend,
        temperature=0.1,  # 低温度，保证稳定性
        max_tokens=len(raw_text) // 2 + 1000,
    )
    corrected_text = response.content
    
    # 3. 按原句子拆分，加回时间戳
    corrected_lines = corrected_text.strip().split("\n")
    corrected_sentences = []
    for i, orig in enumerate(sentences):
        if i < len(corrected_lines):
            corrected_sentences.append(Sentence(
                text=corrected_lines[i].strip(),
                start_time=orig.start_time,
                end_time=orig.end_time,
                confidence=orig.confidence,
            ))
        else:
            corrected_sentences.append(orig)  # 行数不匹配时保留原句
    
    return corrected_sentences
```

### 3.4 纠错失败降级

- LLM 调用失败 → 降级使用原始逐字稿，记录警告日志
- 返回空结果 → 降级使用原始逐字稿
- 行数不匹配 → 保留原句

## 四、图像预处理工具（新增，14.9）

### 4.1 功能说明

去除图片中的彩色部分，只保留黑色印刷体文字。用于板书视频（题目黑色，老师手写彩色），减少 OCR 干扰。

### 4.2 处理逻辑

```
1. 将图片转换为 HSV 色彩空间
2. 高饱和度（彩色）且高亮度的像素 → 替换为白色（去除）
3. 低饱和度或低亮度的像素 → 保留（黑色印刷体）
4. 输出处理后的图片
```

### 4.3 实现代码

```python
import cv2
import numpy as np

def remove_color_keep_black(image_path, output_path=None,
                             saturation_threshold=30, value_threshold=50):
    """去除彩色手写部分，只保留黑色印刷体"""
    img = cv2.imread(image_path)
    if img is None:
        raise FileNotFoundError(f"无法读取图片: {image_path}")
    
    # 转换为 HSV 色彩空间
    hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)
    h, s, v = cv2.split(hsv)
    
    # 创建掩码：高饱和度（彩色）且高亮度 → 去除（替换为白色）
    # 低饱和度或低亮度 → 保留（黑色印刷体）
    color_mask = (s > saturation_threshold) & (v > value_threshold)
    
    # 将彩色部分替换为白色
    result = img.copy()
    result[color_mask] = [255, 255, 255]  # BGR 白色
    
    # 保存结果
    if output_path is None:
        output_path = image_path  # 覆盖原文件
    cv2.imwrite(output_path, result)
    
    return output_path
```

### 4.4 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| saturation_threshold | 30 | 饱和度阈值，低于此值视为非彩色（保留） |
| value_threshold | 50 | 亮度阈值，低于此值视为黑色（保留） |
