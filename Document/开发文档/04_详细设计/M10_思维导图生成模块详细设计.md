## 三、核心流程

### 3.1 generate 流程

```
1. 计算缓存键
2. 缓存命中 → 加载缓存，返回
3. 构造 System Prompt（思维导图生成指令）
4. 构造 User Prompt（视频标题 + 知识点列表 + 全文本）
5. 调用 llm_client.chat(backend="cloud", temperature=0.2, max_tokens=4000)
6. 清理 LLM 返回的 XML（移除 Markdown 代码块标记）
7. 校验 OPML 格式合法性（XML 解析）
8. 校验知识点完整性（所有输入知识点都应出现）
9. 写入缓存
10. 返回 OPML 字符串
```

### 3.2 LLM 调用

## 四、Prompt 设计

### 4.1 System Prompt（完整版）

```
你是一个教学内容结构整理助手。请根据以下教学视频的全文本和知识点列表，生成课程知识结构的思维导图。

【要求】
1. 根据视频内容和知识点列表，整理出课程的章节结构
2. 第1层：章节（如"第一章 一元二次方程"）
3. 第2层：知识点（使用知识点列表中的名称）
4. 第3层（可选）：子知识点或要点
5. 层级不超过3层
6. 为每个知识点节点在 _note 属性中标注时间戳（格式：时间戳: mm:ss）
7. 不要遗漏任何知识点
8. 根节点标题使用提供的视频标题（无标题则用"课程笔记"）
9. 输出标准 OPML 2.0 格式
10. 直接输出 XML，不要包含 Markdown 代码块标记，不要有其他文字

【OPML 格式示例】
<?xml version="1.0" encoding="UTF-8"?>
<opml version="2.0">
  <head>
    <title>课程标题</title>
  </head>
  <body>
    <outline text="第一章 主题名">
      <outline text="1.1 知识点1" _note="时间戳: 05:23"/>
      <outline text="1.2 知识点2" _note="时间戳: 12:45"/>
    </outline>
  </body>
</opml>
```

## 五、OPML 校验

### 5.1 XML 格式校验

```python
import xml.etree.ElementTree as ET

def validate_opml(opml_content: str) -> bool:
    try:
        root = ET.fromstring(opml_content)
    except ET.ParseError as e:
        raise OPMLValidationError(f"OPML XML 格式错误: {e}")

    # 根节点校验
    if root.tag != "opml" or root.get("version") != "2.0":
        raise OPMLValidationError("根节点必须是 <opml version='2.0'>")

    # 必须包含 head 和 body
    if root.find("head") is None:
        raise OPMLValidationError("缺少 <head> 节点")
    if root.find("body") is None:
        raise OPMLValidationError("缺少 <body> 节点")

    # body 下至少有一个 outline
    body = root.find("body")
    if len(body.findall("outline")) == 0:
        raise OPMLValidationError("<body> 下没有任何 <outline> 节点")

    return True
```

### 5.2 知识点完整性校验

```python
def check_knowledge_coverage(opml_content: str, knowledge_points: list) -> list:
    """检查所有知识点是否都出现在思维导图中"""
    root = ET.fromstring(opml_content)
    all_outline_texts = [o.get("text", "") for o in root.iter("outline")]

    missing = []
    for kp in knowledge_points:
        found = any(kp.name in text or text in kp.name for text in all_outline_texts)
        if not found:
            missing.append(kp.name)
            logger.warning(f"知识点未出现在思维导图中: {kp.name}")
    return missing
```

缺失的知识点只记录警告，不中断处理（LLM 可能合并了相似知识点）。

## 九、性能考虑

- LLM 调用约 10-30 秒
- XML 校验是纯内存操作，毫秒级
- OPML 文件通常较小（几十 KB）

4. 时间戳标注（_note 属性）

7. 缓存命中和失效
8. 生成的 OPML 能否被 XMind/幕布等工具导入
