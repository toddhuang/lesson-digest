# 教学视频提取与总结工具 — Windows 开发环境安装文档

> 适用系统：Windows 10 / 11（64位）
> 显卡：NVIDIA RTX 3080（10GB）
> CPU：Intel i7-10700KF 8核16线程
> 内存：64GB DDR4-2666
> 磁盘：Samsung 980 1TB NVMe SSD
> 网络：Intel I225-V 2.5Gbps 有线
> 文档版本：v2.1（2026.08，修正 Windows PaddlePaddle 版本）
>
> **机器分工**：本机（3080）负责 FunASR 语音识别 + PaddleOCR 文字识别 + 主程序/GUI；4090 Ubuntu 工作站负责 vLLM 大模型推理。

## 二、逐个软件安装步骤

### 2.1 Python 3.11.x

#### 下载
- 官网下载页：https://www.python.org/downloads/windows/
- 在页面中找到 **Python 3.11.x** 系列的最新版本（如 3.11.9 / 3.11.10 等，以页面显示为准）
- 点击版本号进入下载页，拉到页面底部，下载 `Windows installer (64-bit)`
- 文件名类似 `python-3.11.x-amd64.exe`

#### 安装步骤
1. 双击运行安装程序
2. **勾选底部 `Add python.exe to PATH`**（非常重要）
3. 点击 `Install Now`（默认安装到 `C:\Users\你的用户名\AppData\Local\Programs\Python\Python311\`）
   - 或选择 `Customize installation`，建议安装到 `C:\Python311\`（路径更短，避免权限问题）
4. 安装完成后点击 `Close`

#### 安装位置
- 默认：`C:\Users\你的用户名\AppData\Local\Programs\Python\Python311\`
- 建议自定义：`C:\Python311\`

#### 环境变量
- 勾选 `Add python.exe to PATH` 后自动配置，无需手动添加
- 如果忘记勾选，手动添加以下两个路径到系统 `Path`：
  - `C:\Python311\`
  - `C:\Python311\Scripts\`

#### 验证
打开 PowerShell，输入：
```powershell
python --version
```
应输出：`Python 3.11.x`

> **为什么选 3.11 而不是 3.12**：FunASR、PaddlePaddle 2.6、PyTorch 均已支持 3.11，且 3.11 的 wheel 包最齐全；3.12 部分第三方库可能尚未发布预编译 wheel，容易遇到编译失败。

### 2.2 ffmpeg

#### 下载
- 官网：https://www.gyan.dev/ffmpeg/builds/
- 下载文件：`ffmpeg-release-full.7z`（full_build 版本，包含所有编解码器）

#### 安装步骤
1. 用 7-Zip 解压下载的 `.7z` 文件
2. 将解压后的文件夹重命名为 `ffmpeg`
3. 移动到 `C:\ffmpeg\`（最终目录结构：`C:\ffmpeg\bin\ffmpeg.exe`）

#### 安装位置
- `C:\ffmpeg\`

#### 环境变量配置
1. 按 `Win + S`，搜索「环境变量」，点击「编辑系统环境变量」
2. 在弹出的「系统属性」窗口中，点击右下角「环境变量」按钮
3. 在「系统变量」列表中找到 `Path`，双击编辑
4. 点击「新建」，输入：`C:\ffmpeg\bin`
5. 点击「确定」保存所有窗口

#### 验证
**关闭所有已打开的 PowerShell 窗口**，重新打开一个新的 PowerShell，输入：
```powershell
ffmpeg -version
```
应输出 ffmpeg 版本信息（第一行类似 `ffmpeg version 7.x-full_build-www.gyan.dev`）

### 2.4 Ollama（本地 LLM 推理 — 备选/兜底）

> 主 LLM 推理由 4090 Ubuntu 工作站的 vLLM 提供。Ollama 作为本地兜底方案，当 4090 不可用时使用。如不需要本地 LLM，可跳过此节。

#### 下载
- 官网：https://ollama.com/download/windows
- 下载文件：`OllamaSetup.exe`

#### 安装步骤
1. 双击运行 `OllamaSetup.exe`
2. 点击 `Install`，等待安装完成
3. 安装完成后 Ollama 会自动在后台运行（系统托盘有图标）

#### 安装位置
- 默认：`C:\Users\你的用户名\AppData\Local\Programs\Ollama\`
- 模型存储位置：`C:\Users\你的用户名\.ollama\models\`

#### 环境变量
- 安装程序自动配置，无需手动添加
- **可选**：如果想把模型存到其他盘（节省 C 盘空间），添加系统环境变量：
  - 变量名：`OLLAMA_MODELS`
  - 变量值：`D:\ollama_models`（你想存放的路径）
  - 设置后需重启 Ollama（任务管理器结束 ollama.exe 再重新打开）

#### 拉取模型
打开 PowerShell，根据你的 3080 显存版本选择：

**10GB 显存 → 推荐 Qwen3-7B：**
```powershell
ollama pull qwen3:7b
```

**12GB 显存 → 推荐 Qwen3-14B：**
```powershell
ollama pull qwen3:14b
```

> 模型文件较大（7B 约 4.7GB，14B 约 9GB），下载需耐心等待。

#### 验证
```powershell
ollama list
```
应显示已拉取的模型列表。

测试推理：
```powershell
ollama run qwen3:7b "你好，请用一句话介绍你自己"
```
模型回复后输入 `/bye` 退出。

## 三、Python 虚拟环境与依赖安装

### 3.1 创建项目目录和虚拟环境

打开 PowerShell，依次执行：

```powershell
# 进入项目目录（如果不存在则创建）
cd <项目根目录>

# 创建 Python 虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\Activate.ps1
```

> 激活成功后，命令行前缀会出现 `(venv)` 标识。
>
> 如果 PowerShell 报错「无法加载文件，因为在此系统上禁止运行脚本」，以管理员身份打开 PowerShell 执行：
> ```powershell
> Set-ExecutionPolicy RemoteSigned
> ```
> 输入 `Y` 确认，然后重新激活虚拟环境。

### 3.2 安装 PyTorch（GPU 版）

**从 PyTorch 官网获取最新安装命令**（推荐，确保版本最新）：
- 访问 https://pytorch.org/
- 选择：Stable → Windows → Pip → Python → CUDA 12.6
- 复制页面给出的安装命令

或直接执行以下命令（2026.08 最新稳定版，以官网为准）：

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cu126
```

> 此包约 2-3GB，下载需要一些时间。必须用 `--index-url` 指定 cu126 源，否则默认装 CPU 版。
>
> **为什么选 cu126**：RTX 3080（Ampere 架构，Compute Capability 8.6）在 CUDA 12.6 下性能最稳定；CUDA 13.x 对 Ampere 的优化不如 12.x 成熟。

验证 GPU 可用：
```powershell
python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0)); print('PyTorch version:', torch.__version__)"
```
应输出：
```
CUDA available: True
Device: NVIDIA GeForce RTX 3080
PyTorch version: 2.x.x+cu126
```

```powershell
pip install "funasr>=1.4.0" modelscope
```

> FunASR 1.4.0 为 2026.08 最新稳定版，支持 50+ 语言、说话人分离、情感检测。modelscope 用于自动下载 FunASR 模型。

### 3.4 安装 OpenAI SDK（用于 DeepSeek API）

### 3.6 安装 PaddleOCR（文字识别）

PaddleOCR 用于提取视频关键帧中的课件/板书文字，与 FunASR 语音识别互补。

> **重要**：PaddlePaddle 3.x **没有 Windows 版**（仅 Linux），Windows 上最高可用 2.6.1。以下命令已针对 Windows 环境修正。

#### 第一步：安装 PaddlePaddle GPU 版（Windows 最高版 2.6.1）

```powershell
pip install paddlepaddle-gpu==2.6.1.post120 -f https://www.paddlepaddle.org.cn/whl/windows/mkl/avx/stable.html
```

> `post120` 表示 CUDA 12.0 编译版。你的驱动支持 CUDA 12.6，向下兼容 12.0，没问题。包约 500MB-1GB。
>
> PaddlePaddle 与 PyTorch 是独立框架，可共存于同一虚拟环境，两者各自管理 GPU 显存，互不冲突。

#### 第二步：安装 PaddleOCR

```powershell
pip install paddleocr
```

> pip 会自动解析与 PaddlePaddle 2.6 兼容的 PaddleOCR 版本。如遇兼容性问题，可指定 `pip install "paddleocr<3.0"`。

#### 验证 PaddlePaddle GPU 可用

```powershell
python -c "import paddle; print('Paddle version:', paddle.__version__); print('Paddle CUDA:', paddle.is_compiled_with_cuda())"
```

应输出：
```
Paddle version: 2.6.1
Paddle CUDA: True
```

#### 验证 PaddleOCR 可导入

```powershell
python -c "from paddleocr import PaddleOCR; print('paddleocr ok')"
```

应输出：`paddleocr ok`

> PaddleOCR 模型无需手动下载，首次实际运行识别时会自动下载到 `C:\Users\你的用户名\.paddleocr\` 缓存目录，总计约 100-200MB。

#### 显存占用说明

| 组件 | 显存占用 |
|---|---|
| FunASR（语音识别） | ~1.5GB |
| PaddleOCR（文字识别） | ~1.5-2GB |
| 合计 | ~3-3.5GB |
| 3080 10GB 剩余 | ~6.5GB |
| 3080 12GB 剩余 | ~8.5GB |

两个识别引擎不会同时满载运行（ASR 跑完再跑 OCR），实际峰值更低，3080 完全无压力。

## 六、说明

1. **主 LLM 推理**：由 4090 Ubuntu 工作站的 vLLM 提供服务（详见《4090工作站_Ubuntu_vLLM部署文档》），Windows 端通过局域网 HTTP API 调用。

## 七、依赖冲突风险与规避

本项目同时使用 PyTorch（FunASR）和 PaddlePaddle（PaddleOCR）两个深度学习框架，以下为已知冲突点及应对措施：

| 冲突点 | 风险 | 说明 | 应对策略 |
|---|---|---|---|
| **numpy 版本** | 低 | PyTorch 2.13+ 已支持 numpy 2.x，PaddlePaddle 2.6 也兼容，不再需要锁定 <2.0 | 无需手动锁定，pip 自动解析；如遇个别库报错再降级 |
| **protobuf 版本** | 中 | FunASR 的 onnxruntime 与 PaddlePaddle 都依赖 protobuf，版本范围可能不重叠 | 全部安装完成后执行 `pip show protobuf` 确认；冲突时手动指定兼容版本 |
| **opencv-python** | 中 | PaddleOCR 依赖 opencv-python；避免引入 opencv-contrib-python 造成冲突 | 全程只装 `opencv-python`，不装 contrib 版 |
| **pydantic 版本** | 中 | openai SDK>=1.0 用 pydantic v2；FunASR/modelscope 某些版本可能依赖 v1 | 严格按第九章安装顺序操作，先框架后上层库；冲突时升级 FunASR 到最新版 |
| **CUDA runtime 共存** | 低 | PyTorch bundle CUDA 12.6，PaddlePaddle bundle CUDA 12.0，两者版本不同但各自独立加载 | 通常无需处理；如出现诡异 CUDA 错误，优先怀疑此点 |
| **shapely / pyclipper** | 低 | PaddleOCR 依赖，Windows 上需预编译 wheel | pip 通常直接装上；如失败执行 `pip install shapely --only-binary :all:` |
| **PaddlePaddle Windows 版本限制** | 中 | PaddlePaddle 3.x 仅支持 Linux，Windows 最高 2.6.1；PaddleOCR 新版可能要求 Paddle 3.x | Windows 上固定用 `paddlepaddle-gpu==2.6.1.post120`；PaddleOCR 用 `pip install paddleocr` 让 pip 自动解析兼容版本 |

## 九、严格安装顺序

**必须按以下顺序安装，最大限度减少依赖冲突：**

```
1. 创建 venv → 激活
2. 安装 PyTorch 最新稳定版+cu126（指定 --index-url，从 pytorch.org 获取命令）
3. 安装 PaddlePaddle-gpu==2.6.1.post120（Windows 最高版，指定飞桨源）
4. 安装 FunASR >=1.4.0 + modelscope
5. 安装 PaddleOCR（pip 自动解析兼容版本）
6. 安装 openai + python-dotenv
7. 执行第五章全部验证
8. 锁定全量版本：pip freeze > requirements.txt
```

**原理**：先装两个大框架（PyTorch、PaddlePaddle），它们对 numpy/protobuf 等底层依赖有严格版本要求，pip 先解析框架的依赖树；上层库后装，在已有约束下解析，冲突概率最低。

> **v2.1 变化**：PaddlePaddle 固定为 2.6.1.post120（Windows 最高版，3.x 仅 Linux）；不再需要 `pip install "numpy<2.0"`，PyTorch 2.13+ 已支持 numpy 2.x。

## 十、Windows 平台注意事项

| 问题 | 影响 | 应对 |
|---|---|---|
| **默认编码 GBK** | Python 读写中文文件/控制台打印可能乱码 | 代码中统一 `encoding='utf-8'`；PowerShell 执行 `chcp 65001` 切换 UTF-8 代码页 |
| **路径长度 260 限制** | venv 嵌套深 + 模型缓存路径长可能报错 | 虚拟环境放在短路径如 `C:\work\videocontents\venv`；如需启用长路径，以管理员执行 `reg add HKLM\SYSTEM\CurrentControlSet\Control\FileSystem /v LongPathsEnabled /t REG_DWORD /d 1 /f`，然后重启 |
| **PowerShell 执行策略** | venv 激活脚本 `Activate.ps1` 被禁止运行 | 以管理员打开 PowerShell 执行 `Set-ExecutionPolicy RemoteSigned`，输入 Y 确认 |
| **符号链接权限** | 某些库创建 symlink 失败 | 以管理员运行 PowerShell，或在「设置 → 更新和安全 → 开发者选项」中启用「开发人员模式」 |
| **防火墙** | 4090 工作站的 vLLM API 可能被 Windows 防火墙拦截 | 首次通信时防火墙弹窗选择「允许」；或手动放行 Python 程序 |
