# 帧去重算法对比测试结果

> 测试日期：2026-08-28
> 测试视频：`tests/test.mp4`（25 分钟，1920×1080，30 fps，45253 帧）
> 抽帧间隔：1.0 秒（共抽样 1509 帧）
> 阈值：0.05（差异分数统一阈值，仅作首轮对比）

---

## 一、测试目的

验证 4 种帧去重算法在教学视频场景的表现，为 R-009 选型提供实测依据。R-008 已定案：**帧去重用图像哈希/帧差算法（非 OCR），无变化保留前一帧、有变化才交给 OCR**。

## 二、算法说明

| 算法 | 原理 | 输出 | 复杂度 | 存储开销 |
|---|---|---|---|---|
| dHash | 8×8 灰度图相邻像素差，汉明距离 / 64 | 差异分数 0~1 | O(n) 像素 | 64 bit/帧 |
| pHash | 32×32 DCT 后取左上 8×8 均值比较 | 差异分数 0~1 | O(n log n) DCT | 64 bit/帧 |
| absdiff | GaussianBlur 后 absdiff+二值化阈值 25，变化像素比例 | 差异分数 0~1 | O(n) 像素 | 前一帧图像 |
| SSIM | 结构相似性，1 - ssim（gray 单通道） | 差异分数 0~1 | O(n × window²) | 全图比对 |

## 四、初步观察

### 4.1 算法保留帧数差异显著

- **pHash 最严**（28 帧）：DCT 频域比对对局部小变化不敏感，可能漏检板书累加帧
- **dHash 最松**（56 帧）：8×8 粗度太粗，对摄像头微小抖动或光线波动可能误判
- **absdiff / SSIM 居中**（41 / 50 帧）：理论上对教学视频场景匹配度最高

### 4.2 阈值需分算法调优

统一 0.05 阈值在不同算法下意义不同：
- dHash/pHash 是汉明距离 / 64，0.05 = 3 位差异（敏感）
- absdiff 是变化像素比例，0.05 = 5% 像素变化（合理）
- SSIM 是 1-ssim，0.05 = ssim 0.95（敏感）

后续应每个算法跑多组阈值（0.02 / 0.05 / 0.08 / 0.12），找各自最优点。

### 4.3 pHash 漏检风险

pHash 28 帧最少，需人工查看是否漏检关键板书累加帧——若漏检，下游 OCR 拿不到完整板书序列。

## 五、下一步建议

1. **人工查看**：打开 `temp/{dhash,phash,absdiff,ssim}/` 目录，对比各算法保留的帧内容，看哪些算法漏检了 PPT 翻页瞬间或板书累加点
2. **多阈值对比**：跑 0.02 / 0.05 / 0.08 / 0.12 四组阈值，看每个算法的阈值响应曲线
3. **混合算法**：考虑 absdiff 做粗筛 + SSIM 做精筛的两级流水线
4. **真实场景验证**：选 2-3 段不同老师/不同学科的教学视频重复测试，避免过拟合到单一视频
